# 评测结果记录

此目录只保存实际运行日志和汇总结果。当前包含一组 `captured_unscored` 的匿名网页模型输出采集记录；它不是已验证结论，也不能替代人工评分、真实学习者数据或正式发行证据。不要用构建成功、一次演示或未评分输出填充“已验证”结论。

每次运行建议保存一个版本化文件，并至少记录：

```text
评估日期：
模型/版本：
任务集版本：prysai-llm-playbook-v1
运行环境：
工具集与权限：
网络条件：
重复次数：每项至少 3 次
输出格式：

首次通过率：
返工率：
停止正确率：
主要错误类型：
平均耗时/成本：
证据完整度：
人工评分：正确性、完整性、清晰度、可维护性、安全性
限制与不确定性：
下一次复核日期：
```

逐项记录应包含任务 `id`、每次运行的原始输出或可追溯引用、通过/失败判定、证据链接或日志位置、错误分类、返工次数以及人工复核备注。敏感信息必须脱敏；不得写入令牌、密码、Cookie、私钥或 `.env` 内容。

建议的状态解释：

- `draft`：结果或夹具仍在编写，尚无最低验证。
- `candidate`：结构检查和基本运行已完成，但覆盖或独立复核不足。
- `verified`：在声明的任务、上下文、工具、权限和重复条件下，通过正例、边界例、失败例和迁移例。
- `production-ready`：另行通过安全、维护、版本、许可和组织发布门禁；不能仅凭本任务集授予。

结果应与 [任务集说明](../README.md) 和 [评测框架](../../docs/quality/evaluation-framework.md) 保持一致。
