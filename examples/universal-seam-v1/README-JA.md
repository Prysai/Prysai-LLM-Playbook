# Universal Seam Fixture v1

これは最初のユニバーサルコアルート用の、小さな架空のオフライン練習です。画面上の返信、ブランチ名、ツール出力のようなブロック、あるいはパーサーの成功だけでは、依頼したタスク、対象、実行、構造化された状態が正しいとは**証明できません**。

アカウント、モデル呼び出し、ネットワーク、認証情報、実在リポジトリ、ファイル変更、コマンド、commit、push、公開、外部副作用はありません。記録はプロジェクト独自の架空教材で、ベンダーのログではありません。

## やること

`cases.json` の各記録について、不一致を特定し、最小で安全な確認を書き、状態の意味を狭く保ちます。

| 状態 | この固定練習での意味 |
| --- | --- |
| `verified_in_fixture` | 与えられたローカル値が、その不一致を直接示す。 |
| `blocked` | 対象または権限の証拠が矛盾するため、次の操作は停止する。 |
| `not_run` | 実行受領書がない。操作が実行されたとは示されていない。 |
| `inferred` | 差異はあるが、実際の診断にはプラットフォームアダプターが必要。 |

リポジトリのルートから実行します。

```powershell
$py = (Get-Command python -ErrorAction Stop).Source
& $py scripts\validate_universal_seam_fixture.py
& $py scripts\test_universal_seam_fixture.py
```

コマンドは固定契約と境界テストを確認するだけで、モデルやサービスには接続しません。

## 範囲を限定した記録カード

```text
タスク：与えられた架空記録の seam を一つ分類する。
先に読む：cases.json と expected/acceptance.json。
許可：固定値を比較し、ローカルの判断メモを書く。
禁止：ネットワーク、アカウント、秘密情報、実在リポジトリ、ライブツール、コマンド、commit、push、公開先の利用。
受け入れ条件：不一致、根拠のない推論、最小安全確認、停止条件、与えられた狭い状態を記す。
受領書：ケース ID、観測項目、判断、未検証リスト、将来アダプターが必要かどうか。
停止：実際の製品挙動、権限、スキーマ、外部状態が必要になった時点。
```

## 合格しても分からないこと

合格は固定された架空記録が受け入れ契約に合うことだけを示します。外部の問題、プラットフォームの挙動、操作の実行、学習者の転移、安全性、可搬性、公開準備を証明しません。
