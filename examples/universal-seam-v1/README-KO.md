# Universal Seam Fixture v1

이것은 첫 번째 범용 코어 경로를 위한 작고 가상의 오프라인 연습입니다. 화면에 보이는 답변, 브랜치 이름, 도구 출력처럼 보이는 블록 또는 파서 성공만으로는 요청한 작업, 대상, 실행, 구조화된 상태가 맞다고 **증명할 수 없습니다**.

계정, 모델 호출, 네트워크 요청, 자격 증명, 실제 저장소, 파일 변경, 명령 실행, commit, push, 게시 또는 외부 부작용은 없습니다. 기록은 공급자 로그가 아니라 프로젝트가 만든 가상 학습 자료입니다.

## 할 일

`cases.json`의 각 기록에서 정확한 불일치를 찾고, 가장 작은 안전 점검을 적은 뒤 상태의 뜻을 좁게 유지하세요.

| 상태 | 이 고정 연습에서의 뜻 |
| --- | --- |
| `verified_in_fixture` | 제공된 로컬 값이 해당 불일치를 직접 보여 줍니다. |
| `blocked` | 대상 또는 권한 증거가 충돌하므로 다음 작업은 멈춰야 합니다. |
| `not_run` | 실행 영수증이 없습니다. 어떤 작업도 실행되었다고 보이지 않습니다. |
| `inferred` | 차이는 있지만 실제 진단에는 플랫폼 어댑터가 필요합니다. |

저장소 루트에서 실행하세요.

```powershell
$py = (Get-Command python -ErrorAction Stop).Source
& $py scripts\validate_universal_seam_fixture.py
& $py scripts\test_universal_seam_fixture.py
```

명령은 고정 계약과 경계 테스트만 확인하며, 모델이나 서비스에 연결하지 않습니다.

## 범위를 제한한 기록 카드

```text
작업: 제공된 가상 기록 하나에서 seam을 분류합니다.
먼저 읽기: cases.json 및 expected/acceptance.json.
허용: 고정 값을 비교하고 로컬 판단 메모를 작성합니다.
금지: 네트워크, 계정, 비밀, 실제 저장소, 라이브 도구, 명령, commit, push, 게시 대상 사용.
수용 조건: 불일치, 뒷받침되지 않는 추론, 최소 안전 점검, 중단 조건, 제공된 좁은 상태를 적습니다.
영수증: 사례 ID, 관찰한 필드, 판단, 미확인 목록, 미래 어댑터 필요 여부.
중단: 실제 제품 동작, 권한, 스키마 또는 외부 상태가 필요할 때.
```

## 통과가 증명하지 않는 것

통과는 고정된 가상 기록이 수용 계약과 맞는다는 뜻뿐입니다. 외부 문제, 플랫폼 동작, 작업 실행, 학습자의 전이, 안전성, 이식성 또는 게시 준비 상태를 증명하지 않습니다.
