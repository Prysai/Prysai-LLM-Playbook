# Skill sandboxes

These are disposable workspaces for turning a Skill contract into an observable
artifact. They are intentionally separate from the book's canonical source and
must stay safe to delete and recreate.

## Current sandbox

- [`product-context-real-estate/`](product-context-real-estate/): a fictional
  buyer-first brokerage brief, context draft, static HTML/CSS page, and local
  screenshot.
- [Case record](../../docs/research/skill-case-product-context-real-estate-2026-08-11.md)
- [Rendered evidence](../../assets/cases/README.md)

The current case is a project-owned concept. It does not prove that the
Product Context Skill ran independently, that a real estate business approved
the page, or that the page has live listings or conversion performance.

## Sandbox rules

- Use synthetic inputs and local-only assets.
- Keep secrets, personal data, live credentials, and external write actions
  out of the sandbox.
- Capture the command or browser conditions needed to reproduce an artifact.
- Record both the visible result and the claims it cannot support.
