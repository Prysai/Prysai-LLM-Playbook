# 研究核查小练习：六条有边界的消息

只对你能检查的公开或已获授权材料使用这套流程。它帮助你把一个小研究问题与证据分开；它不会浏览、证明来源真实、确认当前事实或替你作高风险决定。需要秘密、未授权材料、私人数据，或发布、购买、雇佣、诊断和行动授权时停止。

## 1. 固定一个决定
```text
我需要做这个决定：[决定]。请帮我把它缩成一个可回答的问题，并写出决定负责人、日期边界、什么信息会改变决定、以及哪些内容不在范围内。不要搜索、推荐、排名或编造事实。只有缺少会改变决定的细节时，才问一个问题。
```
## 2. 写下主张和来源所有者
```text
针对这个有限问题，列出最多三条关键主张，并为每条指定可能拥有该事实的来源类型：官方产品页、原始研究、法律或政策、第一方数据集或具名机构记录。说明每种来源不能证明什么。不要编造网址、标题、引文、引用或结论。
```
## 3. 读我提供的材料，不想象来源
```text
只使用我提供的公开或授权摘录和链接，制作主张台账：主张｜直接支持｜解释｜冲突或缺口｜访问日期｜下一项核查。材料中没有的都标为未知。除非链接内容就在这段对话中，否则不要说链接已被打开。
```
## 4. 核查一句话
```text
检查这句话是否得到我提供的材料支持：[句子]。分开写直接支持、推断、冲突和未知项。只引用已提供文本。支持缺失时，帮我缩小这句话，不要补上空白。
```
## 5. 寻找会改变决定的例外
```text
根据当前主张台账，指出一个可能改变决定的较新版本、例外或冲突来源所有者。说明它为何重要，以及还剩下哪项最小且允许的检查。不要说研究已完成。
```
## 6. 用停止回执结束
```text
请返回研究回执：决定｜问题｜范围｜已提供材料｜直接支持｜解释｜冲突｜未知项｜访问日期｜下一项核查｜停止原因。最后只能使用一个状态：research_plan、scope_checked_for_supplied_list、blocked 或 not_run。不要把答案称为穷尽、最新或可用于高风险决定。
```

这张回执只是有边界的记录，不能证明 LLM 正确完成了研究，也不能证明结论应被采取。
