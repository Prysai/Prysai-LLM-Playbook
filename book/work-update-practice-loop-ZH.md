# 工作更新小练习：六条不编造事实的消息

只使用虚构事实。这是一套文字练习，用来让一条短更新更容易核对；它不证明更新准确、专业、已获批准或适用于真实工作。需要私人、客户、雇佣、财务或生产信息时立即停止。

## 1. 先定读者和事实
```text
我想练习一条虚构的工作更新。请依次问我：一位读者、最多三条已确认事实、一条未知或阻碍、以及一个可能的请求。不要编造进度、日期、原因、批准或承诺。只返回简短事实清单，然后等待我自己起草。
```
## 2. 先写，不看范文
```text
只使用我们保存的虚构事实，让我为指定读者写一条 60 字以内的更新。不要代写、润色或添加标题。我发出后，请原样保留第一次尝试。
```
## 3. 找一个关键缺口
```text
按这份检查表比较我的初稿：读者能找到已确认事实、未知或阻碍，以及请求；文中没有无依据的进度或承诺。最多指出一个关键缺口，并引用相关文字。事实不足以判断时，请说“未知”。不要重写更新。
```
## 4. 用自己的话修改
```text
只针对这个缺口给我一条不完整的提示，然后等待我的修改。除非我尝试后明确要求，否则不要写替代版本。把初稿、你的提示和我的修改分开保留。
```
## 5. 更换读者
```text
保持虚构事实完全相同，但把读者从同事换成负责人。请让我在没有提示的情况下另写一版，然后标出语气、细节和请求发生了什么变化。不要把未知写成事实，也不要说任何一版已获批准。
```
## 6. 留下一张小回执
```text
请返回练习回执：虚构事实｜第一次尝试｜一条提示｜学习者修改｜更换读者后的尝试｜需要核对的新增内容｜未知项。最后只能使用一个状态：template_selected、practised、not_run 或 blocked。不要声称效率、写作能力、职场准备度或记忆有所提高。
```

把两版草稿和回执放在一起。一次有记录的循环只是练习，不是独立测评，也不能证明 AI 的反馈正确。
