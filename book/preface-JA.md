# 序：これはプロンプト集ではない

GPT に初めて触れたとき、最も自然に浮かぶ質問は「何と言えばよいのか」でしょう。

この質問は大切ですが、それだけでは足りません。Codex のタスクを安定して完了できるかどうかを決めるのは、別の問いであることが多いからです。何を理解しているのか。どのファイルとルールがコンテキストに属するのか。どんな行動を取れるのか。どの Skill が漏れを減らすのか。Agent はなぜ続行し、再試行し、一時停止し、または停止するのか。完了したと信じてよい根拠は何か。

`Prysai LLM Playbook` が扱うのは、まさにこの一連の関係です。

## ここで学ぶこと

このプロジェクトは、二つの方向へ同時に進みます。

一つは理解の経路です。GPT とモデルから出発し、Codex がモデルをプロジェクト、ファイル、ターミナル、ブラウザー、GitHub、外部サービスへどう接続するかを理解します。そのうえで、コンテキスト、ツール、Skill、Plugin、Connector、MCP、Agent、権限が、行動できる範囲をどのように変えるかを学びます。

もう一つは能力の経路です。低リスクの小さなタスクから始め、タスクの表現、コンテキストの選別、計画、実行、検証、レビュー、納品を練習します。その後、Skill の選択と設計、モデルとワークフローの評価、個人の仕事の仕組みづくりへ進み、最後にはチームで共有・レビュー・更新できる能力パッケージへ方法を変換します。

この二つの経路は分離できません。原理だけを理解して練習しなければ、用語を覚えただけで終わります。境界を理解せずにツールだけを呼び出せば、偶然の成功を信頼できる能力だと誤認しやすくなります。

## 読み方

順番に読んでもよいですし、現実のタスクから入ってもかまいません。各章は同じ閉ループに沿って構成されています。

```text
問題 → 概念 → 判断 → 操作 → 証拠 → 失敗 → 振り返り → 移行
```

章の「実験」は、デモ動画の代わりに眺めるものではありません。学習者自身が実行する最小タスクです。実験では、結果、差分、ログ、出典、スクリーンショット、または振り返りを残すよう求めます。そうして初めて、読書が能力へ変わります。

## 本当に学べたかをどう判断するか

このプロジェクトでは、「出力がとてもきれいに見える」ことを習得の基準にしません。一つの能力には、少なくとも次の四種類の証拠が必要です。

- 自分の言葉で、概念と境界を説明できる。
- 現実の環境、または低リスクな環境で、操作を完了できる。
- なぜそのモデル、ツール、Skill、権限を選んだのか説明できる。
- エラー、リスク、幻覚、未完了の項目、古くなった事実を発見できる。

結果だけを示し、過程と証拠を説明できないなら、練習を一度終えた可能性はあっても、方法を身につけたとは限りません。

## Luna について

GPT-5.6 Luna は、このプロジェクトが重点的に評価するモデルの一つです。原文のプロジェクト文書では、OpenAI の公式資料における位置付けとして、速度が速く比較的低コストで、明確かつ反復可能なタスクに向くという説明を、検証すべき仮説として扱っています。ただし、その位置付けから「すべてのタスクで費用対効果が最も高い」と結論づけることはできません。

このプロジェクトでは、タスクセット、コンテキスト、ツール、権限、時間予算、反復回数、成功基準を固定したうえで、初回通過率、やり直し率、所要時間、コスト、証拠の完全性、停止の正しさを比較する方法を学びます。結論は、明示したタスクセット、環境、日付の範囲にだけ適用されます。日本語訳そのものは、元の主張を独自に再検証した証拠ではありません。[Luna 評価資料（移行中）](../docs/model-evaluation-luna.md) を参照してください。

## 大切な安全原則

能力が強くなるほど、境界は明確でなければなりません。Codex がファイル、ターミナル、ブラウザー、GitHub、外部サービスへアクセスできるからといって、すべての権限を一度に開放しないでください。まずは読み取り専用、低リスク、ロールバック可能なタスクから始め、証拠によって本当に必要だと分かったときだけ、能力を段階的に増やします。トークン、パスワード、API キー、Cookie、秘密鍵、`.env` ファイルは、実験にもリポジトリにも入れません。

この本が最終的に届けたいのは、神秘的な「万能プロンプト」の集まりではありません。説明でき、検査でき、改善でき、他の人へ教えられる仕事の進め方です。

## 現実の問題から始める

最初から順番に読まなくてもかまいません。[日本語版の書籍入口](README-JA.md)から、現在作成済みの入口を確認できます。[書籍目次（移行中）](table-of-contents-JA.md)から章を選び、その章に記載される現実の問題事例、評価フィクスチャの仕様、研究アーカイブへ進むこともできます。第 19～22 章は現在「ドラフト執筆済み、事前テスト待ち」です。これらの入口は練習と証拠の場所を示すものであり、章や評価が検証完了したことを意味しません。
