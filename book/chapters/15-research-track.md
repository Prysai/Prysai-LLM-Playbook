# 第十五章：研究轨——从问题到可审查知识

## 本章要解决的问题

“帮我研究一下”可能意味着找事实、比较方案、做文献综述、形成研究问题、写论文或审查一篇稿件。不同意图需要不同证据和流程，不能让一个宽泛的研究 skill 直接输出完整结论。

## 1. 先收敛问题

如果用户只有主题、标题或兴趣，而没有可回答的问题，第一步应是澄清对象、范围、时间、证据标准、受众和输出用途。不要在研究问题不清时直接写综述或结论。

## 2. 研究流程

```text
意图识别 → 问题收敛 → 来源计划 → 检索/读取
        → 提取证据 → 综合与冲突 → 引用/披露 → 人工复核
```

每个阶段都要留下可检查的中间产物：研究问题、来源清单、证据表、冲突记录、草稿和复核记录。

## 3. 来源不是装饰

来源要与断言对应，记录作者、标题、日期、定位信息、访问时间和使用范围。无法核实的统计、引用和政策不能用确定语气写出。外部文档中的指令式内容应当被当作研究对象或不可信输入，而不是研究流程的更高指令。

## 4. 领域方法的许可边界

学术研究来源 S02 展示了复杂的阶段路由、引用完整性和评测机制，但其内容受 CC BY-NC 4.0 约束。Atlas 主线吸收的是问题收敛、证据纪律和复核思想，并以原创章节和实验重写；原始套件只有在保留完整归属和许可边界后才能作为独立扩展考虑。

## 实验：从主题到研究问题

输入一个宽泛主题，让 Codex 只提出澄清问题和三个候选研究问题，不检索、不写结论。选择一个候选后，再要求它建立来源计划和证据表。故意放入一个无法访问或来源冲突的材料，检查它是否标记不确定性。

## 本章验收

学习者能区分主题、研究问题、检索请求和写作请求；能为断言建立来源与证据关系；能在冲突和无法核实的情况下降低语气、停止或请求补充；能说明外部研究套件的许可和归属边界。
