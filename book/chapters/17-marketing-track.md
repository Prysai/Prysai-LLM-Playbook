# 第十七章：营销轨——从产品理解到增长实验

## 本章要解决的问题

营销任务常常因为缺少产品、受众和定位上下文而变成泛泛的文案。营销 skill 的价值首先是建立共享产品理解，其次才是生成内容、设计实验和测量结果。

## 1. 先建立产品上下文

至少记录产品、受众、核心问题、替代方案、差异化、反对意见、客户语言、品牌语气、证明材料和目标行动。上下文文档应版本化，有变更原因和日期，供不同营销任务复用。

## 2. 为决策而测量

不要先收集大量事件，再问数据有什么用。先写要做的决策、需要知道的问题、最小数据、命名规范、触发条件、隐私边界和验证方式。指标能改变什么行动，才值得实现。

## 3. 用 Agent 做增长实验

```text
产品上下文 → 假设 → 受众/渠道 → 变体 → 测量计划
          → 实施 → 数据质量检查 → 解释与下一轮行动
```

Agent 可以帮助整理、生成和分析，但不能把归因、样本、隐私或统计不确定性隐藏在漂亮图表后面。

## 4. 营销 skill 的融合边界

S04 的 49 个 skills 展示了从产品营销、SEO、内容、转化、广告、留存到分析的完整域。Atlas 不照搬 49 个目录，而是将其压缩为产品上下文、内容与定位、转化实验、分发与增长、测量与归因五个能力簇，再用统一的任务协议和证据审查连接它们。

## 实验：同一产品的两种请求

分别给 Codex：

1. “为产品写一段高级介绍”；
2. 产品上下文 + 目标受众 + 反对意见 + 目标行动 + 测量计划。

比较输出是否更具体、更可检验；再让它提出一个增长实验，检查是否说明假设、指标、样本和下一步决策。

## 本章验收

学习者能创建版本化产品上下文；能从决策反推最小测量计划；能把营销 skill 组织成能力簇而非目录堆叠；能指出一次营销结论的样本、归因、隐私和不确定性边界。
