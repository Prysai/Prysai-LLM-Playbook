# 第 17 章：营销路线——从产品理解到增长实验

**状态：**`candidate`。**实验状态：**`draft / not_run`。本章教你做可检查的营销决定；不承诺客户、活动结果或因果关系。

## 问题

没有产品、受众、定位、证据和目标行动，营销就会变成空话。若还没弄清数据会改变什么决定，就收集个人资料或自动发布，风险会更大。

先写版本化产品上下文，再提出假设，决定最小有用测量，最后才在隐私和授权边界内制作内容或采取行动。

## 产品上下文和决策

记录产品与版本、非目标、纳入和排除的受众、问题与使用情境、替代方案、差异化与已有证据、异议、去标识化用户原话、语气、禁用表述、期望行动、渠道、地区、日期、负责人和复核。没有证据的陈述只能保留为假设，或删去。

在看指标前，先写决定、假设、最小问题、事件和指标、分母、样本、时间窗、分群、重复、缺失数据、延迟、同意、保留期、访问范围、停止规则和下一步行动。“B 的点击更多”若没有曝光量、分母、人群和时间范围，什么也说明不了。

| 能力 | 交付物 | 边界 |
|---|---|---|
| 产品上下文 | 上下文与主张台账 | 事实、假设、负责人、复核 |
| 定位 | 面向受众和异议的版本 | 证据、语气、禁用主张 |
| 实验 | 假设、曝光和停止规则 | 样本、分母、同意 |
| 分发 | 草稿或沙盒批次 | 渠道、批准、回滚 |

## 隐私、归因与授权

Agent 可以整理上下文、起草版本、检查事件名、解释描述统计；它不能自行推断因果、掩盖样本偏差，或未经单独批准发布到广告、CRM、邮件或社交渠道。外部写入要有测试账户或沙盒、人工批准、批次标识以及撤回或回滚方式。

姓名、完整邮件和 IP、私人对话、跨情境标识符不应成为默认输入。优先汇总、去标识化、短保留和最小访问。检查重复、缺失、时区、延迟、机器人流量和分母漂移；一张漂亮图表不能把脆弱数据变成证据。

## 小练习与边界

用一个没有证言、库存或指标的虚构产品，配合只有计数值的本地表格。比较“写一段有说服力的介绍”和一份明确产品上下文、缺失证据、期望行动、假设、指标、分母、样本与下一决定的请求。标出无证据主张，写两种版本，但不宣布赢家或因果。

- [ ] 我在看数据前写出了要改变的决定与停止规则。
- [ ] 我能区分事实、假设和没有证据的营销说法。
- [ ] 所有外部写入都有单独授权、预览与回滚。
- [ ] 我没有把相关性、少量点击或漂亮图表写成因果。

保留请求、上下文版本、版本草稿、假设表、指标定义、样本说明、去标识化数据字典、隐私决定和下一步。没有获授权的数据、质量审查和人工复核前，练习仍是 `candidate / not_run`。

## 从内容草稿到可测决定：实验卡

先问“这次数据会让我改变什么？”而不是“怎样让数字更好看”。以虚构产品的本地介绍页为例：

```text
决定：是否继续测试“减少交接遗漏”的表述，还是改回解释设置成本的表述？
假设：在相同受众和同一页面位置下，清楚说明交接问题的版本更容易让读者请求查看样例。
唯一变化：标题和首段；不同时改价格、受众、渠道或行动按钮。
指标：完成“查看本地样例”这一明确动作的次数 / 已看到该版本的去重次数。
范围：合成或获授权的汇总计数；短时间窗；不收集姓名、完整邮箱、IP 或聊天内容。
停止：样本过小、版本同时变化、事件缺失、同意不清楚或目标组织/渠道未确认。
下一步：只报告描述性差异、缺失和限制；不宣布因果或赢家。
```

这张卡能防止一个常见错误：先让模型写十个版本、收集一堆事件，最后才决定数字意味着什么。若测量不会改变行动，就不应收集该数据。

### 主张台账：文案要有出处或边界

| 句子类型 | 可写方式 | 不能写成 |
|---|---|---|
| 已确认事实 | “此练习使用本地合成任务。” | “已有大量团队采用。” |
| 假设 | “我们正在测试这是否更容易理解。” | “它已经提高效率。” |
| 受众原话 | 经允许、去标识化且可追溯的短句 | 虚构客户引语或评价 |
| 未验证主张 | 删除，或明确写为待检验假设 | “行业领先”“最受欢迎” |

漂亮的文案不应把证据边界藏在脚注里。没有客户、完成率或外部评价时，诚实的下一步是邀请低风险试用并记录同意的反馈，而不是补写社会证明。

## 小实验：两份草稿，不做公开发布

1. 用合成产品上下文写两份介绍草稿。每份都应写明受众、问题、期望行动和没有的证据。
2. 给每个版本一个匿名标签；准备只有汇总计数的本地数据字典，说明分母、去重、时间窗和保留期。
3. 检查每句话是事实、假设还是无证据主张；删除后者。
4. 设计一个不外发的审阅：请一位测试读者在本地样例中指出他理解的行动与不确定项。记录的只是授权反馈，不是市场结果。
5. 若以后要在真实渠道测试，重新确认 host、组织、账号、受众、同意、批次、人工批准和撤回路径；它是新动作，不由这次草稿授权。

## 本章验收补充

- [ ] 我在写版本前先写明一个可能改变的决定、唯一变化、分母和停止规则。
- [ ] 我知道什么是描述性计数，且不会把它写成因果、效率提升或市场接受。
- [ ] 每项文案主张都被标成事实、假设、授权反馈或删除项。
- [ ] 没有客户证据时，我不伪造见证、规模、采用或紧迫感。
