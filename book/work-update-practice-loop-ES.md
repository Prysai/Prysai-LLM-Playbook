# Seis mensajes para practicar una actualización de trabajo sin inventar hechos

Usa solo hechos ficticios. Este ciclo de texto ayuda a revisar una actualización breve; no demuestra que sea exacta, profesional, aprobada ni apta para el trabajo real. Detente si necesitas datos privados, de clientes, laborales, financieros o de producción.

## 1. Define lector y hechos
```text
Quiero practicar una actualización de trabajo ficticia. Pregúntame por un lector, hasta tres hechos confirmados, una incógnita o bloqueo y una posible petición. No inventes avance, fechas, causas, aprobaciones ni promesas. Devuelve solo una lista breve de hechos y espera mi borrador.
```
## 2. Escribe antes de ver una versión modelo
```text
Usando solo los hechos ficticios guardados, pídeme una actualización de 60 palabras para el lector indicado. No la redactes, mejores ni añadas asunto. Cuando responda, conserva mi primer intento exactamente como está.
```
## 3. Encuentra una carencia importante
```text
Compara mi primer intento con esta comprobación: el lector encuentra los hechos confirmados, la incógnita o el bloqueo y la petición; no aparece avance ni promesa sin respaldo. Señala como máximo una carencia importante y cita las palabras. Si los hechos no bastan, di «desconocido». No reescribas la actualización.
```
## 4. Reviso con mis propias palabras
```text
Dame una sola pista parcial para esa carencia y espera mi revisión. No escribas otra actualización salvo que la pida expresamente después de intentarlo. Mantén separados mi primer intento, tu pista y mi revisión.
```
## 5. Cambia de lector
```text
Mantén exactamente los mismos hechos ficticios, pero cambia de compañero a responsable. Pídeme otra versión sin pistas; después señala qué cambió en tono, detalle y petición. No conviertas una incógnita en hecho ni digas que una versión está aprobada.
```
## 6. Guarda un recibo breve
```text
Devuelve un recibo: hechos ficticios | primer intento | una pista | revisión del aprendiz | intento para otro lector | añadidos por comprobar | incógnitas. Termina con un único estado: template_selected, practised, not_run o blocked. No afirmes más productividad, mejor escritura, preparación laboral ni retención.
```

Conserva el recibo junto a ambos borradores. Un ciclo registrado es práctica, no evaluación independiente ni prueba de que la ayuda del modelo sea correcta.
