# Biblioteca de evidencia y términos

Esta página mantiene legible la ruta de aprendizaje sin perder el límite de la evidencia. Las páginas del curso llegan aquí en vez de llevar a la persona lectora a un registro técnico de investigación o gobierno escrito para mantenimiento.

Es una guía de evidencia, no un sustituto del registro original. Una nota solo respalda el alcance que declara; no prueba resultados de aprendizaje, comportamiento actual del producto, calidad del modelo ni seguridad general.

<a id="core-terms"></a>

## Términos centrales

Un **modelo** genera salida; una **herramienta** observa o cambia un sistema externo; un **Skill** es un método reutilizable con entradas, paradas y comprobaciones; un **Agent** es un ciclo observable de varios pasos; la **evidencia** es material que otra persona puede inspeccionar. Una plataforma nombrada no equivale automáticamente a otra.

El registro completo de términos se identifica como `CONTEXT.md`. Nombres de producto, menús, valores predeterminados, precios, límites y permisos son hechos volátiles: antes de usarlos requieren una fuente oficial fechada.

<a id="source-notes"></a>

## Notas de fuentes

| Etiqueta | Puede respaldar | No puede respaldar |
| --- | --- | --- |
| Base oficial | Un hecho fechado dentro de su alcance | Una promesa para toda cuenta o versión futura |
| Informe público | Un problema o solución reportados | Causa raíz confirmada o reproducción local |
| Fixture fijo | Un contrato local limitado | Comportamiento de modelo, alumno o producción |
| Método del proyecto | Un procedimiento propuesto y su límite | Eficacia o adopción independiente |

Los identificadores técnicos incluyen `openai-codex-baseline.md`, `field-problems-codex.md`, `prompt-patterns-for-real-work-2026-08-10.md` y `llm-mechanism-deep-dive-2026-08-10.md`. Son registros de evidencia, no capítulos adicionales.

<a id="method-and-status"></a>

## Método y estado

El ciclo durable es: definir tarea → elegir contexto necesario → fijar límite de acción → hacer la acción reversible más pequeña → inspeccionar evidencia → recuperar o entregar. Una comprobación verde valida solo su propio contrato.

`draft` indica material o evidencia sin terminar. `candidate` indica estructura y comprobaciones básicas, pero evidencia reciente insuficiente. `verified` y `production-ready` necesitan la evidencia más fuerte indicada en los registros técnicos de publicación.

## Uso práctico de una fuente

1. Escribe la decisión que necesitas tomar.
2. Lee etiqueta y fecha.
3. Registra el hecho, informe o incógnita usado.
4. Detente si hace falta observar una plataforma en vivo o nueva autoridad.

Vuelve al capítulo tras anotarlo. No conviertas una nota antigua en hecho actual sin revisar de nuevo su fuente primaria.
