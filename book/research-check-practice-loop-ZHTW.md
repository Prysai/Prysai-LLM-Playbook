# 研究核查小練習：六條有邊界的訊息

只對你能檢查的公開或已獲授權材料使用這套流程。它幫助你把一個小研究問題與證據分開；它不會瀏覽、證明來源真實、確認當前事實或替你作高風險決定。需要秘密、未授權材料、私人資料，或釋出、購買、僱傭、診斷和行動授權時停止。

## 1. 固定一個決定
```text
我需要做這個決定：[決定]。請幫我把它縮成一個可回答的問題，並寫出決定負責人、日期邊界、什麼資訊會改變決定、以及哪些內容不在範圍內。不要搜尋、推薦、排名或編造事實。只有缺少會改變決定的細節時，才問一個問題。
```
## 2. 寫下主張和來源所有者
```text
針對這個有限問題，列出最多三條關鍵主張，併為每條指定可能擁有該事實的來源型別：官方產品頁、原始研究、法律或政策、第一方資料集或具名機構記錄。說明每種來源不能證明什麼。不要編造網址、標題、引文、引用或結論。
```
## 3. 讀我提供的材料，不想象來源
```text
只使用我提供的公開或授權摘錄和連結，製作主張臺賬：主張｜直接支援｜解釋｜衝突或缺口｜訪問日期｜下一項核查。材料中沒有的都標為未知。除非連結內容就在這段對話中，否則不要說連結已被開啟。
```
## 4. 核查一句話
```text
檢查這句話是否得到我提供的材料支援：[句子]。分開寫直接支援、推斷、衝突和未知項。只引用已提供文字。支援缺失時，幫我縮小這句話，不要補上空白。
```
## 5. 尋找會改變決定的例外
```text
根據當前主張臺賬，指出一個可能改變決定的較新版本、例外或衝突來源所有者。說明它為何重要，以及還剩下哪項最小且允許的檢查。不要說研究已完成。
```
## 6. 用停止回執結束
```text
請返回研究回執：決定｜問題｜範圍｜已提供材料｜直接支援｜解釋｜衝突｜未知項｜訪問日期｜下一項核查｜停止原因。最後只能使用一個狀態：research_plan、scope_checked_for_supplied_list、blocked 或 not_run。不要把答案稱為窮盡、最新或可用於高風險決定。
```

這張回執只是有邊界的記錄，不能證明 LLM 正確完成了研究，也不能證明結論應被採取。
