# 事実を作らない業務報告：六つの練習メッセージ

架空の事実だけを使います。短い報告を確認しやすくする文字だけの練習であり、正確さ、専門性、承認、実務での利用可否を証明するものではありません。私的情報、顧客情報、雇用情報、財務情報、本番情報が必要になったら止めてください。

## 1. 読み手と事実を決める
```text
架空の業務報告を練習したいです。読み手を一人、確認済みの事実を三つまで、不明点または障害を一つ、依頼を一つ聞いてください。進捗、日付、理由、承認、約束を作らないでください。短い事実リストだけを返し、私自身の下書きを待ってください。
```
## 2. 見本の前に書く
```text
保存した架空の事実だけを使い、指定した読み手向けに60語以内の報告を私に書かせてください。下書き、改善、件名の追加はしないでください。送った後、最初の試みをそのまま保存してください。
```
## 3. 重要な抜けを一つ探す
```text
次の基準で最初の試みを確認してください。確認済みの事実、不明点または障害、依頼を読み手が見つけられ、根拠のない進捗や約束がないことです。重要な抜けを一つまで示し、該当する語を引用してください。事実だけでは決められない場合は「不明」と言ってください。書き直さないでください。
```
## 4. 自分の言葉で直す
```text
その抜けに対する部分的なヒントを一つだけ出し、私の修正を待ってください。試した後に私が明示的に求めない限り、代替の報告を書かないでください。最初の試み、あなたのヒント、私の修正を分けて残してください。
```
## 5. 読み手を変える
```text
架空の事実はまったく変えず、同僚向けから上司向けに変えてください。ヒントなしで新しい報告を書くよう求め、その後に口調、詳細、依頼の変化を示してください。不明を事実にせず、どちらの版も承認済みとは言わないでください。
```
## 6. 小さな記録を残す
```text
次の練習記録を返してください：架空の事実｜最初の試み｜ヒント一つ｜学習者の修正｜読み手を変えた試み｜確認が必要な追加事項｜不明点。最後は template_selected、practised、not_run、blocked のいずれか一つだけにしてください。生産性、文章力、実務準備、保持が向上したとは主張しないでください。
```

二つの下書きと記録を一緒に保存してください。記録された一周は練習であり、独立評価でもモデルの助言が正しい証明でもありません。
