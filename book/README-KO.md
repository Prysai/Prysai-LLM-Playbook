# Prysai LLM Playbook: 책

이 디렉터리에는 `Prysai LLM Playbook`의 독창적인 주 학습 경로가 들어 있습니다. 이 책은 여섯 개 외부 프로젝트를 이어 붙인 모음이 아니라, 학습자의 성장 순서에 맞춰 다시 구성한 콘텐츠 시스템입니다.

이 한국어 파일은 책의 한국어 핵심 입구입니다. 22개 장과 18개 Lab은 한국어 경로를 갖지만, 현재 번역 상태는 `in-progress`이며 독립 언어 감수와 학습자 실행 증거는 아직 없습니다.

## 한국어로 할 수 있는 두 가지 첫 실습

텍스트 채팅만으로 시작하고 싶다면 [초보자 연습 카드](communication-clinic-KO.md)를 여세요.
언어, 업데이트, 판단, 조사, 출처 확인, 공유 전 경계에 쓸 수 있는 일곱 가지 복사 가능한 메시지가 있습니다.
이 경로는 `draft / not_run`이며 유창함, 효율 또는 학습 효과를 약속하지 않습니다.

바로 하나만 해 보고 싶다면 [업무 업데이트 여섯 단계 연습](work-update-practice-loop-KO.md)이나 [리서치 확인 여섯 단계 연습](research-check-practice-loop-KO.md)을 고르세요. 자신의 첫 답변, 하나의 제한된 수정, 기록을 남기는 연습일 뿐 생산성, 조사 품질, 업무 준비도를 증명하지 않습니다.

아직 프로젝트가 없고 AI가 채팅 밖에서 행동하게 하고 싶지 않다면 먼저
[범용 LLM 첫 과제](routes/universal-core-foundations-KO.md)를 해보세요. 가상의
안내문을 다시 쓰며 확인 방법과 중단 지점을 분명히 합니다. 이것은
`candidate / not_run` 연습이며 학습 효과나 플랫폼 간 동일한 동작을 증명하지
않습니다.

설치를 찾거나 자신의 프로젝트를 사용하기 전에
[첫 번째 안전한 변경](routes/first-safe-change-KO.md)을 진행하세요. 폐기 가능한
로컬 복사본, 하나의 허용된 편집, 관찰 가능한 수용 조건으로 이루어집니다. 이
경로는 `in-progress` 번역이며 독립 언어 검토나 학습자 실행을 주장하지 않습니다.

관련 입구: [한국어 서문](preface-KO.md) · [프로젝트 한국어 README](../README-KO.md)

## 각 장에 필요한 구성

각 장에는 다음 항목이 함께 있어야 합니다.

- 학습 목표
- 핵심 개념
- 최소 실행 가능 실험
- 의도적으로 실패시키는 실험
- 전이 과제
- 수용 증거
- 현재 사실과 출처
- 업데이트 상태

장 초안은 주 학습 경로에 들어오기 전에 평가 프레임워크의 최소 문턱을 통과해야 합니다. 프레임워크는 공유 거버넌스 자료로 원문을 유지하며, 이 한국어 독자 경로에서는 번역된 본문처럼 제시하지 않습니다.

## 현재 읽기 입구

19–22장을 포함한 22개 장은 `candidate` 상태입니다. [한국어 책 목차](table-of-contents-KO.md)에서 각 장의 실제 문제 사례, 평가 fixture 규격과 연구 기록으로 이동할 수 있습니다.

정식 `evals/task-set-v1.yaml`은 16개 트랙을 덮는 40개의 고정 fixture를 담고 있지만, 아직 모델 실행 로그가 없습니다. 따라서 이것을 완료된 평가로 읽어서는 안 됩니다. 이 파일은 공유 평가 자료의 영어 원문이며, 한국어 교과 본문이나 완료된 평가로 제시하지 않습니다.

L3 관통 연습은 [실험 013: 감사 가능한 수직 슬라이스](labs/lab-013-l3-vertical-slice-KO.md)에서 시작합니다. 이 실험은 프로토콜, 기준선, 체크포인트, 검증, 의도적 실패와 전이를 하나의 저위험 경로에 배치합니다.

## 링크와 언어 상태

한국어 페이지의 원칙은 다음과 같습니다.

1. 같은 콘텐츠 ID의 한국어 파일이 있으면 `-KO` 파일을 우선 연결합니다.
2. reader-facing 경로는 다른 언어로 자동 이동하지 않습니다.
3. locale-neutral 거버넌스와 출처 기록은 링크 문구에서 그 성격을 밝힙니다.

목차, 22개 장과 18개 실험은 모두 `-KO` 경로를 사용합니다. 평가와 연구 기록은 locale-neutral이며, 이 사실은 번역 완료나 학습 효과의 증거가 아닙니다.

## 책을 읽는 방법

처음부터 순서대로 읽어도 되고, 실제 작업에서 바로 들어와도 됩니다. 각 장은 같은 폐쇄 루프를 따릅니다.

```text
문제 → 개념 → 판단 → 작업 → 증거 → 실패 → 회고 → 전이
```

장의 “실험”은 시연 영상을 대신하는 것이 아닙니다. 학습자가 직접 완료해야 하는 최소 작업입니다. 실험에서는 결과, 차이, 로그, 출처, 스크린샷 또는 회고를 남기게 합니다. 그래야 읽기가 역량으로 바뀝니다.

## 정말 배웠는지 판단하는 방법

이 프로젝트는 “출력이 보기 좋다”는 것을 숙련 기준으로 사용하지 않습니다. 하나의 역량에는 적어도 네 종류의 증거가 필요합니다.

- 자신의 말로 개념과 경계를 설명할 수 있어야 합니다.
- 실제 또는 저위험 환경에서 작업을 완료할 수 있어야 합니다.
- 왜 이 모델, 도구, Skill 또는 권한을 선택했는지 설명할 수 있어야 합니다.
- 오류, 위험, 환각, 미완료 항목 또는 오래된 사실을 찾아낼 수 있어야 합니다.

결과만 보여 주고 과정과 증거를 설명하지 못한다면, 한 번의 연습을 완료했을 수는 있지만 방법을 습득했다고 볼 수는 없습니다.

## 현재 콘텐츠 상태에 대한 정직한 표기

- 책의 19–22장: `candidate`; 학습자와 모델 실행 증거는 별도로 `not_run`
- 평가 작업 세트: 40개 fixture와 16개 트랙 구조 제출, 모델 실행 로그 없음
- 한국어 책 경로: 22개 장, 18개 Lab, 두 개의 입문 경로와 연습 카드 제공
- 한국어 전체 책: 파일 경로는 완성, 독립 감수는 진행 전
- 번역 검토·브라우저 검증·모델 실행: 이 변경에서 수행하지 않음

파일이 존재하거나 링크 검사가 통과했다고 해서 초안이 검증 완료, 생산 준비 완료 또는 번역 감수 완료가 되는 것은 아닙니다.
