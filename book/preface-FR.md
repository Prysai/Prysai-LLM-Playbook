# Préface : ce livre n’est pas un catalogue de prompts

La première question est souvent : « Que dois-je dire à l’IA ? » Une bonne
méthode commence pourtant avant la phrase : quel résultat voulez-vous, quelles
données fournissez-vous et comment saurez-vous que la réponse tient la route ?

Ce livre sépare le modèle, le produit, les outils, les Skills, les Agents et
les effets externes. Codex est la route pratique la plus développée, mais la
méthode — définir, agir dans une limite, inspecter, conserver une preuve et
déclarer les inconnues — est conçue pour d’autres LLM.

Chaque chapitre suit :

```text
problème → concept → décision → action → preuve → échec → réflexion → transfert
```

Lire une page n’est pas une preuve de maîtrise. Un lecteur doit pouvoir
expliquer le concept, réaliser une petite tâche, justifier ses choix et revoir
une erreur. Les essais de ce dépôt restent `candidate` ou `not_run` tant qu’un
enregistrement réel ne les soutient pas.

Commencez par [les bases des LLM](guides/llm-fundamentals-FR.md), puis la
[première tâche sûre](routes/universal-core-foundations-FR.md). Les routes
Codex, les Skills et les exercices d’application viennent ensuite.

Cette version française est une traduction en cours et attend une relecture
indépendante par une personne francophone.
