# 最初の安全な変更：Lab 001 の前に行うオフライン練習

**コンテンツ状態：** 補助ルート `candidate`。**学習者の実行：** `not_run`。
**翻訳状態：** 日本語の全体ドラフト。独立した言語レビューはまだ行っていません。

これは第 2 章と Lab 001 の間に置く、初心者向けの標準サンドボックスです。
意図的に不完全な README、一つだけ許可されたローカル変更、そして範囲を絞った
検査を用意してから、自分のプロジェクトへ進みます。第 23 章、新しい
Skill、Git の練習、またはモデルが何かを完了した証拠ではありません。

初めてプロジェクトフォルダーを開く、あるいは検査を実行するなら、まさに
そのためにこのルートがあります。何かをインストールしたり、アカウントを
作ったり、本物のプロジェクトを危険にさらしたりする必要はありません。
関連するファイルをすべて見渡し、検査が本当に質問に答えているかを自分で
判断できる大きさまで、対象を絞ります。

## 問題

Lab 001 では、破棄可能なプロジェクト、実際のコマンドの出典、範囲を限定
した README の変更を求めます。実際のプロジェクト向けには良い条件ですが、
初めての実践では循環に感じられます。新しい読者には安全なプロジェクトが
まだなく、どのコマンドの出典を信頼すべきかも分からないからです。

## 概念

フィクスチャは、*方法を練習すること* と *適切なプロジェクトを探すこと*
を分けます。これは練習用に合成されたもので、ローカルで扱えて、破棄できます。想定する内容
変更は README の修正だけで、チェッカーもその一つのファイルだけを読み、
小さな結果を返します。そのため、アカウント、ネットワーク、インストール、
Git、commit、push、公開、個人データなしで、受け入れ条件を確認できます。

## 判断

まだ破棄可能なローカルプロジェクトがないときは、このプロジェクトの
[最初の安全な変更フィクスチャ](../../examples/lab-001-v1/README-JA.md)を使います。
フィクスチャ全体を `.work/` か別の一時場所にコピーしてください。元の
フィクスチャを編集すると、次の読者のための意図的な誤りが失われます。

## 操作

まず、個人用の作業コピーを作ります。ファイルマネージャーで
`examples/lab-001-v1` フォルダー全体を捨てられる場所にコピーし、コピーを
`first-safe-change` と呼びます。

続いて、次の二つの検査から一つを選びます。

1. **プログラムを実行しない検査（標準）。** コピーの中で
   `seed/README.md` と `expected/acceptance.json` を開きます。編集前の README
   には、必須のプレビュー情報が二つ欠けています。一回だけ許可された
   README の編集後、受け入れファイルの `required_readme_strings` に書かれた
   三つの文字列すべてが README に見えることを確認します。
2. **任意のローカルチェッカー。** 自分のコンピューターで Python 3 がすでに
   動くときだけ使います。コピーしたフォルダーでターミナルを開き、次を
   実行します。

```powershell
python .\seed\verify_readme.py
```

最初に実行したチェッカーの結果は `FIRST_SAFE_CHANGE_FAILED` になるはずです。これは
意図された開始状態であり、壊れたインストールではありません。フィクスチャ
README のタスクカードに従って `seed/README.md` を確認し、最小の変更を提案
します。計画を自分で承認してから **その README だけ** を編集します。同じ
手動検査または任意コマンドを繰り返します。任意チェッカーの合格結果は
`FIRST_SAFE_CHANGE_OK` です。

Python が使えない場合、このルートのためだけに実行環境を入れたり別の
コマンドで代用したりしないでください。プログラムを実行しない検査を使い、
`check: manual required_readme_strings 3/3` と記録します。破棄可能なローカル
コピーも作れないなら停止し、テキストだけの First Win を使います。GitHub の
Web 表示をローカルサンドボックスだと扱ってはいけません。

## Web coding への橋渡し：実ブラウザーで一つの表示変更を確認する

次に Web coding を試すときも、「完全なサイトを作って」と始めないでください。
プロジェクトの [Product Context サンドボックス](../../examples/skill-sandbox/product-context-real-estate/README-JA.md)
を使い捨ての静的ページとして使います。架空の文面だけで、実在の物件、フォーム、
分析、API、外部画像はありません。

1. `examples/skill-sandbox/product-context-real-estate` フォルダー全体を一時場所へ
   コピーし、README と `index.html` を読みます。
2. **`index.html` だけ**を変更します。同じ架空の読者向けに、表示される一文を
   置き換えます。CSS、フレームワーク、画像、フォームは追加しません。
3. Python 3 がすでに使える場合だけ、コピー先で記載されたローカルサーバーを
   起動します。

```powershell
python -m http.server 4182
```

ブラウザーで `http://127.0.0.1:4182/` を開きます。タイトル、変更した文、変更
していない見出し、リンク先、コンソール、幅 390px の表示を確認します。コマンド、
対象ファイル、ブラウザー結果が不明なら停止し、この練習だけのためにランタイムを
インストールしません。

短い記録を残します。

```text
sandbox: <コピー先>
allowed_change: index.html only
url: http://127.0.0.1:4182/
browser_check: 新しい文は一度だけ；見出しとリンクを保持；コンソールを観察
diff: <確認済み差分>
unverified: デプロイ、アクセシビリティ審査、他ブラウザー、利用者の受入れ
```

これは一つの幅で一度レンダリングした状態を確認しただけです。本番ビルド、すべての
レスポンシブ状態、アクセシビリティ、セキュリティ、性能、製品価値は示しません。全体の
工程は [第 16 章](../chapters/16-engineering-track-JA.md) へ進んでください。

## 証拠

保存するのは、この短いレシートだけです。

```text
sandbox: <作業コピーのパス>
baseline: FIRST_SAFE_CHANGE_FAILED
allowed_change: seed/README.md only
diff: <確認済みの README 差分>
check: manual required_readme_strings 3/3 | FIRST_SAFE_CHANGE_OK
external_actions: none
unverified:
  - learner completion
  - model behavior
  - transfer
```

チェッカーが示せるのは、ある時点でこの固定の練習用 README が宣言された文字列
に一致することだけです。チェッカーの成功は、Git 操作、ブラウザー、アカウント権限、
セキュリティレビュー、または方法を身につけたことを示しません。

## 失敗と境界事例

合格するためにチェッカー、受け入れファイル、別のパスを編集しないでください。
提案した修正にインストール、ネットワーク要求、秘密情報、アカウント、
リポジトリ操作、または二つ目のファイルが必要なら停止します。それはこの
フィクスチャの範囲ではなく、新しい判断です。

## 振り返り

1. 編集前に受け入れ条件のどの部分を観察できましたか。
2. 最終差分は何を示し、自信のある「完了」メッセージでは何を示せませんか。
3. 実プロジェクトで Lab 001 に同じ型を使う前に、どの事実を確認する必要が
   ありますか。

## 続ける

次の学習単位は[Lab 001：安全な README 変更を一つ行う](../labs/lab-001-first-safe-task-JA.md)です。
Lab は日本語の候補として利用できますが、状態は `draft / not_run` のままです。このルートは
それ自体で完結した練習です。黙って別言語へ移動したり、英語の原文を日本語
翻訳が完成しているかのように示したりしません。

## 状態と限界

このルートは学習者について `candidate / not_run` のままです。リポジトリーの
テストはフィクスチャの形と、チェッカーが宣言する合格/不合格の動作だけを
検査します。学習者を観察せず、Codex や他のモデルを呼び出さず、製品比較や
転移を立証せず、実プロジェクトのコマンドも検証しません。
