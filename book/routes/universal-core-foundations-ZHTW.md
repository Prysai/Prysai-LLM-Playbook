# 通用 LLM 協作：先做一個安全的小任務，再掌握四個基礎

狀態：`candidate`。執行狀態：`not_run`。

如果你想先用一般文字聊天完成一件小事，還沒必要研究特定平台的設定，就從這裡開始。下面的第一次練習可以直接在文字聊天裡完成；它不會把 ChatGPT、Claude、Grok、Gemini、Codex 或其他產品當成同一種產品。這條路線只整理一套跨平台都能用的基本判斷：把任務說清楚、只提供必要材料、寫明如何檢查，並設定停止條件。它不表示各個平台共享工具、權限、記憶、帳號、價格或 Agent 行為。

## 現在就做一個安全的小任務

只使用下面這則虛構通知。不要貼上私人聊天、客戶資料、密碼或權杖、尚未公開的內容或真實檔案。這次練習不需要瀏覽、呼叫工具、上傳檔案、變更帳號、傳送或發布內容。

把下面這段請求複製到你選擇的文字聊天中：

```text
目標：把這則虛構社團通知改寫給新成員看。
材料：“社團每週二 6 點見面。請帶一本筆記本。房間稍後確認。”
輸出形式：寫兩句話。保留已經說明的全部事實；缺失的細節用 [方括號] 標出。然後列出你保留了哪些事實。
檢查：把原文和改寫放在一起對照。不得加入原文沒有的時間、房間、費用、聯絡人或承諾。
停止：不要瀏覽、傳送、釋出，也不要猜測未知細節。
```

接著自己檢查三件事：

1. 改寫中的每個說法，都能在原通知中指出依據嗎？
2. 回答是否遵守「兩句話」的限制，並列出保留的事實？
3. 有沒有把應該維持未知的細節寫成事實？

若第三題回答「有」，就刪掉新增的細節，或只要求它修正這一處。如果聊天工具主動提議搜尋、傳送、發布內容或呼叫工具，或要求提供這項練習不需要的材料，先停下來。回答讀起來順，不代表其中的事實正確，也不代表這套方法已在每個平台上驗證過。

這是 `candidate` 階段的練習，不是萬能提示詞，也不是成效結論。它沒有跨模型執行、學習者表現或成效證據。想多練幾張文字聊天起步卡，可以閱讀[新手提示卡：把話說清](../communication-clinic-ZHTW.md)。

## 接著用四個基礎單元理解剛才的練習

完成一次嘗試後，讀下面四個單元，理解為什麼小任務也需要目標、材料、檢查和停止條件。任務不再只是文字對話時，這四個判斷會更重要。

1. [**把一個想法寫成任務契約**](../chapters/03-task-protocol-ZHTW.md#core-task-contract)——寫明結果、相關背景、行動邊界、驗收、停止規則和交接方式。
2. [**讓主張對應證據，並在界線內復原**](../chapters/09-verification-and-recovery-ZHTW.md#core-evidence-recovery)——先驗證眼前這個最小主張；第一層證據不足時就停下來。
3. [**規劃一個能留下證據的最小工作切片**](../chapters/10-planning-and-slicing-ZHTW.md#core-evidence-bearing-slice)——選出他人可以檢查、也能繼續完成的最小結果。
4. [**分清能力、授權、確認與證據**](../chapters/13-action-boundaries-ZHTW.md#core-action-boundary)——能做不代表獲准去做；獲准也不代表已經完成或已有證據。

特定產品的操作放在對應的平台適配器裡；特定領域的練習放在應用路線裡，不和基礎主線混在一起。

## 先練習一個檢查邊界，再選平台

本路線配套的[通用邊界固定練習](../../examples/universal-seam-v1/README-ZHTW.md)包含四筆虛構紀錄，分別對應「與最新請求不一致」、「目標不正確」、「缺少工具執行紀錄」和「結構化值遭到修改」。針對每筆紀錄，先指出眼前文字無法證明什麼，再選擇最小且安全的檢查；一旦需要真實平台行為，就先停下來，等平台適配器說明。練習說明會維持在繁體中文路徑；固定資料仍是共用的虛構教材。

![四個證據邊界：任務身分、目標身分、執行紀錄與結構化往返；每一項最後都要檢查或停下來。](../../assets/teaching/universal-seams-red-black.svg)

這項練習的驗證器只檢查固定虛構紀錄是否一致：`verified_in_fixture` 不等於產品實際執行，`not_run` 不代表有執行證據；要從 `inferred` 進入真實診斷，仍需要平台適配器。這項練習不會新增章節、實驗、Skill、模型評估或相容性結論。

## 這條路線能證明什麼

這張路線圖只能證明：教學歸屬明確、錨點穩定、引用有效、相依關係沒有循環、路線投影夠精簡。練習驗證器也只會檢查自己的資料契約。兩者都不能證明平台行為、學習者表現或遷移效果、安全結果，或真實產品執行。
