# First mapped universal LLM collaboration units

**Status:** `candidate`. **Run status:** `not_run`.

Use this route when the model or product may change but the work still needs a
clear task, bounded action, inspectable evidence, and a recoverable plan. It is
an index into the first four mapped canonical teaching ranges. It is not yet a
complete universal curriculum: context selection, reuse, evaluation, and team
governance still need bounded owners, neutral labs, and transfer evidence. It
does not duplicate these lessons and does not claim that every platform
implements tools, permissions, memory, or Agent behavior in the same way.

1. [Turn an intention into a task contract](../chapters/03-task-protocol-EN.md#core-task-contract) — define the result, relevant context, action boundary, acceptance, stop rule, and hand-off.
2. [Match claims to evidence and recover in bounded order](../chapters/09-verification-and-recovery-EN.md#core-evidence-recovery) — test the narrow claim and stop at the first unsupported layer.
3. [Plan one evidence-bearing slice](../chapters/10-planning-and-slicing-EN.md#core-evidence-bearing-slice) — choose the smallest outcome another person can inspect and continue.
4. [Separate capability, authorization, confirmation, and evidence](../chapters/13-action-boundaries-EN.md#core-action-boundary) — keep a possible action distinct from an allowed or verified action.

Named-product instructions belong in a platform adapter. A domain-specific
exercise belongs in an application route. Neither should copy these core
ranges merely to appear self-contained.

## What this route proves

The route and its validator prove only that every unit has one owner, stable
anchors, valid consumers, acyclic dependencies, and link-only projection. No
cross-platform run, learner run, retention test, or transfer test is recorded.
