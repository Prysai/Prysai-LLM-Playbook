你不需要從第一張開始。只選今天最接近的一類：想把工作說清楚時先看 B；想核對一項主張或分享邊界時看 C；只有想練外語時才看 A。

## A. 可選外語練習（只在你想練西班牙語時使用）

### 1. 可選外語示例（西班牙語）：先自己開口，再要糾錯

預期：先保留你的原句，再拿到一條有限、可檢查的糾錯。不要讓模型一開始就替你完成對話。

```text
我想用虛構資訊練習用西班牙語確認學習小組的時間。請只扮演同學，不要示範答案。

條件：可用資訊是 [Ana、學習小組、週二或週四、6:00 或 6:30、圖書館或線上、帶一個問題]。
目標：我會先用西班牙語寫一句不超過 12 個詞的話。

等我回復後，請：
1. 只指出最影響理解的一處問題；
2. 用中文解釋原因；
3. 給我一個提示，不直接替我重寫整句；
4. 等我自己改寫。
```

### 2. 西班牙語：把同一能力換一個場景

預期：練習“提出一個簡單請求”，而不是背上一輪的標準答案。

```text
繼續剛才的練習，但把場景改成確認作業計劃：我要問我該準備哪一部分，並澄清初稿是週二還是週四交。
請不要複用我的原句，也不要先給提示。

先讓我自己寫一句。我的句子出現後，請按“能否被對方理解”給出透過 / 需要修改，
並最多指出一處需要修改的地方。不要把這次結果稱為流利、掌握或語言等級。
```

## B. 推薦從這裡開始：工作表達與判斷

### 3. 工作表達：把散亂要點變成可傳送的更新

預期：同一批事實可以有不同語氣；模型不能替你補出不存在的進度。

```text
請把下面的工作要點整理成一條發給 [同事 / 客戶 / 負責人] 的更新。

原始要點：
- [事實 1]
- [事實 2]
- [仍不確定的事]

要求：
- 先列出你從原始要點中能確認的事實；
- 不要補充日期、承諾、完成狀態或原因；
- 給出一個不超過 120 字的版本和一個更正式的版本；
- 最後列出我傳送前必須自己確認的兩件事。
```

### 4. 工作判斷：先問清楚，再給建議

預期：當關鍵條件缺失時，一個好回覆會先暴露未知，而不是裝作已經知道答案。

```text
我需要在 [選項 A] 和 [選項 B] 之間做一個小決定。
我的目標是：[目標]。
目前知道：[事實]。
目前不知道：[未知]。

請不要直接替我決定。先問最多三個會改變結論的問題；
然後給我一個兩列表格，分別寫“現有證據支援什麼”和“仍不能判斷什麼”。
如果缺少關鍵事實，請明確建議我暫停，而不是猜測。
```

## C. 研究與分享前核查

### 5. 研究起步：把“大問題”縮成一個可核查的問題

預期：你先得到研究計劃，而不是一篇看起來很完整、卻無從核查的結論。

```text
我想弄清這個問題：[問題]。
這個問題將幫助我做出的決定是：[決定]。
我目前只接受這些來源型別：[例如官方文件、論文、機構報告]。

請不要回答這個問題，也不要編造來源。
請幫我寫出：
1. 一個更小、可核查的問題；
2. 第一條需要核查的主張；
3. 該主張最可能的來源所有者；
4. 找不到來源時的停止條件。
```

### 6. 研究核對：讓來源支援一句具體的話

預期：連結存在不等於它真的支援你的結論；模型的任務是幫助你準備核對表。

```text
我要檢查下面這句話是否被我提供的材料支援。

主張：[一句具體的話]
材料摘要或原文摘錄：[只放你有權分享的公開內容]
來源連結或出處：[連結 / 書目]

請把結果分成三欄：
- 材料直接支援的部分；
- 材料沒有說明或與主張不一致的部分；
- 我需要親自開啟原始來源再核對的部分。

不要把沒有開啟過的連結稱為已驗證，也不要補寫缺失事實。
```

### 7. 分享前檢查：先縮小內容和物件，再決定是否傳送

預期：先分清“我想分享什麼”和“我被允許分享什麼”。這張卡只幫你整理判斷，不會替你上傳、傳送或公開內容。

```text
我考慮分享一段 AI 回答或聊天摘錄。
我想達到的目的：[例如請同事核對一段措辭]。
可能的收件人：[角色或群體]。
我準備分享的內容：[一句話描述，不貼秘密或私人資料]。
我明確不會分享：[客戶資料、密碼、完整聊天記錄、未公開檔案等]。

不要傳送、上傳或生成連結。請先給我：
1. 這次目的所需的最小摘錄；
2. 傳送前必須由我確認的物件、內容和授權；
3. 哪些未知情況應讓我停止，而不是預設可以分享。
如果我沒有說明收件人或授權，請只建議暫停並補充哪一項。
```

## 先選一條路，不要一次做完全部

如果你還沒決定今天要做什麼，不必先要求一大段回答。只在「練一項技能」、
「整理工作更新」或「核對一項主張」中選一項，做一次短嘗試並留下簡短紀錄。
這張入口卡不是診斷，也不是完整課程。

<span id="request-escalation"></span>

### 先說清楚你需要哪種幫助

```text
我今天要得到的一個小結果：[可觀察的結果]
可以使用的資訊：[事實、文字或我提供的連結]
請先做哪一件事：[改寫／提問／安排練習／列出核查步驟]
不要補寫我沒有提供的事實，不要開啟連結，也不要進行外部操作。
如果缺少必要輸入，請指出缺少什麼並停止。
```

「查最新資料」和「修改公開頁面」不要混在同一個請求裡。先核對來源，
再另外寫出包含目標、對象、授權和復原方式的行動協議。有引用不代表有發布權限。

<span id="first-practice-intake"></span>

### 把大的願望縮成第一次嘗試

```text
我的願望是：[例如「學會西班牙語」]
請一次只問一個問題，直到它變成一項大約十分鐘內可以安全嘗試的練習：
1. 我實際要做的動作
2. 我先自己嘗試什麼
3. 我接受哪種幫助（問題、提示、例子或檢查）
4. 我會親自核對什麼
5. 卡住時可以改用的更小版本
不要把一次練習稱為掌握、流利或能力證明。
```

<span id="four-line-safety-card"></span>

## 進階：分享、搜尋或操作前先寫下界限

只要涉及外部資料、檔案、工具或帳號，就先填這張卡。它不會授予任何權限；
有欄位空白時應該停止，而不是猜測。

```text
目標，以及這次不會做的事：
可以讀取的輸入及其來源：
可能被修改的確切檔案或物件：
不會讀取、傳送或儲存的資料：
預期結果與可檢查的驗收證據：
停止條件：路徑、授權、來源或證據不清楚時停止。
```

<span id="share-check"></span>

### 分享前先縮小內容和對象

```text
我考慮分享的內容：[用一句話描述，不要貼上秘密]
目的：[誰要核對什麼]
可能的對象：[角色或群組]
請列出達成目的所需的最小摘錄，以及我必須親自確認的內容、對象、授權和傳送管道。
不要傳送、上傳或建立連結。
如果對象、授權或內容界限有任何一項不清楚，請指出缺少的項目並停止。
```

## 進階：檢查可能影響他人的 AI 想法

涉及招聘、教育、醫療、住房或福利的想法，先用虛構案例，不要放入真實個人資料。

```text
假設一個虛構系統協助[角色]做出[一個決定]。
請分開列出：誰可能受益或受損；需要的最少資料；人可以在哪裡覆核或申訴；
哪些證據能支持決定；以及出現什麼訊號時必須停止。
不要設計部署方案、不要呼叫服務，也不要把模型建議寫成事實。
```

<span id="general-skill-practice-route"></span>

## 路線 B：練習一項可觀察的技能

```text
我想練習：[解釋一個概念／回答面試問題／做簡報]
請先讓我在[分鐘]內自己完成一次，不要先給範例答案。
完成後只檢查：目標是否清楚、依據是否足夠、聽眾是否知道下一步。
指出最影響結果的一個問題，再給我一個條件不同的情境重做。
不要替我編造經歷，也不要把一次表現稱為掌握。
```

<span id="bounded-research-route"></span>

## 路線 C：為一個決定做有範圍的研究

```text
我要做的決定：[決定]。適用的日期、地區和版本：[範圍]
請先寫出一個可核查的問題、三種優先來源和停止條件。
每項主張都記下來源負責人、原始與目前的 URL、位置、日期、適用範圍和未解之處。
不要把搜尋摘要、論壇經驗或尚未開啟的連結當作已驗證證據。
```

<span id="source-check-route"></span>

### 讓一句話和原文對得上

```text
主張：[一句具體的話]
原始來源或獲准分享的摘錄：[內容]
請分成：原文直接支持的部分、原文沒有說或與主張矛盾的部分、我仍需親自開啟核對的部分。
如果找不到對應段落，標記 citation_unverified，並縮小結論的範圍。
```

<span id="recovery-route"></span>

## 進階：回答跑題時只改一個條件

保留原始請求、可見的上下文、實際收到的回答和原本期待的結果。只改一個溝通條件，
例如先列出輸入或固定輸出格式，再做一次低風險比較。如果需要檔案、權限、網路或外部
操作，就重新寫出界限並停止。

<span id="card-e1-user-declared-continuity-receipt"></span>

### 開始下一輪前留下連續性紀錄

```text
原始任務與不變的限制：
上一輪實際讀取或完成的輸入：
上一輪可驗證的輸出：
仍未知、失敗或尚未執行的部分：
這一輪唯一要改變的條件：
停止條件，以及負責核對結果的人：
```

這是使用者宣告的上下文，不是模型記憶或授權證明。它不會自動把新的帳號、分支、
儲存庫或對象納入原本的授權範圍。

## 只做四步，別把第一次練習做複雜

1. 選一張與今天最接近的卡。
2. 先寫出你自己的短嘗試，或填入你已知的事實。
3. 把回答和你的原始版本並排看，檢查它是否越過了你的限制。
4. 留下一個最小記錄：任務、原始嘗試、使用的幫助、你最終保留的版本、仍未知的部分。

如果模型給出的是完整答案而你本來想練習，請要求它退回到“一條提示”；如果它編造事實、來源或承諾，請停止使用該回答，並把未核查部分保留為未知。

## 練習紀錄：把一次對話留下來

完成任意一張卡後，只保留這一小段記錄。它讓你下次能看清自己練了什麼，也讓“我覺得有用”不至於被寫成沒有證據的結論。

```text
任務：
我的第一次嘗試或已知事實：
AI 提供的幫助（提示 / 糾錯 / 資料規劃）：
我保留的版本：
我親自檢查的內容：
仍未知或有爭議的內容：
狀態：template_selected | practised | not_run | blocked
```

`practised` 只表示儲存了一次有記錄的練習；它不表示流利、掌握、效率提升或來源已被完整驗證。

## 這次練習算完成了嗎？

完成一張卡，最多隻能說明你儲存了一次帶條件的嘗試。若想說“我在這項任務上表現出來了”，還需要預先寫好的標準和可檢查的結果；若要談保持或遷移，還需要延遲和變式任務。當前這七張卡都沒有 Prysai 學習者執行、獨立評分或跨模型比較證據。

這是一組中文起步卡，獨立語言審校仍待完成；它不是“萬能提示詞”。它沒有跨模型執行記錄，不能證明效率提升、學習效果、模型優劣或各平臺行為相同。涉及檔案、工具、瀏覽、賬號、外部發布或真實資料時，先停下並轉到相應的有來源平臺說明。

- [ ] 我只使用了虛構、公開或獲授權的文字。
- [ ] 我在收到完整答案前留下了自己的嘗試或已知事實。
- [ ] 我檢查了模型是否新增了事實、承諾或來源。
- [ ] 我知道本次結果不能證明效率、掌握、流利或模型優劣。
- [ ] 需要檔案、瀏覽、外部行動或敏感資料時，我已經停止並換到有邊界的流程。
