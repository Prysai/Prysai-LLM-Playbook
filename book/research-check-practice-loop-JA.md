# 範囲を決めたリサーチ確認：六つのメッセージ

自分で確認できる公開資料または許可された資料だけに使ってください。小さな問いと証拠を分けるためのもので、閲覧、情報源の真偽証明、最新事実の確認、高影響な決定は行いません。秘密、無許可の資料、個人データ、公開・購入・採用・診断・行動の許可が必要なら止めてください。

## 1. 一つの決定を固定する
```text
私はこの決定をする必要があります：[決定]。これを答えられる一つの問いにしてください。決定の責任者、日付の境界、決定を変える情報、範囲外を示してください。検索、推奨、順位付け、事実の創作はしないでください。決定的な詳細が欠ける場合だけ質問を一つしてください。
```
## 2. 主張と情報源の所有者を挙げる
```text
範囲を決めた問いについて、重要な主張を三つまでと、それぞれを持ちうる情報源の種類を挙げてください：公式製品ページ、一次研究、法律または方針、第一者データセット、名称のある機関記録。それぞれが証明できないことも示してください。URL、題名、引用、結論を作らないでください。
```
## 3. 与えた資料を読み、想像上の資料を使わない
```text
私が提供する公開または許可された抜粋とリンクだけを使い、主張台帳を作ってください：主張｜直接の裏付け｜解釈｜矛盾または不足｜アクセス日｜次の確認。資料にないものは不明としてください。内容がこの会話にないリンクを開いたとは言わないでください。
```
## 4. 一文を確認する
```text
この正確な一文が提供資料に支えられているか確認してください：[文]。直接の裏付け、推論、矛盾、不明を分けてください。提供された文だけを引用してください。裏付けがなければ穴を埋めず、文を狭めるのを手伝ってください。
```
## 5. 決定を変える例外を探す
```text
現在の主張台帳について、決定を変えうる新しい改訂、例外、または矛盾する情報源の所有者を一つ挙げてください。重要な理由と、残る最小の許可された確認を示してください。調査が完了したとは言わないでください。
```
## 6. 停止の記録で終える
```text
次のリサーチ記録を返してください：決定｜問い｜範囲｜提供資料｜直接の裏付け｜解釈｜矛盾｜不明｜アクセス日｜次の確認｜停止理由。最後は research_plan、scope_checked_for_supplied_list、blocked、not_run のいずれか一つだけにしてください。答えを網羅的、最新、高影響な決定に使えるとは言わないでください。
```

この記録は範囲を決めたメモであり、LLM が正しく調査したことや結論に従って行動すべきことの証明ではありません。
