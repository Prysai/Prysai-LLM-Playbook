# 工作更新小練習：六條不編造事實的訊息

只使用虛構事實。這是一套文字練習，用來讓一條短更新更容易核對；它不證明更新準確、專業、已獲批准或適用於真實工作。需要私人、客戶、僱傭、財務或生產資訊時立即停止。

## 1. 先定讀者和事實
```text
我想練習一條虛構的工作更新。請依次問我：一位讀者、最多三條已確認事實、一條未知或阻礙、以及一個可能的請求。不要編造進度、日期、原因、批准或承諾。只返回簡短事實清單，然後等待我自己起草。
```
## 2. 先寫，不看範文
```text
只使用我們儲存的虛構事實，讓我為指定讀者寫一條 60 字以內的更新。不要代寫、潤色或新增標題。我發出後，請原樣保留第一次嘗試。
```
## 3. 找一個關鍵缺口
```text
按這份檢查表比較我的初稿：讀者能找到已確認事實、未知或阻礙，以及請求；文中沒有無依據的進度或承諾。最多指出一個關鍵缺口，並引用相關文字。事實不足以判斷時，請說“未知”。不要重寫更新。
```
## 4. 用自己的話修改
```text
只針對這個缺口給我一條不完整的提示，然後等待我的修改。除非我嘗試後明確要求，否則不要寫替代版本。把初稿、你的提示和我的修改分開保留。
```
## 5. 更換讀者
```text
保持虛構事實完全相同，但把讀者從同事換成負責人。請讓我在沒有提示的情況下另寫一版，然後標出語氣、細節和請求發生了什麼變化。不要把未知寫成事實，也不要說任何一版已獲批准。
```
## 6. 留下一張小回執
```text
請返回練習回執：虛構事實｜第一次嘗試｜一條提示｜學習者修改｜更換讀者後的嘗試｜需要核對的新增內容｜未知項。最後只能使用一個狀態：template_selected、practised、not_run 或 blocked。不要聲稱效率、寫作能力、職場準備度或記憶有所提高。
```

把兩版草稿和回執放在一起。一次有記錄的迴圈只是練習，不是獨立測評，也不能證明 AI 的反饋正確。
