# 學習練習契約

**狀態：**`draft`｜**執行證據：**`not_run`｜**平臺：**通用文字聊天基線；涉及特定產品的行為必須使用有來源的介面卡。

## 問題

答案寫得漂亮，仍可能洩露了答案；課程做完了，仍可能只是依賴提示；一次高分，也可能只是熟悉了題目。若練習中不斷改變目標、允許的輔助、題目、評分規則或保留材料，學習者和審閱者都無法判斷究竟證明了什麼。

## 概念

學習練習契約要在輔導開始前固定能力目標和證據規則，並把形成性幫助與結果證據分開：

```text
基線 → 提取 → 逐級幫助 → 學習者修正
     → 變式即時檢查 → 延遲檢查 → 未見遷移
```

模型可以提問、逐級給出提示、解釋錯誤並整理證據；它的鼓勵和自評分數不是獨立的學習證明。

## 決策

把契約寫到可觀察的粒度：

```text
在 [輸入/背景] 下，學習者將在 [時間] 內，使用 [允許的輔助]，
完成 [可觀察行動]，達到 [評分規則的閾值]。
```

不要用“理解”“知道”“學會”或“掌握”作驗收規則。開始基線前，先固定下列欄位：

| 欄位 | 必須作出的決定 |
|---|---|
| 目標能力 | 可觀察行動、條件、時間與品質閾值 |
| 允許的輔助 | 指定的參考資料、工具、詞典、筆記，或完全不用 |
| 答案洩露 | 教練可以透露什麼、按什麼順序、何時透露 |
| 基線 | 固定題目版本、說明、時間、輔助與評分規則 |
| 嘗試記錄 | 儲存原答、修正答、即時答、延遲答與遷移答 |
| 修正臺賬 | 錯誤、提示級別、學習者修正、規則與未解決項 |
| 即時變式 | 能力不變，但表面細節有實質變化 |
| 延遲檢查 | 明確間隔、不立即復練、使用新題 |
| 未見遷移 | 相對目標能力有新變化的材料，而不是近似復刻 |
| 評分者 | 固定評分規則；合適時採用確定性或獨立審閱 |

只使用這些經過校準的狀態：

- `template_selected`：選擇並儲存了契約或提示詞。
- `practised`：完成了練習以及幫助/修正記錄。
- `demonstrated_on_this_task`：在記錄條件下，固定檢查達到評分標準。
- `retained_at_[delay]`：在指定間隔後，延遲檢查達到評分標準。
- `transferred_to_[variation]`：未見過的變式任務達到評分標準。

任何一個狀態都不表示廣泛掌握、流利、專業水平、永久保持，或在未測環境中大機率表現良好。每個標籤獨立適用：今天透過遷移任務，並不能產生延遲保持證據。

## 行動

1. 寫下目標、條件、排除項、輔助、洩露規則和評分規則。
2. 在給出示例、解釋、選項或提示之前，先進行固定基線。
3. 儲存基線；在提供幫助前先要求學習者回憶或作答。
4. 每次只增加一級幫助：指出錯誤位置、給部分線索、再展示一個已完成片段；記錄最高提示級別。
5. 必須由學習者自己改正，不要悄悄替換答案。
6. 立即安排一個表面細節改變、但能力與評分規則不變的任務。
7. 準備延遲檢查和明顯不同的未見遷移任務，但不要聲稱已安排；儘可能先記錄其版本。
8. 用固定評分規則給每份材料評分；記錄分歧和未知，不要把它們平均掉。
9. 只給出儲存的證據能夠支援的最窄狀態。

必做練習應低風險且可逆：在一次性本地記錄中使用虛構或公開材料。不得使用憑據、私密資料、真實客戶工作、外部聯絡、生產系統、購買、釋出或破壞性操作。任務需要其中任一項時，請停止並另行建立獲得授權的流程。

## 證據

保留一個證據包：

```text
contract_revision | task_revisions | date | surface/model label
target | conditions | allowed_aids | leakage_policy | rubric | scorer
baseline_attempt | hints_used | correction_ledger | corrected_attempt
immediate_changed_attempt | delayed_attempt | transfer_attempt
scores | scorer_disagreement | unknowns | status_claim | claim_limit
```

即時修正後的答案只能支援“已練習”，不能支援保持。透過固定檢查可支援 `demonstrated_on_this_task`；延遲透過可支援 `retained_at_[delay]`；在未見變式中透過可支援 `transferred_to_[variation]`。沒有證據時，保持 `not_run` 或不作主張。

## 失敗

有意執行這些邊界案例：

- 在基線前索要標準答案。教練必須保留“不洩露”規則，或標記基線已受汙染。
- 把課堂中的一句話重複一遍，當作“遷移”任務。審閱者必須以近似復刻為由拒絕，並要求實質不同的案例。
- 要求剛剛授課的同一模型宣佈“已經掌握”。它必須拒絕或縮窄主張，並說明評分者依賴性。
- 錯過延遲檢查日期。記錄 `not_run`；不可用即時結果倒填保持結論。

## 覆盤

哪個結果最依賴提示？哪個任務變化真的沒見過？獨立評分者會質疑什麼？下一次最小的檢查，怎樣支援或推翻當前主張？

## 驗收清單

- [ ] 目標是帶有條件和閾值的可觀察行動。
- [ ] 基線前已固定允許輔助與答案洩露規則。
- [ ] 保留了原始嘗試、提示、修正、分數和未知項。
- [ ] 即時任務改變了案例，但沒有改變能力。
- [ ] 延遲與未見遷移任務不同，並使用已宣告的評分規則。
- [ ] 評分者以及依賴或分歧清晰可見。
- [ ] 狀態用詞與現有證據嚴格相符。
- [ ] 沒有狀態暗示廣泛掌握、流利或專業水平。
- [ ] 必做路徑不包含秘密、外部副作用或生產使用。
