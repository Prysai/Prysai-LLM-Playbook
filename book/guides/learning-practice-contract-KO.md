# 학습 실습 계약

**상태:** `draft` | **실행 증거:** `not_run` | **플랫폼:** 범용 텍스트 채팅 기준선. 제품별 동작에는 출처가 있는 어댑터가 필요합니다.

## 문제

그럴듯한 답변은 정답 유출을 숨길 수 있습니다. 끝낸 수업은 단서 의존을 숨길 수 있고, 한 번의 높은 점수는 시험 친숙도일 수 있습니다. 실습 중 목표, 허용 보조물, 과제, 채점 기준, 산출물이 바뀌면 학습자와 검토자 모두 무엇이 증명되었는지 알 수 없습니다.

## 개념

학습 실습 계약은 코칭 전에 목표 역량과 증거 규칙을 고정하고, 형성적 도움과 결과 증거를 분리합니다.

```text
기준선 → 회상 → 단계적 도움 → 학습자 수정
      → 변경된 즉시 점검 → 지연 점검 → 미경험 전이
```

모델은 질문, 단계적 힌트, 오류 설명, 증거 정리를 할 수 있습니다. 하지만 격려와 자기 채점은 독립적인 학습 증거가 아닙니다.

## 결정

계약을 관찰 가능한 해상도로 씁니다.

```text
[입력/맥락]이 주어지면 학습자는 [시간] 안에 [허용 보조물]을 사용하여
[관찰 가능한 행동]을 하고 [루브릭 임계값]에 도달한다.
```

수용 규칙에 ‘이해한다’, ‘안다’, ‘배운다’, ‘숙달한다’를 쓰지 마세요. 기준선 전에 다음을 고정합니다.

| 항목 | 필요한 결정 |
|---|---|
| 목표 역량 | 관찰 가능한 행동, 조건, 시간, 품질 임계값 |
| 허용 보조물 | 명시한 참고자료, 도구, 사전, 노트 또는 없음 |
| 정답 유출 | 코치가 무엇을, 어떤 순서로, 언제 밝힐 수 있는가 |
| 기준선 | 고정된 과제 판본, 지시, 시간, 보조물, 루브릭 |
| 시도 | 원본, 수정본, 즉시, 지연, 전이 시도를 저장 |
| 수정 장부 | 오류, 힌트 수준, 학습자 수정, 규칙, 미해결 항목 |
| 변경된 즉시 사례 | 역량은 같고 표면 세부만 실질적으로 다름 |
| 지연 점검 | 명시한 간격, 즉시 반복 없음, 새 과제 |
| 미경험 전이 | 비슷한 복사가 아닌 새로운 변형 자료 |
| 채점자 | 고정 루브릭, 적절할 때 결정적 또는 독립 검토 |

상태는 다음만 사용합니다.

- `template_selected`: 계약 또는 프롬프트를 선택하고 저장함.
- `practised`: 연습과 도움/수정 기록을 마침.
- `demonstrated_on_this_task`: 기록된 조건에서 고정 점검이 루브릭을 충족함.
- `retained_at_[delay]`: 명시한 간격 뒤 지연 점검이 루브릭을 충족함.
- `transferred_to_[variation]`: 미경험 변형 과제가 루브릭을 충족함.

어느 것도 폭넓은 숙달, 유창성, 전문성, 영구 보존, 미검증 조건에서의 성과를 뜻하지 않습니다. 오늘 전이에 성공해도 지연 보존 증거가 생기지 않습니다.

## 행동

1. 목표, 조건, 제외 사항, 보조물, 유출 정책, 루브릭을 적습니다.
2. 예시, 설명, 선택지, 힌트보다 먼저 고정 기준선을 제시합니다.
3. 기준선을 보존하고 도움 전에 회상을 요구합니다.
4. 도움은 한 단계씩 올립니다. 오류 위치를 짚고, 부분 단서를 주고, 해결된 조각 하나를 보여 줍니다. 사용한 최고 수준을 기록합니다.
5. 학습자가 직접 수정하게 하며 답을 조용히 바꾸지 않습니다.
6. 역량과 루브릭은 유지하되 세부를 바꾼 즉시 과제를 합니다.
7. 지연 점검과 뚜렷이 다른 미경험 전이 과제를 준비하되, 예약되었다고 주장하지 않습니다. 가능하면 사용 전 판본을 기록합니다.
8. 고정 루브릭으로 각 산출물을 채점하고 불일치와 미지 항목을 평균으로 지우지 않습니다.
9. 보존한 증거가 지지하는 가장 좁은 상태만 선언합니다.

필수 연습은 저위험·가역적이어야 합니다. 일회용 로컬 기록에서 가상 또는 공개 자료만 쓰세요. 자격증명, 사적 데이터, 실제 고객 업무, 외부 연락, 운영 시스템, 구매, 게시, 파괴적 행동을 쓰지 않습니다. 필요하다면 멈추고 별도 승인 절차를 만드세요.

## 증거

하나의 패킷을 보관합니다.

```text
contract_revision | task_revisions | date | surface/model label
target | conditions | allowed_aids | leakage_policy | rubric | scorer
baseline_attempt | hints_used | correction_ledger | corrected_attempt
immediate_changed_attempt | delayed_attempt | transfer_attempt
scores | scorer_disagreement | unknowns | status_claim | claim_limit
```

즉시 수정한 답은 실습을 뒷받침할 뿐 보존을 뒷받침하지 않습니다. 고정 점검 통과는 `demonstrated_on_this_task`, 지연 통과는 `retained_at_[delay]`, 미경험 변형 통과는 `transferred_to_[variation]`를 뒷받침할 수 있습니다. 증거가 없으면 `not_run`으로 두거나 주장하지 않습니다.

## 실패

- 기준선 전에 이상 답안을 요구합니다. 코치는 비유출 규칙을 지키거나 기준선을 오염됨으로 표시해야 합니다.
- 수업 문장을 반복해 ‘전이’ 과제로 냅니다. 검토자는 근접 복사본으로 거부하고 실질적으로 다른 사례를 요구해야 합니다.
- 수업을 가르친 같은 모델에게 숙달을 선언하게 합니다. 거절하거나 주장을 좁히고 채점자 의존을 밝혀야 합니다.
- 지연 날짜를 놓칩니다. `not_run`을 기록하고 즉시 결과로 보존을 채우지 않습니다.

## 성찰

어떤 결과가 힌트에 가장 의존했나요? 어떤 변형이 정말 새로웠나요? 독립 채점자는 무엇을 이의 제기할까요? 현재 주장을 강화하거나 반박할 가장 작은 다음 점검은 무엇일까요?

## 수용 체크리스트

- [ ] 목표는 조건과 임계값이 있는 관찰 가능한 행동이다.
- [ ] 허용 보조물과 유출 규칙은 기준선 전에 고정했다.
- [ ] 원본 시도, 힌트, 수정, 점수, 미지 항목을 보존했다.
- [ ] 즉시 과제는 역량을 바꾸지 않고 사례를 바꿨다.
- [ ] 지연·미경험 전이는 서로 다르고 선언한 루브릭을 사용한다.
- [ ] 채점자와 의존성 또는 불일치가 보인다.
- [ ] 상태 표현이 실제 증거와 맞는다.
- [ ] 폭넓은 숙달, 유창성, 전문성을 암시하는 상태가 없다.
- [ ] 필수 경로에 비밀, 외부 부작용, 운영 사용이 없다.
