# 学习练习契约

**状态：**`draft`｜**运行证据：**`not_run`｜**平台：**通用文字聊天基线；涉及特定产品的行为必须使用有来源的适配器。

## 问题

答案写得漂亮，仍可能泄露了答案；课程做完了，仍可能只是依赖提示；一次高分，也可能只是熟悉了题目。若练习中不断改变目标、允许的辅助、题目、评分规则或保留材料，学习者和审阅者都无法判断究竟证明了什么。

## 概念

学习练习契约要在辅导开始前固定能力目标和证据规则，并把形成性帮助与结果证据分开：

```text
基线 → 提取 → 逐级帮助 → 学习者修正
     → 变式即时检查 → 延迟检查 → 未见迁移
```

模型可以提问、逐级给出提示、解释错误并整理证据；它的鼓励和自评分数不是独立的学习证明。

## 决策

把契约写到可观察的粒度：

```text
在 [输入/背景] 下，学习者将在 [时间] 内，使用 [允许的辅助]，
完成 [可观察行动]，达到 [评分规则的阈值]。
```

不要用“理解”“知道”“学会”或“掌握”作验收规则。开始基线前，先固定下列字段：

| 字段 | 必须作出的决定 |
|---|---|
| 目标能力 | 可观察行动、条件、时间与质量阈值 |
| 允许的辅助 | 指定的参考资料、工具、词典、笔记，或完全不用 |
| 答案泄露 | 教练可以透露什么、按什么顺序、何时透露 |
| 基线 | 固定题目版本、说明、时间、辅助与评分规则 |
| 尝试记录 | 保存原答、修正答、即时答、延迟答与迁移答 |
| 修正台账 | 错误、提示级别、学习者修正、规则与未解决项 |
| 即时变式 | 能力不变，但表面细节有实质变化 |
| 延迟检查 | 明确间隔、不立即复练、使用新题 |
| 未见迁移 | 相对目标能力有新变化的材料，而不是近似复刻 |
| 评分者 | 固定评分规则；合适时采用确定性或独立审阅 |

只使用这些经过校准的状态：

- `template_selected`：选择并保存了契约或提示词。
- `practised`：完成了练习以及帮助/修正记录。
- `demonstrated_on_this_task`：在记录条件下，固定检查达到评分标准。
- `retained_at_[delay]`：在指定间隔后，延迟检查达到评分标准。
- `transferred_to_[variation]`：未见过的变式任务达到评分标准。

任何一个状态都不表示广泛掌握、流利、专业水平、永久保持，或在未测环境中大概率表现良好。每个标签独立适用：今天通过迁移任务，并不能产生延迟保持证据。

## 行动

1. 写下目标、条件、排除项、辅助、泄露规则和评分规则。
2. 在给出示例、解释、选项或提示之前，先进行固定基线。
3. 保存基线；在提供帮助前先要求学习者回忆或作答。
4. 每次只增加一级帮助：指出错误位置、给部分线索、再展示一个已完成片段；记录最高提示级别。
5. 必须由学习者自己改正，不要悄悄替换答案。
6. 立即安排一个表面细节改变、但能力与评分规则不变的任务。
7. 准备延迟检查和明显不同的未见迁移任务，但不要声称已安排；尽可能先记录其版本。
8. 用固定评分规则给每份材料评分；记录分歧和未知，不要把它们平均掉。
9. 只给出保存的证据能够支持的最窄状态。

必做练习应低风险且可逆：在一次性本地记录中使用虚构或公开材料。不得使用凭据、私密数据、真实客户工作、外部联系、生产系统、购买、发布或破坏性操作。任务需要其中任一项时，请停止并另行建立获得授权的流程。

## 证据

保留一个证据包：

```text
contract_revision | task_revisions | date | surface/model label
target | conditions | allowed_aids | leakage_policy | rubric | scorer
baseline_attempt | hints_used | correction_ledger | corrected_attempt
immediate_changed_attempt | delayed_attempt | transfer_attempt
scores | scorer_disagreement | unknowns | status_claim | claim_limit
```

即时修正后的答案只能支持“已练习”，不能支持保持。通过固定检查可支持 `demonstrated_on_this_task`；延迟通过可支持 `retained_at_[delay]`；在未见变式中通过可支持 `transferred_to_[variation]`。没有证据时，保持 `not_run` 或不作主张。

## 失败

有意运行这些边界案例：

- 在基线前索要标准答案。教练必须保留“不泄露”规则，或标记基线已受污染。
- 把课堂中的一句话重复一遍，当作“迁移”任务。审阅者必须以近似复刻为由拒绝，并要求实质不同的案例。
- 要求刚刚授课的同一模型宣布“已经掌握”。它必须拒绝或缩窄主张，并说明评分者依赖性。
- 错过延迟检查日期。记录 `not_run`；不可用即时结果倒填保持结论。

## 复盘

哪个结果最依赖提示？哪个任务变化真的没见过？独立评分者会质疑什么？下一次最小的检查，怎样支持或推翻当前主张？

## 验收清单

- [ ] 目标是带有条件和阈值的可观察行动。
- [ ] 基线前已固定允许辅助与答案泄露规则。
- [ ] 保留了原始尝试、提示、修正、分数和未知项。
- [ ] 即时任务改变了案例，但没有改变能力。
- [ ] 延迟与未见迁移任务不同，并使用已声明的评分规则。
- [ ] 评分者以及依赖或分歧清晰可见。
- [ ] 状态用词与现有证据严格相符。
- [ ] 没有状态暗示广泛掌握、流利或专业水平。
- [ ] 必做路径不包含秘密、外部副作用或生产使用。
