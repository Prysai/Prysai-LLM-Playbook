# 任意の応用練習：言語・仕事・調査

短く順番に練習したい場合は、[業務報告の練習](work-update-practice-loop-JA.md) または [リサーチ確認の練習](research-check-practice-loop-JA.md) を開いてください。

**状態：** `draft` · **学習者の根拠：** `not_run` · **対象：** テキストチャット型 LLM で行う、
低リスクかつ非機微な練習。

**LLM 基礎コアを終えてから使います：**[ユニット 1：LLM の概念](guides/llm-fundamentals-JA.md)
→ [ユニット 2：最初の範囲付きリクエスト](routes/universal-core-foundations-JA.md)。
このカードはコアの方法を応用するもので、LLM とは何かを説明する入門ではありません。
先に[第0章](guides/llm-fundamentals-JA.md)を読み、このカードを応用練習として使ってください。LLMとは何かを説明する入門ではありません。
まだコアを終えていない場合は、[LLM 基礎コア](routes/universal-core-foundations-JA.md)から始めてください。

ここは日本語で説明する学習ルートです。このページの説明、判断、リンクは日本語です。カードに出てくるスペイン語は任意の語学練習の目標であり、誤った言語への移動でも必須科目でもありません。

すぐにコピーできる六つのメッセージは、[スペイン語の六段階練習](spanish-practice-loop-JA.md)にあります。

今日は Codex を開く必要も用語を覚える必要もありません。カードを一つ選び、角括弧を小さな
タスクに置き換え、先に自分で試し、AI には一つの明確な問題だけを手伝わせます。

> 架空、公開、または共有許可のある文章だけを使います。パスワード、トークン、非公開の会話、
> 顧客データ、未公開ファイル、本番システムの内容を貼り付けないでください。

## 目的で選ぶ：言語・仕事・調査

一番目から始める必要はありません。仕事で表現や判断を整えたいなら B から、主張や共有前の境界を確認したいなら C を選びます。A は語学を練習したい場合だけ開いてください。

**初めてで、スペイン語を練習する目的がない場合は、B のカード 3 から始めてください。** すでにある要点を、事実を作り足さずに送れる業務報告へまとめる練習です。A は「まず自分で試し、その後で限定した訂正を求める」方法をスペイン語で示す任意の例です。

<span id="language-practice-route"></span>

## A. 任意の語学練習（スペイン語を練習したい場合のみ）

### 1. 任意の語学例（スペイン語）：先に話し、限定した訂正をもらう

自分の文を残し、小さく確認できる訂正を受けます。最初からモデルに会話を代行させません。

```text
架空の情報で、スペイン語の学習グループの時間確認を練習したいです。あなたは同級生だけを演じ、見本の答えは出さないでください。
使える情報は [Ana、学習グループ、火曜か木曜、6:00か6:30、図書館かオンライン、質問を一つ持参] です。
まず私がスペイン語で12語以内の一文を書きます。
私が返したら、伝わりやすさを最も損なう問題を一つだけ指摘し、理由を[私の言語]で説明し、
文全体を書き直さないヒントを一つ出して、私が直すのを待ってください。
```

### 2. スペイン語：答えを暗記せず、場面を変える

```text
練習を続けますが、今度は課題計画に変えてください。私が準備する部分を尋ね、下書きが火曜か木曜かを確認します。
私の文を使い回さず、私が書く前にヒントを出さないでください。私が先に一文を書きます。
その後は「伝わる」か「修正が必要」だけを示し、直す点を一つだけ指摘してください。
この結果を流暢、習得、語学レベルとは呼ばないでください。
```

## B. ここから始める：仕事の表現と判断

### 3. 仕事の更新：事実を並べ、進捗を作らない

```text
次のメモを[同僚 / 顧客 / 責任者]への更新に整えてください。
メモ： [事実 1]、[事実 2]、[まだ不明なこと]。
先に確認できる事実を列挙してください。日付、約束、完了状態、理由を追加しないでください。
120語以内の版と、より正式な版を書き、送信前に私が確認すべき二点で終えてください。
```

### 4. 仕事の判断：助言の前に質問する

```text
[選択肢 A] と [選択肢 B] の間で小さな決定が必要です。
目的： [目的]。分かっていること： [事実]。分からないこと： [未知]。
代わりに決めないでください。結論を変える質問を最大三つ先にしてください。
次に「今の根拠が支えること」と「まだ決められないこと」の二列を作ってください。
重要な事実が欠けるなら、推測せず止まるよう勧めてください。
```

## C. 調査と共有前の確認

### 5. 調査の開始：大きな問いを確認可能な問いへ縮める

```text
調べたいこと： [問い]。この問いで行う決定： [決定]。
今受け入れる出典の種類： [公式文書、論文、機関報告など]。
問いに答えたり出典を作ったりしないでください。確認可能な小さい問い、最初に確かめる
主張、その出典を持ちそうな組織または人、見つからないときの停止条件を書いてください。
```

### 6. 出典確認：材料が一つの文を本当に支えるか確かめる

```text
私が共有する材料が次の主張を支えるか確認したいです。
主張： [一つの具体的な文]
抜粋： [共有許可のある公開内容だけ]
リンクまたは書誌： [URL / 引用]
「直接支える部分」「言っていない、または矛盾する部分」「私が原出典を開いて確認する部分」の
三列を返してください。開いていないリンクを検証済みと呼ばず、欠けた事実を補わないでください。
```

### 7. 共有前の確認：送る前に内容と相手を小さくする

「共有したい」と「共有を許可されている」を分けます。このカードは判断を整理するだけで、送信、アップロード、リンク作成はしません。

```text
AI の回答または会話の抜粋を共有することを考えています。
目的： [例：同僚に一文の表現を確認してもらう]。
相手候補： [役割またはグループ]。
共有予定の内容： [一文で説明。秘密や私的情報は貼らない]。
共有しない内容： [顧客情報、パスワード、会話全体、未公開ファイルなど]。

送信、アップロード、リンク作成はしないでください。先に次を示してください。
1. この目的に必要な最小の抜粋;
2. 私自身が確認すべき相手、内容、許可;
3. 共有できると決めつけず、止まるべき未知。
相手または許可を書いていない場合は、止まることと不足項目だけを示してください。
```

<span id="practice-route-chooser"></span>

## まず一つだけ選ぶ

何をしたいかまだ決まっていないなら、長い回答を求める前に、今日の目的を
一つに絞ります。語学などの技能を練習するのか、仕事の更新を整えるのか、
一つの主張を調べるのかを選び、短い試みと記録を一回だけ残してください。
これは診断や完全な学習計画ではありません。

<span id="request-escalation"></span>

### どんな助けが必要かを先に伝える

```text
今日達成したい小さな結果： [観察できる結果]
使ってよい情報： [事実、文章、または自分が渡すリンク]
最初にしてほしいこと： [書き換え / 質問 / 練習 / 確認手順]
私が渡していない事実を補わず、リンクを開かず、外部の操作もしないでください。
必要な情報が足りなければ、不足している項目を一つずつ示して止まってください。
```

「最新情報を調べて公開ページを更新する」のように確認と行動が混ざる場合は、
まず出典を確認し、その後に目的、対象、許可、取り消し方を含む別の行動手順を作ります。
出典があることは、公開してよいという意味ではありません。

<span id="first-practice-intake"></span>

### 大きな願いを、最初の一回に縮める

```text
私の願い： [例：スペイン語を学びたい]
10分ほどで安全に試せる練習になるまで、一度に一問だけ質問してください。
1. 私が実際にできる行動
2. 先に私が自分で試すこと
3. 受けてもよい助け（質問、ヒント、例、確認）
4. 私自身が確認すること
5. つまずいたときの、さらに小さな代替案
一度の練習を、習得、流暢さ、到達レベルとは呼ばないでください。
```

<span id="four-line-safety-card"></span>

## 高度な確認：共有・検索・操作の前に境界を書く

外部の資料、ファイル、ツール、アカウントが関わるときは、先にこのカードを
埋めます。カード自体は権限を与えません。項目が空なら止まってください。

```text
目的と、今回しないこと：
読んでよい入力と、その出所：
変更してよい正確なファイルまたは対象：
読まない・送らない・保存しないデータ：
期待する結果と、受け入れを確認する証拠：
停止条件：パス、許可、出典、証拠のいずれかが不明なら停止。
```

<span id="share-check"></span>

### 共有する前に、内容と相手を小さくする

```text
共有を考えているもの： [秘密を貼らず、一文で説明]
目的： [誰に何を確認してほしいか]
想定する相手： [役割またはグループ]
この目的に必要な最小の抜粋と、私が確認すべき内容、相手、許可、経路を分けてください。
送信、アップロード、リンクの作成はしないでください。
相手、許可、内容の境界が一つでも不明なら、欠けている項目を示して停止してください。
```

<span id="public-interest-safety-route"></span>

## 高度な確認：人に影響する AI の案を問い直す

採用、教育、医療、住まい、給付などに関わる案は、実在の個人情報を使わず、
まず架空のケースで確認します。

```text
架空のシステムが [役割] の人の [一つの判断] を支援するとします。
誰が利益を得たり不利益を受けたりするか、必要最小限のデータ、
人が確認・異議申立てできる場所、判断を支える証拠、必ず止める兆候を分けてください。
導入計画を作らず、サービスも呼び出さず、モデルの提案を事実として扱わないでください。
```

<span id="general-skill-practice-route"></span>

## ルート B：観察できる技能を一つ練習する

```text
練習したいこと： [概念を説明する / 面接に答える / 発表する]
まず [分] だけ、見本を見せずに私の実演を待ってください。
終わったら、目的が明確か、根拠が十分か、相手が次に動けるかだけを確認してください。
結果への影響が最も大きい問題を一つだけ指摘し、条件を変えた場面を一つ出してください。
私の経験を作らず、一回の実演を習得とは呼ばないでください。
```

<span id="bounded-research-route"></span>

## ルート C：一つの判断のために、範囲を決めて調べる

```text
判断したいこと： [判断]。対象にする日付・地域・版： [範囲]
まず、確認可能な問い、優先する出典の種類を三つ、調査を止める条件を書いてください。
各主張について、出典の責任者、元 URL と現在の URL、該当箇所、日付、適用範囲、未確定事項を記録してください。
検索結果の抜粋、フォーラムの体験談、開いていないリンクを検証済みの根拠にしないでください。
```

<span id="source-check-route"></span>

### 一文の主張を、原文と突き合わせる

```text
主張： [一つの具体的な文]
元の出典または共有が許可された抜粋： [本文]
直接支える部分、書かれていないか矛盾する部分、私が原文を開いて確認する部分の三つに分けてください。
該当箇所を見つけられなければ citation_unverified と記し、結論の範囲を狭めてください。
```

<span id="recovery-route"></span>

## 高度な確認：答えがずれたときに一条件だけ直す

元の依頼、見えていた文脈、実際の回答、期待した結果を残します。入力を先に
列挙する、出力形式を固定するなど、伝え方の条件を一つだけ変えて、低リスクな
比較を一回行います。ファイル、権限、ネットワーク、外部操作が必要になったら、
新しい境界を定めて停止してください。

<span id="card-e1-user-declared-continuity-receipt"></span>

### 次のラウンドを始める前の継続記録

```text
元の課題と、変えない制限：
前のラウンドで実際に読んだ、または終えた入力：
前のラウンドで確認できる出力：
まだ不明、失敗、未実行の部分：
今回変える唯一の条件：
停止条件と、結果を確認する人：
```

これは利用者が書いた文脈の記録であり、モデルの記憶や権限の証明ではありません。
新しいアカウント、ブランチ、リポジトリ、対象者を自動的に許可するものでもありません。

## 最初の練習は四歩だけ

1. 今日の必要に最も近いカードを選ぶ。
2. 自分の短い試み、または既知の事実を先に書く。
3. 回答と元の文を並べ、AI が制限を越えたか確認する。
4. 課題、元の試み、使った助け、残した版、未知を記録する。

練習したいのに完全な答えが出たら、一つのヒントへ戻すよう求めます。事実、出典、約束を
作ったら、その回答を使うのを止め、未確認部分を未知として残します。

## 練習記録：一回の対話を残す

どのカードの後でも、この短い記録だけを残します。次回何を練習したかが分かり、「役立った気がする」を根拠のない結論にしません。

```text
課題：
最初の試みまたは既知の事実：
AI の助け（ヒント / 修正 / 出典計画）：
残す版：
自分で確認したこと：
未確認または争いのあること：
状態：template_selected | practised | not_run | blocked
```

`practised` は記録付きで一度練習したことだけを意味します。流暢さ、習得、効率向上、出典の完全な検証を意味しません。

## これで終わりですか

カードを終えても、条件つきの試みを保存したことしか示しません。課題での成果を言うには
事前に決めた基準と検査可能な結果が必要です。定着や転移には後日の別の
課題が必要です。このカードには Prysai 学習者の実行記録、独立採点、モデル比較がありません。

これは日本語の起動カードであり、完全訳でも「万能プロンプト」でもありません。効率、学習、
流暢さ、モデル品質、プラットフォーム間で同じ動作をすることを証明しません。ファイル、ツール、
ブラウザー、アカウント、外部公開、実データが必要なら止まり、境界と出典のある手順を使ってください。

- [ ] 架空、公開、または許可された text だけを使った。
- [ ] 完全な答えの前に自分の試みまたは既知事実を残した。
- [ ] モデルが事実、約束、出典を追加していないか確認した。
- [ ] 結果が効率、習熟、流暢さ、モデル品質を証明しないと分かる。

## 出典と境界

これらは Prysai のオリジナル教材です。設計と出典記録は現在英語にあります。それらは
「先に試す、限定したフィードバック、最後に記録」という候補設計を説明しますが、カード、
モデル、コースの効果を証明しません。
