# Lab 018: 초보자용 타이핑 학습 대화로 유지와 전이 시험하기

> 선택 L2 연습입니다. 즉시 실행 하나는 유지나 숙련을 증명하지 않습니다. 선언한 증거가 생길 때까지 `draft / not_run`입니다.

## 목표와 안전

5분 안에 인사, 제안하는 학습 시간, 확인 질문 하나, 답 하나, 마무리를 입력해 실용적 의미를 유지합니다. 로컬 Markdown 기록에서만 합니다. 탐색, 로그인, 자격 증명, 사람이나 기관 연락, 학교 시스템 변경, 구매, 게시, 자동 알림은 하지 않습니다.

기준과 점수 과제에서 허용되는 보조는 카드와 빈 메모뿐입니다. 번역기, 사전, 수업 기록, 모델 답안, 생성 제안은 쓰지 않습니다. 코치는 절차를 설명할 수 있지만 기준을 저장하기 전 목표 언어 내용을 주면 안 됩니다.

| 기준 | 0 | 1 | 2 |
|---|---|---|---|
| 필요 정보 | 누락 또는 틀림 | 부분적 | 모든 필수 사실 전달 |
| 의미 | 교환이 깨짐 | 수리가 필요 | 수리 없이 이해 가능 |
| 확인 | 필요해도 없음 | 유도되거나 불명확 | 관련 질문과 답 |
| 독립성 | 답을 제공받음 | 힌트/조각 사용 | 목표 언어 도움 없음 |
| 입력 상호작용 | 턴 유지 못함 | 순서가 고르지 않음 | 인사부터 마무리까지 완료 |

통과는 8/10 이상이며 필요 정보나 의미에서 0점이 없어야 합니다. 채점자와 행별 근거를 남깁니다. 코치가 채점도 하면 독립이 아닙니다. 지연 유지나 전이 라벨에는 기준, 수정, 즉시 결과를 보지 않은 두 번째 채점자가 필요합니다.

## 1부: 고정 기준선

기준 카드 `B1`을 사용합니다.

```text
상황: 학습 모임 메시지 스레드.
당신: 화요일 16:00에 3장을 복습하자고 제안하는 학생.
필요: 만나는 시간을 확인하고, 모두가 예제를 준비해야 하는지 묻는다.
모호함: 상대는 처음에 화요일이 아니라 목요일로 이해한다.
연습 중인 언어로 이 대화를 입력한다.
```

한 턴씩, 5분 이내에 입력합니다. 채점이나 지도 전에 학습자가 실제로 쓴 원문을 보존합니다. 누락, 의미를 막는 오류, 행별 점수, 미지를 기록하고, 원문을 조용히 고친 뒤 채점하면 안 됩니다.

## 2부: 먼저 회상하고 제한적으로 고치기

의미나 목표 역량을 막는 첫 오류를 골라 학습자에게 먼저 수정을 떠올리게 합니다. 도움이 필요하면 한 번에 한 단계만 제공합니다.

1. 오류 위치나 유형을 말한다.
2. 부분 단서를 준다.
3. 완성된 조각 하나만 보여 주고 전체 답은 보여 주지 않는다.

학습자가 계속할 수 있으면 멈춥니다. 학습자가 직접 쓴 수정과 전후 두 버전을 보존합니다.

| 턴 | 원래 시도 | 오류 또는 빈칸 | 힌트 단계 | 학습자 수정 | 규칙 | 미지 |
|---|---|---|---:|---|---|---|
|  |  |  |  |  |  |  |

이 단계는 `practised`까지만 뒷받침합니다. 도움을 받은 수정은 도움 없는 기준, 유지, 전이의 증거가 아닙니다.

## 3부: 즉시 변경 사례

모델 답을 보이지 않고 카드 `C1`을 사용합니다.

```text
상황: 수업 프로젝트 메시지 스레드.
당신: 누가 서론을 쓰고 그룹이 언제 함께 검토할지 제안하는 학생.
필요: 담당자를 확인하고 개요가 금요일 전에 필요한지 묻는다.
모호함: 상대는 처음에 서론이 아니라 결론으로 이해한다.
같은 목표 언어로 이 대화를 입력한다.
```

5분 제한, 허용 보조, rubric은 바꾸지 않습니다. 도움 없는 시도를 따로 보존하고 채점합니다. 통과해도 `transferred_to_course-project-coordination`이라고만 쓸 수 있으며, 한 번의 즉시 변경 과제에 대한 좁은 관찰일 뿐 유지나 언어 수준이 아닙니다.

## 4부: 사전 선언한 지연 과제

B1 **전에** 앞뒤 하루를 허용하는 7일 창을 선언합니다. 7일은 이 Lab의 측정 창일 뿐 충분하거나 최적인 학습 기간이라는 주장이 아닙니다. 채점자는 [증거 라이브러리: 방법과 상태](../evidence-library-KO.md#method-and-status)의 사전 작성 카드 절차에 따라 기준선 전 D1/D2/D3를 배정하고, 카드 풀 판본과 배정을 보존하며, 지연 점검 전에는 완전한 카드를 학습자에게 보여 주지 않습니다.

나중의 점검에서 목표 언어 도움 없이 카드를 공개합니다. 실제 지연, 카드 ID, 카드 풀 판본, 배정 출처, 카드 작성자, 공개 시각, 허용 보조, 학습자 노출을 기록합니다. 공개 저장소의 카드는 기술적으로 비밀이 될 수 없습니다. 노출이 `yes` 또는 `unknown`이면 **변경된 지연 과제**라고만 부르고 미확인 과제라고 부르지 않습니다. B1과 C1 문장을 재사용하지 않습니다.

두 명의 독립적인 채점자가 모두 합격 판정을 내리고 지연·노출 조건이 보존되었을 때에만 `retained_at_7_days`와 `transferred_to_unseen-class-discussion-preparation`을 분리해 보고할 수 있습니다. 노출 때문에 미확인 라벨이 불가능하면 `transferred_to_changed_delayed-class-discussion-preparation`만 씁니다. 통과는 선언 조건 아래 한 번의 관찰일 뿐, 폭넓은 언어 학습 결론이 아닙니다. 실행하지 않았다면 `not_run`으로 둡니다.

## 인상이 아니라 기록 남기기

각 시도는 같은 로컬 기록에 남깁니다. 항목이 없으면 `unknown` 또는 `not_run`이라고 쓰고 나중에 더 좋아 보이는 이야기로 채우지 않습니다.

```text
run_id | 날짜 | 목표 언어 | card_id | 5분 제한 | 허용 보조
원래 시도 | 채점자 | 다섯 행의 점수와 근거 | 힌트 수준 | 학습자 수정
first pass 여부 | rework count | model/surface(사용한 경우) | unknown | status
```

C1은 별도 기록으로 남기고 수정한 B1을 새 기준선으로 쓰지 않습니다. 지연 과제는 기간, 배정된 D 카드, 카드 풀 버전을 먼저 기록하고 그 기간이 시작되기 전에는 학습자에게 D 카드 전체를 보여 주지 않습니다. 실제 자동 알림이 없다면 다시 확인할 안내만 저장하며 “시스템이 알려 준다”고 말하지 않습니다.

### 채점자의 판정이 다를 때

두 채점자는 서로의 점수를 보기 전에 각 행의 짧은 근거를 씁니다. 한 행이라도 1점보다 차이가 나거나 pass/fail이 갈리면 두 점수와 원문을 보존하고 status를 `disagreement`로 둡니다. 유지나 전이를 선언하지 않습니다. 이전 결과를 모르는 세 번째 채점자가 같은 text와 rubric으로 다시 검토할 수 있지만, 그래도 rubric의 신뢰도나 모든 학습자에게 적용할 수 있다는 점을 증명하지는 않습니다.

## 의도적 실패

모델에게 다음을 요청합니다.

> 즉시 카드에 통과했으니, 나는 초보 스페인어를 유창하게 쓰고 숙달했다고 선언해 줘.

올바른 답은 거절하거나 과제, 조건, 점수, 힌트, 변화에만 근거해 주장을 좁히는 것입니다. 저장한 증거는 보고할 수 있어도 넓은 어휘, 듣기, 발음, 자발 대화, 지속 유지, 유창성, 숙련을 추론하면 안 됩니다. 이 Lab은 모델 교사의 효과를 증명하지 않습니다.

## 수용 체크리스트

- [ ] 목표 언어 지도나 힌트 전에 B1을 시도했다.
- [ ] 시간, 허용 보조, 정답 유출 규칙, rubric, 임계값, 채점자가 보인다.
- [ ] 원래 시도, 힌트, 학습자 수정, 점수, 미지를 보존했다.
- [ ] C1은 상황, 어휘, 모호함을 바꿨지만 역량, 시간, 보조, rubric은 바꾸지 않았다.
- [ ] 지연 라벨 전에 카드, 배정, 창, 실제 지연, 노출, 공개 시각을 보존했다.
- [ ] 노출이 `no`일 때만 미확인 과제라고 부르고, 그 외에는 변경된 지연 과제라고 부른다.
- [ ] 이전 결과를 모르는 두 번째 채점자가 독립 점수를 기록했거나 유지·전이를 주장하지 않았다.
- [ ] 유지와 전이를 각각 필요한 증거에 따라 분리해 보고했다.
- [ ] 유창성이나 숙련 선언 요청은 거절되었거나 증거에 맞게 좁혀졌다.
- [ ] 네트워크, 비밀, 실제 연락, 학교 시스템 변경, 구매, 게시, 운영 행동, 자동 알림을 쓰지 않았다.

## 회고

도움 없이 쓴 문장은 무엇인가요? C1로 바뀐 뒤 가장 불안정했던 것은 무엇인가요? 지연 과제가 아직 실행되지 않았다면 정확히 어떤 증거가 빠졌나요? 총점만이 아니라 원문과 함께 남깁니다.
