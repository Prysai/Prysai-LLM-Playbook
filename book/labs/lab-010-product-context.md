# 实验 010：建立共享产品上下文

```yaml
id: lab-010-product-context
title: "让两个营销任务共享同一份产品理解"
level: L3
domain: marketing
goal: "理解上下文资产如何减少重复说明并提高决策质量"
status: draft
last_verified: 2026-08-09
```

为一个产品建立最小上下文：产品、受众、问题、差异化、反对意见、客户语言、品牌语气和目标行动。让 Codex 先写介绍，再设计一个测量计划。更新一个定位决策后重新生成并记录版本差异。

通过标准：两个任务能使用同一上下文，更新有版本和原因，测量计划能对应一个真实决策。
