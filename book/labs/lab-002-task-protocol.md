# 实验 002：把模糊愿望改成任务协议

## 输入

选择一个真实但低风险的目标，例如：改进 README、整理一个研究问题、设计一个营销实验或修复一个小 UI 问题。

## 任务

先给出一句自然语言愿望，不要直接提供完整说明。让 Codex 只做澄清和协议草案，不执行修改。要求它把目标转换为：目标、背景、输入、约束、允许行动、验收标准、失败处理和交付格式。

## 学习者检查

- 它是否问了真正影响结果的问题？
- 它是否把“高级”“做好”“尽快”等词转成可检查条件？
- 它是否区分了只读检查、编辑和外部副作用？
- 它是否指出了缺失输入和不确定性？
- 你是否同意每一条允许行动？

## 通过标准

协议能让另一位贡献者在不参与原对话的情况下判断：任务边界是什么、完成需要什么证据、失败时应该在哪里停。
