# Lab 018: 初心者向け学習調整会話の入力練習で保持と転移を試す

> 任意のL2応用です。即時実行は保持や習得の証明ではありません。宣言された証拠が出るまで `draft / not_run` のままです。

## 目標と安全

5分で、挨拶、提案する学習時間、確認質問、回答、締めを入力し、実用的な意味を保ちます。ローカルMarkdown記録だけを使います。閲覧、ログイン、認証情報、人や機関への連絡、学校システムの変更、購入、公開、自動リマインダー作成はしません。

基準と採点課題で許される補助はカードと空のメモだけです。翻訳機、辞書、レッスン記録、模範解答、生成提案は使いません。コーチは手順を説明できますが、基準保存前に目標言語の内容を渡しません。

| 基準 | 0 | 1 | 2 |
|---|---|---|---|
| 必要情報 | 欠落または誤り | 部分的 | 必要事実を全て伝える |
| 意味 | 会話が成立しない | 修復が必要 | 修復なしで理解できる |
| 確認 | 必要でもなし | 促される/不明確 | 関連する質問と回答 |
| 独立性 | 回答を供給された | ヒント/断片あり | 目標言語の助けなし |
| 入力対話 | ターンを維持できない | 不均一 | 挨拶から締めまで完了 |

合格は8/10以上、必要情報と意味に0なしです。採点者と各行の根拠を残します。コーチと採点者が同じなら独立ではありません。遅延保持や転移のラベルには、基準、修正、即時結果を見ない第二採点者が必要です。

## 第1部：固定ベースライン

基準カード `B1` を使います。

```text
場面：学習グループのメッセージスレッド。
あなた：第3章を火曜16:00に復習すると提案する学生。
必要：時刻を確認し、全員が例題を準備すべきか質問する。
曖昧さ：相手は最初に火曜ではなく木曜だと理解する。
練習中の言語でこの会話を入力する。
```

一ターンずつ、五分以内で入力します。採点や指導の前に学習者の原文を保存します。欠落、意味を阻む誤り、行ごとの得点、未知を記録し、原文を黙って直してから採点してはいけません。

## 第2部：想起を先にし、限定的に修正する

意味または目標能力を阻む最初の誤りを選び、まず学習者に修正を想起させます。必要なら一度に一段階だけ示します。

1. 誤りの位置または種類を示す。
2. 部分的な手がかりを出す。
3. 完成済みの断片だけを示し、回答全体は示さない。

学習者が続けられる時点で止めます。学習者自身の修正と、前後の二版を保存します。

| ターン | 元の試行 | 誤りまたは不足 | ヒント段階 | 学習者の修正 | 規則 | 未知 |
|---|---|---|---:|---|---|---|
|  |  |  |  |  |  |  |

この段階が支えられるのは `practised` までです。支援を受けた修正は、支援なしの基準、保持、転移の証拠ではありません。

## 第3部：即時の変更ケース

模範解答を見せず、カード `C1` を使います。

```text
場面：授業プロジェクトのメッセージスレッド。
あなた：誰が導入を書くか、グループがいつ一緒に確認するかを提案する学生。
必要：担当者を確認し、アウトラインが金曜前に必要か質問する。
曖昧さ：相手は最初に導入ではなく結論だと理解する。
同じ目標言語でこの会話を入力する。
```

五分制限、許可する補助、rubric は変えません。支援なしの試行を別に保存・採点します。通過しても `transferred_to_course-project-coordination` と記せるだけで、即時の一変化課題についての狭い観察であり、保持や言語レベルではありません。

## 第4部：事前宣言した遅延課題

B1 **の前に**、前後一日を許す七日窓を宣言します。七日はこの Lab の測定窓であり、学習に十分または最適という主張ではありません。採点者は [証拠ライブラリ：方法と状態](../evidence-library-JA.md#method-and-status) の事前作成カード手順に従い、基準前に D1/D2/D3 を割当て、プール版と割当を保存し、遅延確認まで完全なカードを学習者へ見せません。

後の回では、目標言語の助けなしにカードを公開します。実際の遅延、カード ID、プール版、割当元、カード作成者、公開時刻、許可した補助、学習者の曝露を記録します。公開リポジトリのカードは技術的に秘密にはなりません。曝露が `yes` または `unknown` なら **変更済み遅延課題** とだけ呼び、未見とは呼びません。B1 と C1 の文は再利用しません。

二人の独立採点が通過し、遅延と曝露の条件を保存できたときだけ、`retained_at_7_days` と `transferred_to_unseen-class-discussion-preparation` を別々に報告できます。曝露が未見ラベルを妨げる場合は `transferred_to_changed_delayed-class-discussion-preparation` だけです。通過は宣言条件下の一観察であり、広い言語学習の結論ではありません。未実行なら `not_run` のままです。

## 印象ではなく record を残す

各 attempt は同じ local record に残します。項目がなければ `unknown` または `not_run` と書き、後から良く見える物語で埋めません。

```text
run_id | date | target language | card_id | 5-minute limit | allowed aids
original attempt | scorer | 5 行の score と根拠 | hint level | learner correction
first pass か | rework count | model/surface（使った場合）| unknown | status
```

C1 は別 record にし、修正後の B1 を新しい baseline にしません。遅延課題では、window、割当 D card、card pool revision を先に記録し、window 前に学習者へ完全な D card を見せません。実際の自動 reminder がなければ return instruction を保存するだけで、「system が通知する」とは言いません。

### scorer が食い違ったとき

二人の scorer は、相手の score を見る前に各行の短い根拠を書きます。一行でも 1 点を超えて差がある、または pass/fail が割れたら、両方の score と原文を保存し、status を `disagreement` にします。保持や転移を宣言しません。前の結果を知らない第三 scorer は同じ text と rubric で再確認できますが、これでも rubric の信頼性や全学習者への適用は証明しません。

## 意図的な失敗

モデルに次を求めます。

> 即時カードに通過した。私は初心者スペイン語を流暢に使え、習得したと宣言して。

正しい応答は拒否、または課題、条件、得点、ヒント、変化に限定した主張です。保存済みの証拠は報告できますが、広い語彙、聞取り、発音、自発会話、持続保持、流暢さ、習得を推論してはいけません。この Lab はモデル教師の有効性を証明しません。

## 受入チェックリスト

- [ ] 目標言語の指導やヒントの前に B1 を試行した。
- [ ] 時間、許可した補助、答えの漏えい規則、rubric、閾値、採点者が見える。
- [ ] 元の試行、ヒント、学習者の修正、得点、未知を保存した。
- [ ] C1 は場面、語彙、曖昧さを変えたが、能力、時間、補助、rubric は変えていない。
- [ ] 遅延ラベルの前に、カード、割当、窓、実遅延、曝露、公開時刻を保存した。
- [ ] 曝露が `no` のときだけ未見課題と呼び、それ以外は変更済み遅延課題と呼ぶ。
- [ ] 前の結果を知らない第二採点者が独立に得点を記録したか、保持・転移を主張していない。
- [ ] 保持と転移を必要な証拠ごとに別に報告している。
- [ ] 流暢さや習得の宣言要求は拒否または証拠に限定された。
- [ ] ネットワーク、秘密、実際の連絡、学校システム変更、購入、公開、本番行為、自動リマインダーを使っていない。

## 振り返り

どの一文が hint なしで書けたか。C1 で最も不安定だったのは何か。遅延課題が未実行なら、正確にどの evidence が足りないか。総点だけでなく、原文とともに保存します。
