# 新手提示卡：把话说清

状态：`draft` ｜ 学习者运行证据：`not_run` ｜ 适用范围：任何文字聊天式 LLM 工作台中的低风险、非敏感练习。

想直接复制六条西班牙语练习消息？打开[西班牙语六步练习](spanish-practice-loop-ZH.md)。
想练一条不编造事实的工作更新，或核查一项资料？打开[工作更新六步练习](work-update-practice-loop-ZH.md)或[研究核查六步练习](research-check-practice-loop-ZH.md)。

今天先不讲术语，也不要求你先打开 Codex。选一张卡，把方括号里的内容换成你自己的小任务：先自己试一次，再让 AI 只帮你解决一个明确问题。

> 只使用虚构、公开或已获授权的文字。不要粘贴密码、令牌、私人聊天、客户资料、未公开文件或生产系统内容。

## 先选一张：七个马上能做的小练习

### 1. 西班牙语：先自己开口，再要纠错

预期：先保留你的原句，再拿到一条有限、可检查的纠错。不要让模型一开始就替你完成对话。

```text
我想练习在酒店办理入住时说第一句话。请先只扮演前台，不要示范答案。

条件：我只会这些词：[hola, tengo una reserva, mi nombre es, por favor]。
目标：我会先用西班牙语写一句不超过 12 个词的话。

等我回复后，请：
1. 只指出最影响理解的一处问题；
2. 用中文解释原因；
3. 给我一个提示，不直接替我重写整句；
4. 等我自己改写。
```

### 2. 西班牙语：把同一能力换一个场景

预期：练习“提出一个简单请求”，而不是背上一轮的标准答案。

```text
继续刚才的练习，但把场景改成在车站询问去 [城市名] 的车票。
请只使用我已经列出的词；如果不够表达，请先用中文问我想新增哪一个词。

先让我自己写一句。我的句子出现后，请按“能否被对方理解”给出通过 / 需要修改，
并最多指出一处需要修改的地方。不要把这次结果称为流利、掌握或语言等级。
```

### 3. 工作表达：把散乱要点变成可发送的更新

预期：同一批事实可以有不同语气；模型不能替你补出不存在的进度。

```text
请把下面的工作要点整理成一条发给 [同事 / 客户 / 负责人] 的更新。

原始要点：
- [事实 1]
- [事实 2]
- [仍不确定的事]

要求：
- 先列出你从原始要点中能确认的事实；
- 不要补充日期、承诺、完成状态或原因；
- 给出一个不超过 120 字的版本和一个更正式的版本；
- 最后列出我发送前必须自己确认的两件事。
```

### 4. 工作判断：先问清楚，再给建议

预期：当关键条件缺失时，一个好回复会先暴露未知，而不是装作已经知道答案。

```text
我需要在 [选项 A] 和 [选项 B] 之间做一个小决定。
我的目标是：[目标]。
目前知道：[事实]。
目前不知道：[未知]。

请不要直接替我决定。先问最多三个会改变结论的问题；
然后给我一个两列表格，分别写“现有证据支持什么”和“仍不能判断什么”。
如果缺少关键事实，请明确建议我暂停，而不是猜测。
```

### 5. 研究起步：把“大问题”缩成一个可核查的问题

预期：你先得到研究计划，而不是一篇看起来很完整、却无从核查的结论。

```text
我想弄清这个问题：[问题]。
这个问题将帮助我做出的决定是：[决定]。
我目前只接受这些来源类型：[例如官方文档、论文、机构报告]。

请不要回答这个问题，也不要编造来源。
请帮我写出：
1. 一个更小、可核查的问题；
2. 第一条需要核查的主张；
3. 该主张最可能的来源所有者；
4. 找不到来源时的停止条件。
```

### 6. 研究核对：让来源支持一句具体的话

预期：链接存在不等于它真的支持你的结论；模型的任务是帮助你准备核对表。

```text
我要检查下面这句话是否被我提供的材料支持。

主张：[一句具体的话]
材料摘要或原文摘录：[只放你有权分享的公开内容]
来源链接或出处：[链接 / 书目]

请把结果分成三栏：
- 材料直接支持的部分；
- 材料没有说明或与主张不一致的部分；
- 我需要亲自打开原始来源再核对的部分。

不要把没有打开过的链接称为已验证，也不要补写缺失事实。
```

### 7. 分享前检查：先缩小内容和对象，再决定是否发送

预期：先分清“我想分享什么”和“我被允许分享什么”。这张卡只帮你整理判断，不会替你上传、发送或公开内容。

```text
我考虑分享一段 AI 回答或聊天摘录。
我想达到的目的：[例如请同事核对一段措辞]。
可能的收件人：[角色或群体]。
我准备分享的内容：[一句话描述，不贴秘密或私人资料]。
我明确不会分享：[客户资料、密码、完整聊天记录、未公开文件等]。

不要发送、上传或生成链接。请先给我：
1. 这次目的所需的最小摘录；
2. 发送前必须由我确认的对象、内容和授权；
3. 哪些未知情况应让我停止，而不是默认可以分享。
如果我没有说明收件人或授权，请只建议暂停并补充哪一项。
```

## 只做四步，别把第一次练习做复杂

1. 选一张与今天最接近的卡。
2. 先写出你自己的短尝试，或填入你已知的事实。
3. 把回答和你的原始版本并排看，检查它是否越过了你的限制。
4. 留下一个最小记录：任务、原始尝试、使用的帮助、你最终保留的版本、仍未知的部分。

如果模型给出的是完整答案而你本来想练习，请要求它退回到“一条提示”；如果它编造事实、来源或承诺，请停止使用该回答，并把未核查部分保留为未知。

## 练习回执：把一次对话留下来

完成任意一张卡后，只保留这一小段记录。它让你下次能看清自己练了什么，也让“我觉得有用”不至于被写成没有证据的结论。

```text
任务：
我的第一次尝试或已知事实：
AI 提供的帮助（提示 / 纠错 / 资料规划）：
我保留的版本：
我亲自检查的内容：
仍未知或有争议的内容：
状态：template_selected | practised | not_run | blocked
```

`practised` 只表示保存了一次有记录的练习；它不表示流利、掌握、效率提升或来源已被完整验证。

## 这次练习算完成了吗？

完成一张卡，最多只能说明你保存了一次带条件的尝试。若想说“我在这项任务上表现出来了”，还需要预先写好的标准和可检查的结果；若要谈保持或迁移，还需要延迟和变式任务。当前这七张卡都没有 Prysai 学习者运行、独立评分或跨模型比较证据。

这是一组中文起步卡，独立语言审校仍待完成；它不是“万能提示词”。它没有跨模型运行记录，不能证明效率提升、学习效果、模型优劣或各平台行为相同。涉及文件、工具、浏览、账号、外部发布或真实数据时，先停下并转到相应的有来源平台说明。

- [ ] 我只使用了虚构、公开或获授权的文本。
- [ ] 我在收到完整答案前留下了自己的尝试或已知事实。
- [ ] 我检查了模型是否新增了事实、承诺或来源。
- [ ] 我知道本次结果不能证明效率、掌握、流利或模型优劣。
- [ ] 需要文件、浏览、外部行动或敏感资料时，我已经停止并换到有边界的流程。
