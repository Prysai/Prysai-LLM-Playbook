## 先按目的选：语言练习、工作表达或研究核查

你不需要从第一张开始。只选今天最接近的一类：想把工作说清楚时先看 B；想核对一项说法或判断能不能分享时看 C；只有想练外语时才看 A。

**如果你只是第一次来、也不打算练西班牙语：先从 B 的第 3 张开始。** 它会让你把已有要点整理成一条可发送、但不凭空补事实的工作更新。A 区只是用西班牙语演示“先尝试，再要一处有限反馈”的练习方法。

## A. 可选外语练习（只在你想练西班牙语时使用）

### 1. 可选外语示例（西班牙语）：先自己开口，再要纠错

预期：先保留你的原句，再拿到一条有限、可检查的纠错。不要让模型一开始就替你完成对话。

```text
我想用虚构信息练习用西班牙语确认学习小组的时间。请只扮演同学，不要示范答案。

条件：可用信息是 [Ana、学习小组、周二或周四、6:00 或 6:30、图书馆或线上、带一个问题]。
目标：我会先用西班牙语写一句不超过 12 个词的话。

等我回复后，请：
1. 只指出最影响理解的一处问题；
2. 用中文解释原因；
3. 给我一个提示，不直接替我重写整句；
4. 等我自己改写。
```

### 2. 西班牙语：把同一能力换一个场景

预期：练习“提出一个简单请求”，而不是背上一轮的标准答案。

```text
继续刚才的练习，但把场景改成确认作业计划：我要问我该准备哪一部分，并澄清初稿是周二还是周四交。
请不要复用我的原句，也不要先给提示。

先让我自己写一句。我的句子出现后，请按“能否被对方理解”给出通过 / 需要修改，
并最多指出一处需要修改的地方。不要把这次结果称为流利、掌握或语言等级。
```

## B. 推荐从这里开始：工作表达与判断

### 3. 工作表达：把散乱要点变成可发送的更新

预期：同一批事实可以有不同语气；模型不能替你补出不存在的进度。

```text
请把下面的工作要点整理成一条发给 [同事 / 客户 / 负责人] 的更新。

原始要点：
- [事实 1]
- [事实 2]
- [仍不确定的事]

要求：
- 先列出你从原始要点中能确认的事实；
- 不要补充日期、承诺、完成状态或原因；
- 给出一个不超过 120 字的版本和一个更正式的版本；
- 最后列出我发送前必须自己确认的两件事。
```

### 4. 工作判断：先问清楚，再给建议

预期：当关键条件缺失时，一个好回复会先暴露未知，而不是装作已经知道答案。

```text
我需要在 [选项 A] 和 [选项 B] 之间做一个小决定。
我的目标是：[目标]。
目前知道：[事实]。
目前不知道：[未知]。

请不要直接替我决定。先问最多三个会改变结论的问题；
然后给我一个两列表格，分别写“现有证据支持什么”和“仍不能判断什么”。
如果缺少关键事实，请明确建议我暂停，而不是猜测。
```

## C. 研究与分享前核查

### 5. 研究起步：把“大问题”缩成一个可核查的问题

预期：你先得到研究计划，而不是一篇看起来很完整、却无从核查的结论。

```text
我想弄清这个问题：[问题]。
这个问题将帮助我做出的决定是：[决定]。
我目前只接受这些来源类型：[例如官方文档、论文、机构报告]。

请不要回答这个问题，也不要编造来源。
请帮我写出：
1. 一个更小、可核查的问题；
2. 第一条需要核查的主张；
3. 该主张最可能的来源所有者；
4. 找不到来源时的停止条件。
```

### 6. 研究核对：让来源支持一句具体的话

预期：链接存在不等于它真的支持你的结论；模型的任务是帮助你准备核对表。

```text
我要检查下面这句话是否被我提供的材料支持。

主张：[一句具体的话]
材料摘要或原文摘录：[只放你有权分享的公开内容]
来源链接或出处：[链接 / 书目]

请把结果分成三栏：
- 材料直接支持的部分；
- 材料没有说明或与主张不一致的部分；
- 我需要亲自打开原始来源再核对的部分。

不要把没有打开过的链接称为已验证，也不要补写缺失事实。
```

### 7. 分享前检查：先缩小内容和对象，再决定是否发送

预期：先分清“我想分享什么”和“我被允许分享什么”。这张卡只帮你整理判断，不会替你上传、发送或公开内容。

```text
我考虑分享一段 AI 回答或聊天摘录。
我想达到的目的：[例如请同事核对一段措辞]。
可能的收件人：[角色或群体]。
我准备分享的内容：[一句话描述，不贴秘密或私人资料]。
我明确不会分享：[客户资料、密码、完整聊天记录、未公开文件等]。

不要发送、上传或生成链接。请先给我：
1. 这次目的所需的最小摘录；
2. 发送前必须由我确认的对象、内容和授权；
3. 哪些未知情况应让我停止，而不是默认可以分享。
如果我没有说明收件人或授权，请只建议暂停并补充哪一项。
```

<span id="practice-route-chooser"></span>

## 先选一条路线，不要一次做完全部

如果你还没有明确今天要做什么，先回答一个更小的问题：你要练习一项
技能、整理一条工作信息，还是核对一个可引用的说法？只选一条路线，做
一次有记录的尝试；这张入口卡不会替你制定课程，也不会替你做决定。

<span id="request-escalation"></span>

### 先判断你需要哪种帮助

```text
我现在要完成的一个小结果是：[结果]。
我已经有的材料是：[事实、文字或链接；没有就写“没有”]。
我希望你先做哪一件事：[改写 / 提问 / 给出练习 / 制定核查步骤]。
不要补充我没有提供的事实，也不要访问、发送或修改外部内容。
如果这不是文字范围内的问题，请告诉我缺少什么并停下来。
```

如果这段请求同时要求“查最新资料”和“更新公开页面”，先拆成两个任务：
先核查来源，再另写一个带目标、受众、授权和回滚的行动协议。引用本身
不是发布许可。

<span id="first-practice-intake"></span>

### 把愿望缩成一次可检查的尝试

```text
我的愿望是：[例如“学会西班牙语”]。
请只问我一次一个问题，直到可以形成一项低风险、十分钟内能尝试的表现：
1. 我需要实际做出的动作；
2. 我现在先自己试什么；
3. 允许你提供哪一种帮助（问题、提示、例子或复核）；
4. 我会检查什么；
5. 失败时更小的替代动作是什么。
不要替我宣布掌握、流利或已经完成。
```

<span id="four-line-safety-card"></span>

## 高级：边界卡（分享、搜索或行动前）

在任务涉及外部材料、文件、工具或真实账号前，先让模型填这张卡。卡片
本身不授予权限；缺字段时应停下，而不是猜测。

```text
目标和不做什么：
要读取的输入及其来源：
允许改变的确切文件或对象：
不会读取、发送或保存的数据：
预期结果和验收证据：
停止条件：路径、授权、来源或证据不清楚时停止。
```

<span id="share-check"></span>

### 分享前检查：先缩小对象和受众

```text
我考虑分享：[一句话描述，不粘贴隐私或秘密]。
目的：[让谁核对什么]。可能的受众：[角色或群体]。
请给出实现这个目的所需的最小摘录，并列出我必须亲自确认的
对象、内容、授权和渠道。不要发送、上传或生成链接。
如果受众、授权或内容边界缺少一项，请只标记为未知并停止。
```

<span id="public-interest-safety-route"></span>

## 高级：公共利益安全询问

当一个 AI 想法可能影响求职、教育、医疗、福利或其他真实群体时，先做
一个虚构案例，不要放入真实个人资料：

```text
虚构系统要帮助[角色]做出[一个决定]。
请分开列出：谁可能受益或受损、需要哪些最小数据、谁能复核或申诉、
哪些证据能支持这项决定，以及出现什么情况必须停止。
不要提出部署方案，不要调用服务，也不要把“模型建议”写成事实。
```

<span id="language-practice-route"></span>

## 路线 A：语言练习的四轮循环

先尝试，再只修正一处会影响理解的问题，换一个场景重新做一次。保留原
句和修改后句子；一次对话不能证明流利或听说能力。

<span id="general-skill-practice-route"></span>

## 路线 B：一项可观察的非语言技能

```text
我想练习：[解释一个概念 / 做一次汇报 / 回答一个面试问题]。
请先让我在计时[分钟]内完成一次，不要先给范文。
完成后只按这三项检查：目标是否说清、证据是否足够、听众能否采取下一步。
只指出最影响结果的一处问题，再给我一个变式情境让我重做。
不要把一次表现称为掌握，也不要替我编造经历。
```

<span id="bounded-research-route"></span>

## 路线 C：围绕一个决定做有限研究

```text
我要做的决定是：[决定]，截止时间和地区是：[范围]。
请先写出一个可核查的问题、三类优先来源和停止条件。
每条主张都记录来源负责人、原始/最终 URL、位置、日期、范围和未知项。
不要把搜索摘要、论坛经验或没有打开的链接当成已验证证据。
```

<span id="source-check-route"></span>

### 来源检查：让一句话和一段原文对得上

```text
主张：[一句原子化的话]
原始来源或已授权摘录：[内容]
请分三栏输出：直接支持、没有说明或相矛盾、我还需要打开核对的地方。
如果无法定位原文，请标记 citation_unverified，并降低结论范围。
```

<span id="recovery-route"></span>

## 高级：回答跑题后的恢复

保留原始请求、可见上下文、模型回复和你期待的结果。只改变一个沟通条件
（例如先列输入，或限制输出格式），再做一次低风险比较。不要用更长的
提示词掩盖原因；如果需要新文件、权限、网络或外部行动，就停止并重新
写任务协议。

<span id="card-e1-user-declared-continuity-receipt"></span>

### 连续性收据：开启新一轮前先写清楚

```text
原任务和不变的限制：
上一轮真正读取或完成的输入：
上一轮的可验证输出：
仍未知、失败或未执行的部分：
这一轮唯一要检查的变化：
停止条件和下一位复核者：
```

这张收据是用户声明的上下文，不是模型记忆或权限证明。它不能证明上一轮
真的执行过，也不能把一个新账号、新分支或新受众自动纳入原授权。

## 只做四步，别把第一次练习做复杂

1. 选一张与今天最接近的卡。
2. 先写出你自己的短尝试，或填入你已知的事实。
3. 把回答和你的原始版本并排看，检查它是否越过了你的限制。
4. 留下一个最小记录：任务、原始尝试、使用的帮助、你最终保留的版本、仍未知的部分。

如果模型给出的是完整答案而你本来想练习，请要求它退回到“一条提示”；如果它编造事实、来源或承诺，请停止使用该回答，并把未核查部分保留为未知。

## 练习记录：把一次对话留下来

完成任意一张卡后，只保留这一小段记录。它让你下次能看清自己练了什么，也避免把“我觉得有用”误写成已经证明的结论。

```text
任务：
我的第一次尝试或已知事实：
AI 提供的帮助（提示 / 纠错 / 资料规划）：
我保留的版本：
我亲自检查的内容：
仍未知或有争议的内容：
状态：template_selected | practised | not_run | blocked
```

`practised` 只表示保存了一次有记录的练习；它不表示已经流利、掌握、提高效率，也不表示来源已经完整核实。

## 这次练习算完成了吗？

完成一张卡，最多只能说明你保存了一次带条件的尝试。若想说“我在这项任务上表现出来了”，还需要预先写好的标准和可检查的结果；若要谈保持或迁移，还需要延迟和变式任务。当前这七张卡都没有 Prysai 学习者运行、独立评分或跨模型比较证据。

这是一组中文起步卡，独立语言审校仍待完成；它不是“万能提示词”。它没有跨模型运行记录，不能证明效率提升、学习效果、模型优劣或各平台行为相同。涉及文件、工具、浏览、账号、外部发布或真实数据时，先停下并转到相应的、有来源的平台说明。

- [ ] 我只使用了虚构、公开或获授权的文本。
- [ ] 我在收到完整答案前留下了自己的尝试或已知事实。
- [ ] 我检查了模型是否新增了事实、承诺或来源。
- [ ] 我知道本次结果不能证明效率、掌握、流利或模型优劣。
- [ ] 需要文件、浏览、外部行动或敏感资料时，我已经停止并换到有边界的流程。

## 来源与边界

这些提示卡是 Prysai 的原创练习材料。其设计边界和来源记录目前只保存在语言中立研究档案中，因此本中文阅读路线不直接打开它们。这些记录解释为何采用“先尝试、再限制性反馈、最后留记录”的候选设计；它们不证明提示卡、模型或课程的效果。
