# Case evidence

`assets/cases/` stores rendered artifacts from the disposable examples under
[`examples/`](../../examples/). Each image is evidence for a narrowly stated
claim, not a product screenshot gallery.

The current image documents a local static render at the recorded viewport. It
does not establish live data, customer demand, market performance, a runtime
Skill invocation, or production readiness.

## Evidence rule

Keep the source page, capture conditions, and limitation statement together.
Do not replace a source record with a screenshot, and do not use a polished
image to hide an unverified workflow.
