# Assets

This directory contains project-owned visual material used to teach a concept
or document a bounded case. It is not a general image dump.

## Start here

- Read the [asset register](../docs/sources/asset-register.md) before adding,
  adapting, or distributing an asset.
- Open [`teaching/`](teaching/) for original diagrams used in the book and
  public showcase.
- Open [`cases/`](cases/) for screenshots and other evidence from disposable
  local sandboxes.

## Evidence boundary

A diagram explains a relationship. A screenshot proves only the recorded
rendering conditions. Neither one proves that a Skill ran, that a customer
approved the result, or that a feature is production-ready. Keep the source,
viewport, date, and known limits beside any case evidence.

## Adding an asset

1. Decide whether it is teaching material or case evidence.
2. Record its origin, license, attribution, and distribution decision in the
   asset register.
3. Use a descriptive filename and an accessible alt description at every
   reader-facing link.
4. Run the relevant link, structure, and visual checks before publishing.
