# Branding assets

This directory contains the Prysai Lab marks supplied by the project owner
for the Codex Field Guide reading surface.

## Files

- `prysai-lab-mark-black.png` — use on light surfaces.
- `prysai-lab-mark-white.png` — use on dark surfaces.
- `prysai-lab-mark-black-512.png` and `prysai-lab-mark-white-512.png` —
  512px display derivatives for larger page surfaces.
- `prysai-lab-mark-black-96.png` and `prysai-lab-mark-white-96.png` — compact
  display derivatives for favicons, headers, and footers.

The two 8334px files are retained as supplied master assets. The smaller PNGs
are display derivatives cropped to the visible mark with transparent padding;
they are used so a 34–40px header does not ask a browser to decode an 8334px
image. The source dimensions, hashes, permission boundary, and distribution
decision are recorded in [`docs/sources/asset-register.md`](../../docs/sources/asset-register.md).
These are brand marks, not teaching diagrams or evidence of a product runtime.
