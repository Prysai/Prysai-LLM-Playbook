**状态：** `candidate`
**版本：** `0.1.0`
**维护者：** `curriculum-maintainer`
**复核日期：** 2026-08-17
**下一次复核：** 2026-09-17

## 这份契约解决什么问题

Prysai LLM Playbook 同时包含通用方法、Codex 实践、Skills、研究记录和团队治理。
这些材料可以继续存在，但不能共同充当初学者的第一课。本契约定义默认课程的最小
边界：先让没有开发背景的人理解 LLM 的工作边界，完成一次低风险对话，检查一次
不可靠输出，再在未见任务中独立复现这个检查循环。

这是课程的产品契约，不是学习效果证明。`candidate` 只表示结构和静态检查正在建立；
真实学习者完成、迁移、长期记忆和跨模型表现仍为 `not_run`。

## 首要学习者

已经使用过 ChatGPT 或相似聊天产品，但不知道为什么答案会出错，也没有稳定检查
习惯的成年人。课程不要求 Codex、Git、终端、付费账户、文件上传或外部连接。

开发者、研究者、团队负责人和平台适配器用户属于后续路线。它们可以从课程中链接出去，
但不能成为完成核心课程的前置知识。

## 五项核心结果

完成核心路线只允许使用以下可观察表述：

1. **解释：** 学习者能用自己的话说明 LLM 根据上下文生成输出，流畅不等于真实，
   模型、产品、工具和 Agent 不是同一个东西。
2. **发起：** 学习者能写出包含目标、必要上下文、约束和输出形式的简短请求。
3. **识别：** 学习者能在固定示例中标出遗漏、无依据添加、歧义强行补全或过度自信，
   并指出原文证据。
4. **修正：** 学习者能用 `PASS / FAIL / UNSURE` 对照检查，保留原始尝试，做最小修正，
   并写出一句仍未证明的限制。
5. **迁移：** 学习者能在没有完整 Prompt 或答案模板的未见任务中，独立完成
   `定义 → 尝试 → 检查 → 修正 → 限制`，并记录获得的帮助。

## 核心路线边界

```text
LLM 是什么
  → 上下文与第一次生成
  → 识别可见失败
  → 检查、修正与限制
  → 未见任务综合实践
```

每个单元必须同时提供：一个简短解释、一个低风险操作、一个失败或边界例子、一个
学习者产物和一个可检查的结束条件。只读完页面、复制 Prompt、获得模型的正确答案，
都不能单独算作完成。

## 允许的第一轮实践

- 纯文本、虚构或公开无敏感内容；
- 无文件、Git、终端、浏览器、账号连接、凭据、购买、发布、发送或删除；
- 可以使用任意文本聊天模型，记录模型名称/界面（若可见），不把一次输出推广成模型结论；
- 必须保留学习者的第一次尝试和修正后的版本；
- 缺少输入、需要现实世界事实、涉及隐私或出现不可解释的副作用时停止并记录 `blocked`。

## 明确不属于核心课程

以下内容保持可访问，但在核心路线中标为 `advanced`、`reference` 或 `experimental`：

- Codex 安装、文件编辑、终端、浏览器、GitHub 和外部服务；
- Plugin、MCP、Skill 设计/安装、多 Agent 编排和团队治理；
- 工程、研究、营销、语言学习等应用路线；
- 额外平台适配器、价格/额度/界面事实和新的语言扩张。

在核心课程完成首轮学习者观察前，不新增这些类别的内容。安全修复、事实错误、断链、
隐私/许可证问题和数据损坏是冻结规则的例外。

## 课程完成声明

课程只能在同时具备五个单元产物、未见任务记录和辅助披露时写成
`core_route_completed_on_this_task`。该状态不表示掌握、长期保留、生产力提升、
职业能力、跨领域迁移或任何平台等价。

## 证据边界

当前契约支持的是内容身份、顺序、产物字段和静态路由检查。它不支持以下声明：

- 学习者已经学会或会长期记住；
- Prompt 对所有模型有效；
- 课程比其他教程更有效；
- 课程降低了真实事故或提高了生产力；
- 八种入口语言已登记；独立母语审校尚未完成，法语仍处于 `in-progress`。

## 来源与维护

稳定原则来自本仓库 `CONTEXT.md`、`docs/book-architecture.md`、`docs/charter.md` 和
现有第一方/学术来源记录。平台事实仍必须进入对应的来源回执，不得从本契约推断。

`docs/governance/core-course.yaml`、评分 rubric 和本契约的版本/复核日期。
