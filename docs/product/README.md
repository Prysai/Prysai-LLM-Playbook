# Product Contracts

This directory contains human-readable contracts for the product's audience,
default learning promise, and release scope. It does not promote a page,
chapter, Skill, or platform beyond the status recorded by governance files.

| Contract | Purpose |
|---|---|
| [`core-course-contract.md`](core-course-contract.md) | Defines the five beginner learning results, allowed first practice, and claim boundary. |

The machine-readable route and asset classification live under
[`../governance/`](../governance/). Change the contract before changing a
public default; then update the route, tests, and status evidence together.
