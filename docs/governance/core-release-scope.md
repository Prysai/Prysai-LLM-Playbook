# 核心课程范围冻结

**生效：** 2026-08-17
**适用范围：** Prysai LLM Playbook 核心课程 v1 candidate

## 默认规则

在核心课程完成两轮学习者观察之前，工作优先改善五项核心学习结果：解释、发起、
识别、修正和迁移。新内容必须同时写明对应结果、学习者产物、失败边界和验证方式；
只增加目录数量、平台名称、Skill 数量或译文文件数量的工作不进入当前里程碑。

## 暂停新增

- 章节、Lab、Skill、平台适配器和专业轨；
- 非核心治理契约、视觉装饰和 SEO 扩张；
- 把 Codex、Agent、MCP、Plugin 或 Skill 放入 LLM 基础前置路径；
- 以文件覆盖率、CI 通过、Prompt 长度或模型输出数量代替学习证据。

## 仍然允许的维护

- 修复事实错误、断链、路径错配、无障碍缺陷和数据损坏；
- 修复隐私、凭据、许可证或外部内容边界；
- 让既有高级内容明确标记为 `advanced`、`reference` 或 `experimental`；
- 为核心课程建立必要的正文、练习、学习产物、评分夹具和浏览器门禁；
- 修订已经由学习者观察或评分分歧直接指出的问题。

## 提交准入记录

每个非维护性变更的提交说明或变更记录必须回答：

```text
core_outcome: explain | initiate | identify | repair | transfer
learner_artifact: <what the learner keeps>
failure_boundary: <what makes the task stop or downgrade>
verification: <focused command, fixture, or observation>
scope_class: core | advanced | reference | experimental
```

没有这些字段的新增教学内容应退回规划阶段。字段是审查线索，不是学习效果证明。

## 解冻条件

只有在以下事实都被记录后，才可以恢复横向扩张：

1. 核心五单元能够从公开入口连续运行，且每单元都有产物和结束条件；
2. 至少 5 名独立目标学习者完成首轮观察，记录耗时、卡点、帮助和退出；
3. 至少两名评分者独立使用同一 rubric，并保留分歧；
4. 第二轮使用未接触过首轮版本的学习者，且结果没有被写成普遍效果；
5. 恢复项有负责人、用户需求、维护成本和独立验证计划。

## 停止条件

出现以下任一情况，停止当前扩张并回到核心路线：

- 两名学习者对同一任务产生不兼容理解；
- 课程需要维护者口头补充才可完成；
- 核心任务要求私人资料、特定付费产品或外部副作用；
- 评分者无法区分“模型答对”和“学习者完成检查”；
- 新增工作继续增加目录，却没有改善五项结果之一。
