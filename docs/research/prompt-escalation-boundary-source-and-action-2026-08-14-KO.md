# 간단한 프롬프트로 부족할 때: 출처와 행동의 전환 경계

**상태:** 연구 후보 / `not_run`

**확인일:** 2026-08-14 (America/Los_Angeles)

**담당자:** curriculum-maintainer

**다음 검토:** 2026-11-14. 이 경계를 학습자 카드로 만들거나, 학습자에게 평가하거나, 특정 제품에 대한 주장에 사용하기 전에도 다시 검토합니다.

## 질문과 범위

초보자가 일반적인 텍스트 프롬프트와 출처 기반 조사 또는 감사 가능한 작업 프로토콜이 필요한 일을 구분하려면 어떤 최소 판단이 필요한가요? 이 기록은 첫 번째 경로 선택만 다룹니다. 독자가 제공한 텍스트를 바꾸거나 논의하는 요청, 외부 세계에 대한 중요한 사실을 주장하는 요청, 파일·계정·공유 시스템·게시물·기타 외부 상태를 바꾸는 요청이 섞일 때 어디로 보낼지 정합니다.

일반 프롬프트 형식을 정하지 않고, 모델을 비교하지 않고, 출처를 검증하지 않고, 작업을 실행하지 않고, 학습자를 평가하지 않습니다. 이 문서는 일반 LLM 협업 핵심의 경계이지 특정 플랫폼 어댑터가 아닙니다.

## 방법과 출처 선택

현재 OpenAI 개발자 문서와 NIST 출판물이라는 1차 지침만 남겼습니다. OpenAI 페이지는 제품에 한정되고 변할 수 있으며, NIST 출판물은 프롬프트 안내서나 모델 테스트가 아닌 위험 프로필입니다. 두 자료 모두 읽기만 했습니다. 계정, API 요청, 모델 대화, 학습자 세션, 출처 조회, 작업 실행은 하지 않았습니다.

프로젝트의 추론은 보수적입니다. 제공된 자료만으로 결과를 확인할 수 있고 현재 외부 사실이나 외부 행동이 필요하지 않을 때만 간단한 프롬프트를 사용합니다. 어느 조건이든 맞지 않으면 전환합니다. 긴 프롬프트가 위험하거나 전환이 정답을 보장한다는 뜻은 아닙니다.

## 초보자 문제의 좁은 형태

“이 정책은 아직 유효한가요? 요약하고 공개 도움말 페이지를 업데이트해 주세요.”라는 요청은 현재 외부 사실과 게시 행동을 한 번에 섞습니다. 문장이 그럴듯해도 출처 담당자, 날짜, 권한, 대상, 수용 증거가 비어 있을 수 있습니다. 빈도를 측정하는 조사나 공개 사용자 표본은 없으므로 이는 프로젝트가 만든 교육 시나리오이지 발생률 주장이 아닙니다.

## 짧은 라우팅 테스트

첫 요청 전에 일상적인 말로 두 가지를 묻습니다. (1) 내가 제공한 글과 사실만으로 결과를 판단할 수 있는가? (2) 현재 외부 사실이 필요하거나 대화 밖을 바꾸는가? 첫째가 예이고 둘째가 아니면 텍스트 프롬프트로 시작할 수 있습니다. 중요한 외부 사실은 출처 경로로, 외부 행동은 작업 계약으로 보냅니다. 둘 다 있으면 출처 탐색과 행동 권한을 분리하고 인용처럼 보이는 답변이 변경을 승인하게 두지 않습니다. 의료·법률·금융·고용·교육·주거·이민·보험·개인 안전 질문은 적절한 사람이나 분야 전문가의 검토가 필요하며 이 기록은 그 검토를 제공하지 않습니다.

## 실패 경계와 수용 증거

실패 사례: 한 번에 “현재 규칙을 확인하고 업데이트를 보내 주세요”라고 요청합니다. 모델은 자신 있는 문단과 링크를 반환하지만 출처 담당자, 확인 날짜, 근거 위치, 게시 대상, 전송 권한을 알 수 없습니다.

가장 작은 안전 복구는 보내지 않은 초안을 보존하고 출처 질문과 행동 제안을 나눈 뒤, 선택한 경로에서 입력이 빠진 지점에서 중지하는 것입니다. 모델에게 권한을 만들어 내라고 하지 말고 열 수 없는 페이지를 증거로 쓰지 않습니다.

후보 수용 조건은 독자가 목표 결과, 외부 주장의 중요성, 외부 행동의 유무, 선택한 경로, 중지 조건을 가리킬 수 있는 것입니다. 출처·출력·행동·학습 결과를 검증하는 조건은 아닙니다.

## 기존 자료와의 경계

이 기록은 first-turn, research, source, task 계약을 대신하지 않습니다. 간단한 프롬프트는 제공된 텍스트를 변환·논의하고, Source Investigator는 제한된 현재 출처 질문을 다루며, Research Router는 미해결·다중 출처 연구 설계를 다루고, Task Protocol은 권한·부작용·수용 증거·복구를 다룹니다. 새 Skill, 카드, 장, Lab, 등록 항목, 평가 fixture, 독자용 주장은 제안하지 않습니다.

## 한계, 공개, 다음 증거

이 문서는 Prysai가 작성한 원문입니다. 출처는 증거 링크로만 연결했으며 외부 프롬프트·코드·교육 자료를 복사하지 않았습니다. 초보자가 경계를 알아보는지, 모델이 올바르게 라우팅하는지, 인용이 유효한지, 경로가 안전과 성공을 높이는지는 증명하지 않습니다.

독자용 교육 자료로 만들기 전에 사전 정의된 저위험 학습자 관찰을 실시합니다. 최초 요청, 선택 경로, 이유, 미해결 필드, 걸린 시간, 참여자가 계획이나 인용을 실행 증거로 착각했는지를 남깁니다. 관찰이 더 좁은 주장을 뒷받침할 때까지 `candidate`로 유지합니다.
