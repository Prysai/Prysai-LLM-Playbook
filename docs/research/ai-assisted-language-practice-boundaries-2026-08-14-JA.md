# 文字のリハーサルは口頭会話ではない：LLM を使った語学練習の境界

**状態：** 候補の調査記録。学習者セッション、モデル実行、音声サンプル、採点練習、結果評価はまだ行っていません。

**閲覧日：** 2026-08-14（America/Los_Angeles）  
**判断責任者：** Prysai Lab カリキュラム担当  
**次回レビュー：** 2026-11-14。口頭練習、モデルのフィードバック、評価について読者向けの主張にこの記録を使う場合も、その前に見直します。

## 問いと範囲

**問い：** 初心者が一般的なテキスト型 LLM で第二言語のロールプレイをするとき、文字入力での成功やモデルのフィードバックを口頭会話の証拠と取り違えずに、残った証拠をどう呼べるでしょうか。

対象はテキストだけのやり取りです。学習者が指示を読み、返答を入力し、生成された文章を受け取ります。音声機能、音声認識、発音、特定の言語や製品、教師としての LLM、学習成果は評価しません。

これは、範囲を限定した練習や短いプロンプト数を扱う既存記録とは別の問題です。それらの練習手順、公開レポート、一般的な「流暢さは証明できない」という境界を繰り返しません。文字のロールプレイを会話練習と呼ぶときに欠ける、**モダリティに合った証拠**だけを扱います。

## 出典に基づく初心者向けの含意

残した証拠が示せるものとして、テキストのやり取りを**明示した支援条件のもとで、指定した一つの言語機能を文字でリハーサルしたもの**と呼びます。成果物には学習者の入力、モデルの候補修正、学習者が自分で書いた改訂を含められますが、話を聞き取ったか、発音したか、速度に対応したか、口頭の誤解をその場で修復したかは直接記録しません。

これは O1–O3 から導いたプロジェクトの推論であり、学習結果ではありません。別のプロンプト方式を増やさず、短いレシートで境界を見えるようにできます。

| レシート項目 | 記録する値 | そこから推測しないこと |
| --- | --- | --- |
| モード | `typed rehearsal` | 口頭の相互作用、発音、聴解能力 |
| 目標 | 電車の時刻を尋ねるなど、一つの書き言葉の機能 | 一般的な言語レベル |
| 支援 | 分かる場合はモデル名/バージョン、フィードバック、確認した外部資料 | 流暢または自信のあるフィードバックが正しいこと |
| 成果物 | 元の入力と学習者が作った改訂 | 独立した口頭パフォーマンス |
| 未観察 | 別に記録しない限り、発話、音声理解、ペース、ライブでの修復 | 欠けた証拠が成功裏に起きたこと |

目標が**口頭**会話になったら、主張を変える前に証拠の面を変えます。適切な同意を得た音声またはライブ対話のサンプルを取り、口頭の目標を定め、その目的に合うレビュー方法を使います。重要な配置、資格認定、教育上の判断では、一般 LLM のフィードバックは評価結果ではありません。目的と証拠は適切な専門家のレビュー経路に渡します。

## 失敗シナリオ

初心者がイタリア語のレストランで四往復のやり取りを入力しました。モデルは返答が自然で、もう会話できると伝えます。学習者はその称賛を、普通の速度で話す店員を理解できる証拠だと受け取ります。

保存したチャットではその結論を支えられません。あるのは文字の産出と生成されたフィードバックだけで、口頭の質問を聞いたことも、聞こえる返答をしたことも記録されていないからです。O1 に照らせば、訂正自体にも自信のある誤りがあり得ます。責任あるレシートは `typed_rehearsal_observed; feedback_unverified_for_assessment` で、口頭の聴解と発話は `not_observed` のままです。

## 言わないこと

この記録は、文字のロールプレイが語学学習を改善・悪化させるか、練習として役に立たないか、文字で成功した学習者が話せないか、文字で苦労した学習者が話せないか、特定のフィードバックや文法訂正、確信表明、生成ルーブリックが誤りか、音声・人のレビュー・テスト得点だけで流暢さや保持、実際のコミュニケーション、レベルを証明できるか、ETS や NIST の資料が Prysai のカード・モデル・語学プログラム・学習結果を検証するかを示しません。

## 次に必要な証拠

範囲を超えた主張には、対象となる初心者集団と言語機能を明示した承認済み評価、テキストと音声に対する同意・最小化ルール、文字と口頭を分けた課題、事前に定めた支援とルーブリック、元の成果物、適切なレビュー担当者、各結果の解釈が必要です。持続性や転移を見るなら、後日の課題と明確な主張の境界も必要です。これらの証拠はまだありません。

## 出典とライセンスの境界

外部資料は所有者に帰属し、ここではリンクと限定的な要約だけを使います。外部の文章、評価項目、プロンプト、画像、音声、データセット、専有の採点手順はコピーしていません。O1 は公式技術プロファイル、O2 は一つの評価機関の現在のウェブ資料、O3 はオープンアクセスのテスト基準です。引用しても再利用権は得られません。

## 停止レシート

生成出力の誤りリスク、語学評価プログラムが技能の面を区別する資料、スコア解釈の根拠を確認したところで調査を停止しました。公開レポートを根拠に昇格させず、モデル、学習者、音声機能、評価はテストしていません。教材上の含意は、文字型 LLM の会話を文字リハーサルと表示し、対応する証拠が得られるまで口頭会話の能力やフィードバックの妥当性を主張しないことに限ります。
