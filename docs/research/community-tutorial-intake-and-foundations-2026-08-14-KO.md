# 커뮤니티 튜토리얼 수용: 초보자를 위한 더 나은 시작이지, 제품 출처가 아님

**상태:** `candidate` 연구 기록.  
**결정:** 제공된 커뮤니티 튜토리얼은 `reference-only` 신호로만 보존합니다. 플레이어를 삽입하거나, 대본을 복사하거나, 스크린샷을 재사용하거나, 현재 제품 동작의 근거로 사용하지 않습니다.

## 이 기록이 뒷받침하는 결정

제공된 Bilibili/BibiGPT 자료에는 유용한 편집 강점이 하나 있습니다. 익숙한 이름으로 시작해 처음 온 독자에게 계속 볼 이유를 주고, 컨트롤을 따로 나열하는 대신 하나의 구체적인 프로젝트를 따라갑니다. 이것은 교육 패턴이지, 표현을 재사용할 허가나 현재 제품 주장의 근거가 아닙니다.

이 기록은 좁은 질문에 답합니다. **자체 문장, 출처, 증거를 정직하게 유지하면서 이 교육 패턴에서 무엇을 배울 수 있는가?**

답은 기능을 둘러보기 전에 관찰 가능한 질문 하나로 시작하는 것입니다.

> 언어 모델 도구가 끝났다고 말할 때, 결과를 믿기 전에 무엇을 확인할 수 있나요?

이 질문은 Codex, Claude Code와 다른 모델 보조 작업 표면에도 적용되지만 컨트롤, 권한, 지속성 또는 Agent 동작이 같다고 주장하지 않습니다.

## 공개 출처에서 얻을 수 있는 것과 없는 것

| 제공된 출처의 자료 | 프로젝트에서의 처리 | 이유 |
| --- | --- | --- |
| 익숙한 제품명에서 간단한 프로젝트로 이어지는 흐름 | **교육 패턴으로만 유지하고 처음부터 다시 씀** | 초보자에게는 계속할 구체적 이유가 필요하지만 표현과 연출은 복사할 수 없습니다. |
| 제품명, 요금제, 할당량, 단축키, 인터페이스 라벨 | **이 출처로 가르치지 않음** | 계정과 표면에 따라 바뀌는 사실이며 제공 자료는 해당 문서의 소유자가 아닙니다. |
| 권한 모드와 승인 동작 | **날짜가 있는 1차 출처로 sandbox와 승인의 원칙만 가르침** | 모드와 기본값은 바뀔 수 있습니다. 승인 검토자가 런타임 경계를 넓혀 주지는 않습니다. |
| 시각적 지시/주석 흐름 | **이름 붙은 컨트롤이 아니라 오래가는 원칙을 가르침** | 시각적 맥락이 필요할 때 관련 영역과 원하는 결과를 가리킵니다. 모든 표면에 같은 UI가 있다고 약속하지 않습니다. |
| 미리보기/저장 실패 이야기 | **제품 지침에서 제외** | 한 번의 증상 사례일 뿐입니다. 이 프로젝트는 재현하지 않았고 원인 확인도 없습니다. |
| Git 체크포인트, 범위를 정한 작업, 독립 검사, 중지 조건 | **제품과 무관한 방법으로 가르침** | 특정 공급업체의 흐름을 복사하지 않아도 유용한 관행입니다. |
| Skills, 플러그인, 외부 도구 | **정의는 현재 소유자 문서를 사용하고 행동·데이터 경계는 유지** | Skill은 권한 부여가 아니며 플러그인 목록도 외부 행동 실행을 증명하지 않습니다. |
| 스레드 편집·분기·보관, 자동화, 컴퓨터 제어, 모바일 사용 | **지정한 표면의 최신 어댑터 기록이 생길 때까지 제외** | 해당 제품 주장을 위한 현재 1차 실행 계약이 출처에 없습니다. |

## 현재 공식 경계 확인

다음 출처는 2026-08-14에 접근할 수 있었습니다. 페이지는 OpenAI가 관리하지만 주장은 명시된 제품 표면에만 적용되며, 이를 근거로 출시하기 전 다시 확인해야 합니다.

| 가르쳐도 충분히 안전한 주장 | 1차 출처 | 여전히 입증하지 않는 것 |
| --- | --- | --- |
| Codex 용어는 여러 표면에 걸치지만 각 표면의 구체적 기능에는 범위가 있습니다. | [OpenAI 용어집](https://learn.chatgpt.com/docs/glossary.md) | 학습자의 계정, 설치 버전, 권한 또는 성공적인 실행. |
| 유용한 요청은 목표, 맥락, 출력, 경계를 드러내며 시각 작업에서는 관련 영역을 가리키는 편이 좋습니다. | [OpenAI 프롬프팅 안내](https://learn.chatgpt.com/docs/prompting.md) | 요청이 성공한다는 것 또는 모든 클라이언트가 같은 주석 컨트롤을 제공한다는 것. |
| Sandbox는 접근 가능한 파일·네트워크 자원을 제어하고, 승인은 런타임이 멈추는 시점을 제어합니다. 검토자를 바꿔도 sandbox가 넓어지지 않습니다. | [OpenAI 권한](https://learn.chatgpt.com/docs/permission-modes.md) | 현재 기본값, 조직 정책 또는 특정 대상 권한. |
| Skill은 재사용 가능한 작업별 지침과 자원을 묶고, Plugin은 Skills와 커넥터를 묶을 수 있습니다. | [OpenAI Skills 및 Plugins](https://learn.chatgpt.com/docs/skills-and-plugins.md) | Skill 선택, 커넥터 인증, 외부 행동 완료. |
| 데스크톱 앱에서 Local과 Worktree는 별도 실행 위치이며 Worktree는 Git worktree에서 변경을 격리합니다. | [OpenAI Codex 환경](https://learn.chatgpt.com/docs/environments/modes.md) | 특정 동시 작업에 격리만으로 충분한지 또는 다른 플랫폼도 같은 모델을 쓰는지. |

이는 출처 확인이지 로컬 제품 실행이 아닙니다. 따라서 가이드는 `candidate` 상태를 유지하며 영상의 인터페이스, 요금제, 사용 가능성, 미리보기 동작, 모바일 흐름 또는 특정 기능 라벨에 대해 현재 주장을 하지 않습니다.

## 일반 과정의 독창적 도입부

다음은 현재 1장의 시작 부분에서 사용하는 독자용 방향입니다. 대본이나 번역이 아니라 프로젝트가 새로 작성한 내용입니다.

> Codex나 Claude Code 같은 이름을 들어 본 적이 있을 겁니다. 이는 더 큰 변화의 예입니다. 이제 언어 모델은 채팅 답변만 반환하는 것이 아니라 작업, 맥락, 때로는 도구와 함께 일할 수 있습니다. 컨트롤을 둘러보기 전에 나머지를 쉽게 만드는 질문 하나를 배워 보세요. 도구가 끝났다고 말할 때 실제로 무엇을 확인할 수 있나요?
>
> 첫 수업에서는 제품을 외울 필요가 없습니다. 제안된 행동과 허용된 행동, 도구 메시지와 대상의 변화, 그럴듯한 답변과 증거를 구분합니다. 여기서는 Codex를 대표 실습 경로로 깊이 다룹니다. 방법은 더 넓으며, 이름을 붙인 플랫폼은 버튼을 사실로 가르치기 전에 자체 어댑터를 갖춰야 합니다.

이런 도입부는 초보자를 초대하고 쓸 수 있는 정신 모델과 분명한 보상을 주면서, 근거 없는 “핵심 제품”, “최선의 선택”, “다른 제품의 직접 대응물” 같은 주장을 피합니다.

## 처음 10분: 약속 하나, 경계 하나

기초 수업은 모델, 유료 요금제, 플러그인 또는 권한 모드를 고르는 일부터 시작하지 않아야 합니다. 작은 약속 하나를 보여 줍니다.

1. **결과 하나를 이름 붙입니다.** 예: 허구 메시지에 사실을 추가하지 않고 다시 쓰거나, 파일 하나의 변경을 검사합니다.
2. **시작 자료를 보여 줍니다.** 모델에게 행동을 요청하기 전에 정확한 텍스트, 파일 또는 fixture를 보게 합니다.
3. **행동 경계를 말합니다.** 텍스트만, 읽기 전용, 또는 되돌릴 수 있는 변경 한 번인지 밝힙니다. 비밀과 외부 계정은 사용하지 않습니다.
4. **검사를 보여 줍니다.** 무엇이 유지되어야 하고, 무엇이 바뀌며, 무엇이 아직 unknown인지 말하게 합니다.
5. **멈춰도 안전하게 합니다.** 대상, 권한 또는 증거가 불명확하면 접근을 넓히지 말고 가장 작은 다음 검사를 남긴 채 멈춥니다.

기존 선택형 워밍업은 허구 원본 메시지로 이 패턴을 따릅니다. 1장 도입부는 이제 왜 이 작은 첫 결과가 긴 기능 목록보다 가치 있는지 설명합니다.

## 이름이 뜻하는 것: 일반 방법과 명시적인 대표 경로

콘텐츠는 두 층으로 설명해야 합니다.

- **일반 방법:** 결과를 정의하고 필요한 맥락만 선택하며 행동 경계를 정하고 증거를 확인한 뒤 복구하고 기록을 보존합니다.
- **대표 실습 경로:** 최신 1차 출처, 제한된 실행, 실패 증거, 검토 날짜가 있는 곳에서 Codex를 깊이 가르칩니다.

Claude Code와 다른 이름 붙은 시스템은 비교 또는 어댑터 후보이지 서로 바꿔 쓸 수 있는 대체품이 아닙니다. 보류된 제품명 권고와 단계적 전환은 [이름 전환 기록](../strategy/naming-and-positioning-transition-2026-08-14.md)에 남아 있습니다.

| 담당 및 검토 | 커리큘럼 담당자. 별도 라이선스가 있고 1차 출처와 관련된 자료가 편집 결정을 바꿀 때만 재평가합니다. |

## 이 기록이 입증하지 않는 것

이 수용 기록은 출처의 작성자, 대본 서비스, 요금제, 권한, 컨트롤, 미리보기 동작, 프로젝트 흐름, 자동화, 컴퓨터 사용, 모바일 사용 또는 결과가 정확하고 최신이며 재사용 허가가 있고 대표적이며 안전하거나 다른 플랫폼과 동등하다는 점을 입증하지 않습니다. 수정한 도입부가 이해, 완료, 유지, 전이 또는 프로젝트 채택을 개선한다는 점도 입증하지 않습니다. 그런 주장은 범위를 정한 학습자 연구가 필요합니다.
