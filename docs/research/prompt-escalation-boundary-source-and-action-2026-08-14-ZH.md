# 简单提示不够时：来源与行动的升级边界

**状态：**研究候选 / `not_run`

**访问日期：**2026-08-14（America/Los_Angeles）

**负责人：**curriculum-maintainer

**下次复查：**2026-11-14，或在将本边界做成学习卡、用学习者评估，或支持具体产品主张之前。

## 研究问题与范围

什么是面向初学者的最小判断，可以把普通的纯文本提示与需要来源支持的调查或可审计任务协议区分开？本记录只覆盖第一次路由选择，不是通用提示写作指南。它处理三类可能混在一起的请求：

1. 改写或讨论读者已经提供的文本；
2. 对外部世界提出有实质影响的事实主张；
3. 修改文件、账户、共享系统、发布内容或其他外部状态。

它不规定通用提示格式、不比较模型、不验证来源、不执行任务，也不评估学习者。它是通用 LLM 协作核心的路由边界，不是具体平台适配器。

## 方法与来源选择

本记录只保留一手指导：当前 OpenAI 开发者文档和一份 NIST 出版物。OpenAI 页面有产品范围且会变化；NIST 出版物是风险框架画像，不是提示指南或模型测试。两者都只读，没有运行账户、API 请求、模型对话、学习者会话、来源查找或任务执行。

本项目的推论保持保守：只有当读者能用已提供的材料检查结果，且不需要当前外部主张或外部行动时，才从简单提示开始。任一条件不满足就升级。这是课程路由决定，不是说长提示不安全，也不是说升级会保证正确。

## 狭义的初学者问题

“这项政策还有效吗？请总结它，并更新我们的公开帮助页。”同时包含当前外部事实和发布行动。答案即使写得很像样，也可能没有写清来源、日期、权限、目标和验收证据。本记录没有调查或公开用户样本来测量这种请求的频率，因此它只是项目定义的教学情境，不是流行度结论。

## 紧凑路由测试

第一次请求前，读者用日常语言回答：

1. 我能否只用自己提供的文本和事实判断结果？
2. 请求是否需要当前外部主张，或会改变对话之外的东西？

第一题是“是”、第二题是“否”时，纯文本简单提示可以是起点。需要重要外部事实就走来源路径；提出外部行动就同时走任务契约。两者都需要时，保持来源发现和行动授权分开，不能让带引用的答案悄悄授权修改。医疗、法律、金融、就业、教育、住房、移民、保险和人身安全等重要问题还需要合适的人类或领域审阅；本记录不提供这些审阅。

## 失败边界与验收证据

失败情境：读者一轮请求模型“确认当前规则并发送更新”。模型返回自信的段落和链接，但读者找不到来源负责人、访问日期、支持位置、发布目标或发送权限。

最小安全恢复：保留未发送草稿，把请求拆成来源问题和拟议行动，然后在相关路径的缺失输入规则处停止。不要让模型填补缺失的授权，也不要把打不开的页面当证明。

候选验收：读者能指出目标结果、外部事实是否重要、是否提出外部行动、选择的现有路径和停止条件。这里只检查路由决定是否写清，不验证来源、输出、行动或学习结果。

## 现有材料边界

本记录不替代现有的 first-turn、research、source 或 task 契约，只加入一个小区别：简单提示处理已提供的纯文本改写或讨论；Source Investigator 处理一个有界的当前来源问题；Research Router 处理未解决或多来源研究设计；Task Protocol 处理授权、副作用、验收证据与恢复。本记录不提出新 Skill、提示卡、章节、实验、注册项、评测夹具或读者主张。
