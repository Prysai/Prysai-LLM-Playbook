# 타이핑 리허설은 말하기 대화가 아니다: LLM 언어 연습의 경계

**상태:** 후보 연구 기록. 학습자 세션, 모델 실행, 오디오 샘플, 채점 연습, 결과 평가는 아직 진행하지 않았습니다.

**확인일:** 2026-08-14 (America/Los_Angeles)  
**결정 담당:** Prysai Lab 커리큘럼 담당자  
**다음 검토:** 2026-11-14. 이 기록으로 말하기 연습, 모델 피드백, 평가에 관한 독자용 주장을 뒷받침하려면 그 전에 다시 검토합니다.

## 질문과 범위

**질문:** 초보자가 일반적인 텍스트 기반 LLM으로 제2언어 역할극을 할 때, 타이핑 성공이나 모델 피드백을 실제 말하기 대화의 증거로 착각하지 않고 결과를 어떻게 설명할 수 있을까요?

이 기록은 텍스트 교환만 다룹니다. 학습자가 지시를 읽고 답을 입력한 뒤 생성된 텍스트를 받습니다. 음성 기능, 음성 인식, 발음, 특정 언어, 특정 제품, 튜터로서의 LLM, 학습 결과는 평가하지 않습니다.

이는 범위를 제한한 연습 및 짧은 프롬프트 기록과 구별되는 간극입니다. 그 기록의 연습 순서, 공개 사용자 보고, 일반적인 유창성 경계를 반복하지 않습니다. 타이핑 역할극을 회화 연습이라고 부를 때 빠지는 **양식에 맞는 증거**만 다룹니다.

## 증거 지도

공개 사용자 보고는 사용하지 않습니다. 출처는 참고용으로만 인용하며 원문, 평가 문항, 프롬프트, 자산은 복사하지 않았습니다.

| ID | 증거 유형과 소유자 | URL 및 확인일 | 뒷받침하는 범위 | 증명하지 않는 범위 |
| --- | --- | --- | --- | --- |
| O1 | 미국 국립표준기술연구소(NIST) 공식 기술 안내, *Artificial Intelligence Risk Management Framework: Generative Artificial Intelligence Profile* | [PDF](https://nvlpubs.nist.gov/nistpubs/ai/NIST.AI.600-1.pdf), 2026-08-14 확인 | NIST는 생성된 내용이 틀려도 부당하게 자신 있게 전달될 수 있는 confabulation을 설명합니다. 모델의 교정은 스스로 검증된 증거가 아니라 확인할 후보로 다뤄야 한다는 근거입니다. | 특정 교정이 틀렸다는 것, 모든 모델의 동작이 같다는 것, LLM이 저위험 연습에 쓰일 수 없다는 것. |
| O2 | 공식 평가 기관 자료, ETS *TOEIC Tests preparation materials* | [ETS 페이지](https://www.ets.org/toeic/test-takers/about/speaking-writing.html), 2026-08-14 확인 | ETS는 TOEIC 제품군에서 듣기·읽기와 말하기·쓰기를 구분한 자료를 제공합니다. 이는 한 평가 기관이 언어 능력의 표면을 구분하는 방식입니다. | 보편적인 능력 모델, 특정 학습자에 대한 주장, Prysai 활동의 타당성. |
| O3 | 전문 검사 기준, AERA·APA·NCME *Standards for Educational and Psychological Testing* | [공개 PDF](https://www.testingstandards.net/uploads/7/6/6/4/76643089/standards_2014edition.pdf), 2026-08-14 확인 | 이 기준은 점수 해석과 사용 목적을 근거로 뒷받침하도록 합니다. 따라서 타이핑 산출물의 해석을 좁게 유지해야 합니다. | 이 기록의 기록지, LLM 점수, 비공식 언어 활동이 검증된 평가라는 것. |

## 출처에 한정한 초보자용 결론

남겨 둔 증거가 보여 주는 만큼만 텍스트 교환을 부릅니다. **명시한 도움 조건에서 특정 언어 기능 하나를 타이핑으로 연습한 리허설**입니다. 산출물에는 학습자의 타이핑 답변, 모델의 후보 교정, 학습자가 직접 만든 수정본이 들어갈 수 있지만, 학습자가 말을 들었는지, 발음했는지, 속도를 처리했는지, 실제 말하기 오해를 즉시 해결했는지는 직접 기록하지 않습니다.

이는 O1–O3에서 나온 프로젝트 추론이지 학습 결과가 아닙니다. 새 프롬프트 방식을 추가하지 않고도 짧은 기록으로 경계를 보이게 할 수 있습니다.

| 기록 필드 | 이렇게 기록 | 여기서 추론하지 않음 |
| --- | --- | --- |
| 모드 | `typed rehearsal` | 말하기 상호작용, 발음, 듣기 능력 |
| 목표 | 기차 시간을 묻기처럼 하나의 쓰기 기능 | 일반적인 언어 수준 |
| 도움 | 알고 있다면 모델명/버전, 피드백, 확인한 외부 참고자료 | 유창하거나 자신 있게 들리는 피드백이 옳다는 것 |
| 산출물 | 원래 타이핑 답변과 학습자가 직접 쓴 수정본 | 독립적인 구두 수행 |
| 관찰하지 않음 | 별도로 수집하지 않은 말하기, 음성 이해, 속도, 실시간 복구 | 빠진 증거가 성공적으로 일어났다는 것 |

목표가 **말하기** 대화로 바뀌면 주장을 바꾸기 전에 증거 표면부터 바꿉니다. 적절한 동의를 받고 오디오 또는 실시간 상호작용 표본을 확보하고, 말하기 목표를 정하고, 그 목적에 맞는 검토 방법을 사용합니다. 결과가 중요한 배치·자격·교육 결정에서는 일반 LLM의 피드백을 평가 결과로 취급하지 않습니다. 목적과 증거는 적절한 전문가 검토 경로로 보내야 합니다.

## 실패 시나리오

초보자가 이탈리아어 식당 대화를 네 차례 타이핑했습니다. 모델은 답변이 자연스럽고 이제 대화할 준비가 됐다고 말합니다. 학습자는 그 칭찬을 보통 속도로 말하는 종업원을 이해할 수 있다는 증거로 받아들입니다.

저장된 채팅은 이 결론을 뒷받침하지 못합니다. 타이핑 산출물과 생성 피드백만 있고, 학습자가 말로 된 질문을 듣거나 들을 수 있는 답을 했다는 증거가 없기 때문입니다. O1에 따르면 교정 자체도 자신 있게 틀릴 수 있습니다. 따라서 책임 있는 기록은 `typed_rehearsal_observed; feedback_unverified_for_assessment`이고 말하기 듣기와 말하기는 `not_observed`로 둡니다.

## 하지 않는 주장

이 기록은 타이핑 역할극이 언어 학습을 개선하거나 해치거나 아무 영향이 없다는 것, 텍스트 교환이 리허설이나 준비에 쓸모없다는 것, 글로 성공한 학습자가 말할 수 없다는 것, 글로 어려움을 겪은 학습자가 말할 수 없다는 것, 특정 피드백·문법 교정·확신 표현·생성 루브릭이 틀렸다는 것, 오디오·사람의 검토·시험 점수 하나만으로 유창성·기억 유지·실제 소통·언어 수준을 증명할 수 있다는 것, ETS 설계나 NIST 안내가 Prysai 카드·모델·언어 프로그램·학습자 결과를 검증한다는 것을 증명하지 않습니다.

## 다음 증거

범위를 넘는 주장을 하려면 초보자 집단과 목표 언어 기능을 선언한 승인된 평가, 텍스트·오디오의 동의 및 최소화 규칙, 분리된 타이핑·말하기 과제, 사전 선언한 도움과 루브릭, 원본 산출물, 적합한 검토자, 결과별 해석이 필요합니다. 지속성이나 전이를 보려면 후속 과제와 명확한 주장 경계도 필요합니다. 이 기록에는 그런 증거가 없습니다.

## 출처와 라이선스 경계

외부 자료는 각 소유자에게 있으며 여기서는 링크와 제한적 요약만 사용합니다. 외부 텍스트, 평가 문항, 프롬프트, 이미지, 오디오, 데이터셋, 독점 채점 절차는 복사하지 않았습니다. O1은 공식 기술 프로필, O2는 한 평가 기관의 현재 웹 자료, O3는 공개된 검사 기준입니다. 인용한다고 재사용 권리가 생기지 않습니다.

## 중단 기록

생성 출력 오류 위험에 대한 주요 소유자 자료, 한 언어 평가 프로그램의 기능 표면 구분, 점수 해석 근거를 확인한 뒤 연구를 중단했습니다. 공개 보고를 증거로 격상하지 않았고 모델, 학습자, 음성 기능, 평가는 테스트하지 않았습니다. 교육적 함의는 텍스트형 LLM 대화를 타이핑 리허설로 표시하고, 일치하는 증거가 생길 때까지 말하기 대화 능력이나 피드백 타당성을 주장하지 않는 데 한정됩니다.
