# 文字排练不是口语对话：LLM 语言练习边界

**状态：** 候选研究记录；尚未进行学习者会话、模型运行、音频采样、评分练习或结果评估。

**访问时间：** 2026-08-14（America/Los_Angeles）  
**决策负责人：** Prysai Lab 课程维护者  
**下次复核：** 2026-11-14；如果要用本记录支持面向读者的口语练习、模型反馈或评估主张，也应提前复核。

## 问题与范围

**问题：** 初学者用通用的文字型 LLM 进行第二语言角色扮演时，在不把文字成功或模型反馈误认为口语对话证据的前提下，可以如何描述留下的证据？

本记录只讨论文字交换：学习者阅读提示词、输入回复，并收到生成的文字。它不评估语音功能、语音识别、发音、特定语言、命名产品、作为教师的 LLM 或任何学习结果。

这与已有的有界练习和短提示词记录刻意区分。它不重复那些记录的练习顺序、公开用户报告或一般性的“不能证明流利度”边界；唯一关注点是：把文字角色扮演称作会话练习时，缺少与模态相匹配的证据。

## 受来源约束的初学者结论

应按保留下来的证据来称呼文字交换：**在明确援助条件下，针对一项指定语言功能的文字排练**。产物可以包含学习者的文字回复、模型给出的候选纠正和学习者自己写的修订，但没有直接记录学习者如何听懂语音、如何发音、如何处理实时速度或如何修复口语误解。

这是基于 O1–O3 的项目推断，不是学习发现。一个小型初学者记录可以在不增加另一种提示词方法的情况下保持边界清楚：

| 记录字段 | 记录为 | 不要从中推断 |
| --- | --- | --- |
| 模式 | `typed rehearsal` | 口语互动、发音或听力能力 |
| 目标 | 一个书面功能，例如询问火车时间 | 通用语言等级 |
| 援助 | 已知时记录模型名称/版本、模型反馈和核对过的外部参考 | 反馈因为流畅或自信就一定正确 |
| 产物 | 原始文字回复和学习者自己写的修订 | 独立口语表现 |
| 未观察到 | 除非另行记录，否则为语音、音频理解、速度和实时修复 | 缺少的证据已经成功发生 |

如果目标后来变成**口语**会话，应先改变证据表面，再改变主张：在适当同意的前提下取得音频或实时互动样本，明确口语目标，并使用适合该目的的复核方法。任何有后果的分级、认证或教学决定都不应把通用 LLM 的反馈当作评估结果；目的和证据应转交合格的评估路径。

## 失败情境

一名初学者用文字完成四轮意大利语餐厅对话。模型称回复很自然，并说学习者已经可以交流。学习者于是把这句赞扬当作自己能听懂正常语速服务员的证明。

保存的聊天无法支持这个结论：它只有文字产出和生成的反馈，没有学习者听到口头问题或给出可听见回答的证据。按照 O1，纠正本身也可能带着自信的错误。因此，负责的记录应是 `typed_rehearsal_observed; feedback_unverified_for_assessment`，而口语听力与口语表达保持 `not_observed`。

## 不作出的主张

本记录不证明：

- 文字角色扮演会改善、损害或不会改善语言学习；
- 文字交换不能作为排练或准备而有用；
- 文字中成功的学习者不能开口交流，或文字中困难的学习者就不能开口交流；
- 任何具体模型反馈、语法纠正、自信声明或生成评分表是错误的；
- 单独的音频、人工复核或测验分数就能证明流利度、保持、真实沟通能力或语言等级；
- ETS 的评估设计或 NIST 指引验证了 Prysai 卡片、模型、语言课程或学习者结果。

## 下一步证据

在提出超出有界记录的主张前，需要经授权的评估：明确初学者群体与目标语言功能；为文字或音频制定同意和最小化规则；分开设置文字与口语任务；预先声明援助与评分表；保留原始产物；由适合任务的评审者进行检查；并为每项结果定义解释。若要考察稳定性或迁移，还需要后续任务和明确的主张边界。本记录没有这些证据。

## 来源与许可证边界

外部材料仍归其所有者所有，本项目仅链接并作限定性转述。没有复制外部文字、测验题、提示词、图像、音频、数据集或专有评分程序。O1 是官方技术画像，O2 是一个评估机构的当前网页材料，O3 是开放获取的测验标准；被引用不代表获得底层内容的再利用权。

## 停止记录

研究在确认生成输出错误风险的主要负责人材料、一个语言评估项目对技能表面的区分，以及分数解释证据后停止。没有把公开报告提升为证据，也没有测试模型、学习者、语音功能或评估。由此得到的课程含义仅限于：把文字型 LLM 对话标为文字排练；在获得匹配证据前，不声称口语会话能力或反馈有效性。
