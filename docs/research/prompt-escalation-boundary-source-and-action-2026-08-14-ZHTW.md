# 簡單提示不夠時：來源與行動的升級邊界

**狀態：**研究候選／`not_run`

**存取日期：**2026-08-14（America/Los_Angeles）

**負責人：**curriculum-maintainer

**下次複查：**2026-11-14，或在將本邊界製作成學習卡、以學習者評估，或用來支持特定產品主張之前。

## 研究問題與範圍

面向初學者的最小判斷是什麼，才能把一般的純文字提示，與需要有來源依據的調查或可稽核任務協定區分開？本紀錄只處理第一次路由選擇，不是一般的提示撰寫指南。它涵蓋三種可能混在一起的要求：

1. 改寫或討論讀者已提供的文字；
2. 對外部世界提出有實質影響的事實主張；以及
3. 修改檔案、帳號、共用系統、發佈內容或其他外部狀態。

它不規定通用提示格式、不比較模型、不驗證來源、不執行任務，也不評估學習者。它是通用 LLM 協作核心的路由邊界，不是特定平台的介面卡。

## 方法與來源選擇規則

只保留第一手指引：目前的 OpenAI 開發者文件與一份 NIST 出版品。OpenAI 頁面有產品範圍且會變動；NIST 出版品是風險框架剖面，不是提示指南或模型測試。兩者都只讀，沒有執行帳號、API 請求、模型對話、學習者工作階段、來源查找或任務執行。

本專案的推論刻意保守：只有在讀者能用已提供的資料檢查結果，且不需要目前的外部主張或外部行動時，才使用簡單提示。任一條件不成立就升級。這是課程路由決定，不是說長提示不安全，也不是說升級就能保證正確。

## 狹義的初學者問題

「這項政策目前仍有效嗎？請摘要它，並更新我們的公開說明頁。」這項要求同時包含目前的外部事實與發佈行動。即使答案寫得很有說服力，也可能沒有說清楚來源、日期、權限、目標與驗收證據。本紀錄沒有調查或公開使用者樣本來量測這種要求的頻率，因此它只是專案定義的教學情境，不是普遍性結論。

## 精簡路由測試

第一次提出要求前，讀者用日常語言回答：

1. 我能否只根據自己提供的文字與事實判斷結果？
2. 這項要求是否需要目前的外部主張，或會改變對話以外的東西？

第一題回答「是」、第二題回答「否」時，純文字簡單提示可以是起點。需要重要外部事實就走來源路徑；提出外部行動就同時走任務協定。兩者都需要時，保持來源探索與行動權限分開，不要讓帶有引用的答案悄悄授權修改。醫療、法律、金融、就業、教育、住房、移民、保險、人身安全等重大問題仍需要合適的人類或領域審閱；本紀錄不提供這些審閱。

## 失敗邊界與驗收證據

失敗情境：讀者在一輪要求模型「確認目前規則並送出更新」。模型回傳自信的段落與連結，但讀者找不到來源負責人、存取日期、支持位置、發佈目標或傳送權限。

最小安全復原：保留未傳送草稿，把要求拆成來源問題與擬議行動，然後在相關路徑的缺少輸入規則處停止。不要叫模型填補缺少的權限，也不要把無法開啟的頁面當成證明。

候選驗收：讀者能指出目標結果、外部主張是否重要、是否提出外部行動、選擇的既有路徑與停止條件。這只檢查路由決定是否寫清楚，不驗證來源、輸出、行動或學習結果。

## 既有材料的邊界

本紀錄不取代既有的 first-turn、research、source 或 task 協定，只加入一項刻意小的區分：簡單提示處理已提供的純文字轉換或討論；Source Investigator 處理一項有界的目前來源問題；Research Router 處理未解決或多來源研究設計；Task Protocol 處理權限、副作用、驗收證據與復原。本紀錄不提出新的 Skill、提示卡、章節、Lab、註冊項目、評測夾具或讀者主張。
