## Niveles de evidencia y reglas de revisión

- `Informe de usuario` demuestra solo que la persona afirma haber observado el síntoma en el entorno indicado; varias plataformas no lo convierten automáticamente en confirmación oficial.
- Una `sugerencia de quien responde` registra una solución comunitaria y sus riesgos; no se convierte por sí sola en sintaxis actual ni en política de soporte.
- La `confirmación oficial` exige respuesta del mantenedor, documentación oficial, registro de corrección o nota de versión comprobable; un bot de deduplicación no cuenta.
- La `reproducción local` solo se puede rellenar después de ejecutar el caso en este proyecto y guardar evidencia; este índice no tiene ninguna.
- Al citar un caso volátil, conserva URL original, estado del Issue, versión/plataforma, fecha de consulta y el límite “no reproducido en este proyecto”. `closed` describe el estado de la página, no una corrección ni disponibilidad universal.

## Límite de foros y licencias

Las páginas de Stack Overflow indican CC BY-SA 4.0. El proyecto conserva solo resúmenes fácticos, estructura del problema y enlaces; no copia pasajes largos, código ni comandos de quienes respondieron. Los Issues de GitHub se citan como fuentes de informes públicos, no como confirmación de OpenAI. Autores, etiquetas y resultados de búsqueda no cambian ese límite. Reddit, GitHub Discussions y páginas que no se puedan verificar de forma fiable no entran en la evidencia principal.
