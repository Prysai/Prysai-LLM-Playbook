# Beginner Practice Pack: primary-source boundary

**Status:** research record; curriculum recommendation only

**Accessed:** 2026-08-13

**Scope:** source basis for a beginner practice pack covering language
practice, transferable skill practice, and bounded research

## Question

Which durable methods can support a beginner-facing practice pack, and which
current vendor recommendations can inform its prompt cards without being
misrepresented as evidence of learning or cross-model effectiveness?

## Decision

Build the pack around observable work rather than a catalogue of allegedly
powerful prompts:

```text
fixed baseline -> learner attempt -> bounded feedback -> learner correction
               -> changed task -> delayed check where the claim requires it

bounded question -> source-owner search -> claim ledger -> conflict check
                 -> scoped synthesis -> stop receipt
```

The learning sources below support retrieval, delayed measurement, and
careful instructional design within their studied or declared scopes. The
information-literacy sources support contextual authority and lateral source
evaluation. The vendor sources support current prompt-design practices for
their products. None proves that an LLM is an effective tutor, that a prompt
works across platforms, or that a learner can master a language or skill in a
fixed number of days.

## Curriculum implications

1. A beginner card should name one observable performance or decision, not
   “learn Spanish,” “master research,” or another unbounded outcome.
2. The first learning card should request a fixed baseline and wait for the
   learner's attempt before disclosing a model answer.
3. Feedback should preserve the original attempt, disclose hints, request a
   learner-authored correction, and test the same capability in a materially
   changed case.
4. Retention requires a separately recorded delayed attempt. A reminder may be
   proposed, but the project must not claim that one was scheduled unless an
   authorized tool actually created it.
5. A research card should bind the question to a decision, route claims to
   appropriate source owners, inspect sources in context, seek material
   disagreement, and end with a stopping receipt.
6. Vendor prompt practices belong in dated adapters. Baseline, attempt,
   evidence, uncertainty, and stopping rules belong in the durable core.

## Reuse and evidence boundary

These sources are references, not bundled assets. Their hosted terms,
copyright, linked-file notices, and product details remain with their owners.
Before adapting any source expression, example, table, descriptor, assessment
item, or code, perform a file-level permission review and record the decision
in the asset register.

Public posts, forum answers, and screenshots can reveal a learner need or a
failure pattern. Repetition or popularity does not establish efficacy,
prevalence, root cause, fluency, mastery, retention, or prompt superiority.
The reported claim that a person learned a language in seven days is therefore
treated only as a demand signal unless the underlying capability, baseline,
aids, attempts, delayed check, transfer task, scoring, and limitations can be
independently inspected.

## Stop receipt

The search stopped after the requested roles had an owner source: instructional

No inaccessible material was bypassed. The resulting recommendation remains a
