# Atlas 首批独立上下文前测记录

**日期：** 2026-08-09
**范围：** 三个 Atlas 核心 Skill 的独立上下文前测归档
**目的：** 记录结构、触发和基本行为是否达到 `candidate` 门槛，不把一次前测写成生产就绪证明。

## 测试条件

- 测试者在不依赖本轮设计讨论的独立上下文中提出任务；
- 使用当时工作区中的 Skill 文件和项目规则；
- 每个 Skill 至少观察一个正向任务、一个边界/失败任务和交付格式；
- 前测只判断“是否值得继续评估”，不替代迁移测试、人工复核、许可证审查或真实用户学习测试。

## 结果摘要

| Skill | 正向触发 | 边界行为 | 失败/缺失输入行为 | 初步结论 |
|---|---|---|---|---|
| `prysai-task-protocol` | 能把模糊请求整理为目标、背景、输入、约束、行动、验收、失败和交付 | 能识别外部副作用、秘密和不可逆操作需要确认 | 缺失会改变范围或风险的输入时应暂停；低风险缺口可先检查 | `candidate`，通过基础前测 |
| `prysai-evidence-review` | 能将完成声明拆成断言，并逐条要求对应证据 | 能区分已验证、部分完成、未验证和无法判断 | 不把“测试已通过”或“官方确认”这类无证据断言直接采信 | `candidate`，通过基础前测 |
| `prysai-skill-selector` | 能按目标、生命周期、风险和依赖选择最小 Skill 组合 | 能拒绝目录数量、热度或“全部安装”作为充分理由 | 候选缺少许可证、依赖、触发或维护信息时标记为阻塞/待审查 | `candidate`，通过基础前测 |

## 证据边界

本记录证明的是三项 Skill 在独立上下文中完成了基础前测。它不证明：

- 所有 Atlas Skill 都已经验证；
- 三项 Skill 在所有领域、模型和产品入口上都稳定；
- 学习者已经掌握对应能力；
- 外部候选目录中的任何 Skill 已获准安装或发行；
- GPT-5.6 Luna 已被证明是最具性价比或转换率最高的模型。
