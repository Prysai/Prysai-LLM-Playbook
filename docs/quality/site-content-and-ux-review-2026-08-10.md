# 公共展示页内容与体验审查

**审查日期：** 2026-08-10
**审查状态：** candidate
**审查类型：** 只读内容、可读性、导航与可访问性审查
**审查范围：** `site/index.html`、`site/styles.css`、`site/app.js`、`site/README.md`、已有浏览器验收记录

## 证据边界

本地静态服务 `http://localhost:4173/site/` 返回 HTTP 200。本轮在 Codex 应用内浏览器重新加载页面并检查 DOM、交互状态、窄屏布局、截图和控制台错误；结果与[公共展示页浏览器验收记录](review-public-site-browser-2026-08-10.md)一致。浏览器检查没有读取凭据、Cookie、localStorage 内容或浏览历史。

本记录证明的是当前本地静态页面在声明范围内的运行观察，不证明 GitHub Pages、生产域名、真实移动设备、屏幕阅读器、跨浏览器、性能或真实用户测试结果。

## 本轮已关闭的问题

### 学习路径入口已暴露

`site/index.html` 的主导航现在包含 `Learning path`，首屏第二入口指向 `#path`。DOM 检查确认导航文字、锚点和学习路径区域均存在；L3 入口与实验 013 的映射仍由生成数据驱动。

### 首屏行动已收敛

首屏现在提供一个主行动 `Start a 30-minute safe task` 和一个次行动 `Choose a learning level`。英文默认和中文切换后两条入口都保持对应优先级，避免让用户在一开始先面对 Skill 目录或状态说明。

### P1 — 主要阅读入口直接打开 Markdown 源文件

**证据：** 首屏章节和实验链接直接指向 `../book/**/*.md`（[site/index.html:50-51](../../site/index.html#L50-L51)）；学习路径动态链接也由 [site/app.js:155-190](../../site/app.js#L155-L190) 指向 Markdown 文件。`site/README.md` 只说明静态服务和文件存在，没有证明目标托管环境会把这些文件渲染成文章页面。

**影响：** 链接目标存在不等于访客能舒适阅读。若浏览器显示原始 Markdown、下载文件或失去站点导航，用户从展示页进入正文后会感到产品断裂，尤其影响首个章节和实验的完成率。

**可落地改动：** 选择并明确一种公开阅读方案：为章节和实验生成静态 HTML；或把链接文案明确为“Open source Markdown”；或提供稳定的仓库/文档渲染入口。展示页不要同时把“阅读入口”和“源文件入口”写成同一种链接。

**验证方法：** 从首屏、L3 面板和实验卡片各打开一个目标，在本地静态服务和目标部署环境分别检查标题层级、代码块、返回路径、页面标题和移动端换行；记录响应类型和实际阅读截图。

### P2 — 长页面的信息负担仍未完成用户测试

**证据：** 页面包含 22 章、13 个实验和 7 个 Skill 的连续内容块（[site/index.html:154-235](../../site/index.html#L154-L235)）。大量辅助文字使用 `0.68rem–0.82rem`（例如 [site/styles.css:188-199](../../site/styles.css#L188-L199)），章节和实验之后仍有更新、状态和下一步区块。窄屏在 480px 下变为单列（[site/styles.css:282-297](../../site/styles.css#L282-L297)），不会减少内容数量。

**影响：** 现有验收记录证明无横向溢出，但没有证明阅读负担、中文换行、对比度或 200% 缩放下的舒适度。用户容易在“章节—实验—Skill—更新—状态”连续滚动中失去当前任务。

**可落地改动：** 给每个大区块增加一句稳定的“你将在这里完成什么”；实验区默认突出 Lab 001、Lab 013 和按等级推荐的少量入口，其余收进“all labs”；把关键说明从小号辅助文字提升到正文尺寸，状态与元数据保持小号。

**验证方法：** 在桌面、320px、390px 和 200% 浏览器缩放下截图；逐段检查中文不截断、正文与辅助文字层级明显、当前区块标题可定位；用一次 30 秒滚动测试记录能否说出当前区块的目的和下一步。

### 路线筛选已补齐可访问状态

路线按钮使用 `aria-pressed` 表达唯一当前选项，脚本在切换时同步属性，并通过 `role="status"` / `aria-live="polite"` 报告当前结果。实测切换到 B 路线后只有 B 组可见，中文提示为“正在显示 B · 真实工作的 7 章”。
