## 这份实验要解决什么

此前的实验分别讲任务协议、行动边界、证据审查和工程生命周期，但学习者仍可能把它们当成互不相干的清单。实验 013 将这些接口串成一条低风险的本地 Markdown 任务：先固定输入和基线，再定义切片、记录 checkpoint、受限编辑、验证、故意失败、恢复和跨领域迁移。

## 来源与原创边界

实验中的 checkpoint、断言—证据表、停止状态和迁移字段是本项目基于[高阶方法研究](../research/web-methods-synthesis-2026-08-10.md)与[网页田野研究](../research/web-field-problems-2026-08-10.md)的原创重写。公开来源只用于记录问题和方法，不复制外部教程、代码、图片或 Skill 指令。产品入口、权限和命令等易变事实仍回到官方来源记录，不能由本实验自行推断。

## 升级前的最小运行门

1. 在无秘密、可回滚的临时 Markdown 项目中按实验运行一次；保存 run ID、输入 hash、CP0–CP3、diff、命令输出和退出码。
2. 至少完成一个故意失败变体，并保留失败前状态、停止原因和恢复动作。
3. 由没有阅读本实验审查记录的人独立复核交付摘要，确认其能指出未验证项、回滚目标和下一步。
4. 在另一个低风险研究或内容任务上完成迁移，并重新填写来源、权限和验收字段。

在这些证据出现前，实验保持 `draft` / `not_run`，本审查记录保持 `candidate`。
