# ADR 0001：把 Atlas 定义为课程、实验室与能力生态

**状态：** accepted
**日期：** 2026-08-09
**决策者：** Prysai Lab 项目发起人和维护团队

## 背景

六个输入项目混合了中文教材、工程方法、营销技能、学术研究套件、生态索引和大量外部自动化技能。如果直接合并，会得到一个内容很多但学习路径、许可边界、质量标准和更新责任都不清楚的目录。

## 决策

Atlas 的首要产品是书籍式的 Codex GPT 能力系统，包含：

- 从 GPT/Codex 认知到组织级熟练运用的学习主线；
- 可重复的低风险实验和学习者证据；
- 经审查的可执行 skills；
- 工程、研究、营销、内容/设计/数据/自动化等专业轨；
- 来源、许可证、更新、评测和贡献治理。

外部项目只作为来源、参考、独立扩展或逐项适配候选。Prysai Lab 的原创内容与外部组件保持清晰分界。

## 备选方案

### 直接合并所有目录

放弃。目录规模不能替代学习路径，且会混淆许可证、依赖、命名、质量和外部副作用。

### 只做一本静态书

放弃。没有实验、skill 和评测，读者无法证明自己从“看过”走到“会用”。

### 只做一个 skill marketplace

放弃。用户首先需要判断力和工作方法，安装能力不能代替理解和验证。

## 影响

- 第一版交付会比直接复制目录慢，但后续维护、学习和审查成本更可控；
- 需要建立来源与评测责任；
- 外部许可受限内容不会自动进入核心发行版；
- 目录数量不再作为进度指标，学习结果和验证证据成为进度指标。
