# ADR 0002：分离稳定原理与易变产品事实

**状态：** accepted
**日期：** 2026-08-09

## 决策

Field Guide 将知识分为稳定层、产品层、领域层和实例层：

- 稳定层写入长期章节；
- 产品层引用官方文档并定期复核；
- 领域层通过案例和评测更新；
- 实例层记录日期、版本、适用范围和维护责任。

模型名称、价格、额度、入口、权限默认值、工具支持和外部服务 API 不作为脱离日期的永久结论。GPT-5.6 Luna 的“高性价比”只作为待验证假设。

## 原因

Codex 和模型更新快，书籍式内容若把易变事实写死，很快会误导读者。分层让方法保持稳定，同时允许具体产品步骤持续更新。

## 影响

章节需要来源表和复核日期；发布流程需要检查 stale claims；维护者需要接受“删除过时内容”也是质量工作。
