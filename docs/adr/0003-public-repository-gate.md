# ADR 0003：先私有开发、再公开发布

**状态：** proposed
**日期：** 2026-08-09

## 决策

本项目现在位于维护组织的私有开发仓库，用于持续融合、更新、审查和团队协作。仓库已经创建，但私有开发仓库不等于公开发行版；公开发布仍需完成下列门禁。

## 公开发布门禁

在将仓库公开或发布公开发行版前，必须完成：

1. 确认项目正式名称、描述和品牌表达；
2. 确认组织希望采用的发行版许可证；
3. 完成六个输入来源的归属和可发布边界审查；
4. 首批主线章节和实验完成前测；
5. 首批项目 skills 完成结构、触发、边界、失败和新鲜上下文验证；
6. 删除或隔离所有秘密、个人数据和不可公开资产；
7. 决定是否以单一仓库、插件仓库或书稿与 skills 分仓发布；
8. 指定至少一名维护者和更新责任。

## 当前状态

当前本地拟采用名称为 `Codex: From First Task to Real Work`，中文副标题为“Codex：从第一个任务到真实工作”；README、书稿入口和展示页已先保持一致。GitHub 仓库路径暂不迁移，避免在名称尚未确认前破坏旧链接。许可证、外部资产边界、学习者测试、公开范围和首批能力的运行验证仍未全部完成，因此当前不公开发行。
