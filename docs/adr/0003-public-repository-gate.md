# ADR 0003：组织仓库先私有开发、再公开发布

**状态：** proposed
**日期：** 2026-08-09

## 决策

Atlas 现在创建为 Prysai Lab 组织下的私有开发仓库，用于持续融合、更新、审查和团队协作。私有开发仓库不等于公开发行版；公开发布仍需完成下列门禁。

## 公开发布门禁

在 Prysai Lab 组织下创建公开仓库前，必须完成：

1. 确认项目正式名称、描述和品牌表达；
2. 确认组织希望采用的发行版许可证；
3. 完成六个输入来源的归属和可发布边界审查；
4. 首批主线章节和实验完成前测；
5. 首批 Atlas skills 完成结构、触发、边界、失败和新鲜上下文验证；
6. 删除或隔离所有秘密、个人数据和不可公开资产；
7. 决定是否以单一仓库、插件仓库或书稿与 skills 分仓发布；
8. 指定至少一名维护者和更新责任。

## 当前状态

组织当前可见的仓库只有 `OpenSiteTrust`。Atlas 的私有开发仓库会在本地基线通过后创建；正式名称、许可证、外部资产边界、学习者测试和公开范围仍未完成，因此不在创建时直接公开。
