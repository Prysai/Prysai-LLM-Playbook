# Product and curriculum strategy

This directory stores dated proposals about product positioning, audience,
curriculum shape, information architecture, and migration sequencing.

Strategy documents are decision inputs, not active contracts. A proposal does
not rename the project, move canonical content, change public claims, or grant
permission to publish. Adopt an expensive or externally visible direction with
an ADR, update the affected governance contracts, and verify the migration.
