# GPT-5.6 Luna 模型评估实验

## 目的

验证 GPT-5.6 Luna 是否适合 Prysai LLM Playbook 的主要任务，而不是预先假定它“性价比最高”。评估结论只对声明的任务集、上下文、工具、权限和日期负责。

## 假设

> 在清晰、重复性较强、需要结构化输出或高频执行的 Playbook 任务中，GPT-5.6 Luna 可能以较低成本提供足够质量；在高不确定性、复杂工具编排或高风险审查任务中，结果需要与更强模型或更高人工复核进行比较。

## 任务集

固定任务集 v1 包含 38 个任务，覆盖 15 个轨道，覆盖：

- 解释 GPT/Codex 概念；
- 从模糊愿望生成任务协议；
- 选择最小 skill 组合；
- 审查完成声明和证据；
- 研究问题收敛和来源计划；
- 工程计划与小型代码修改；
- 营销产品上下文与实验计划；
- 文档/设计/数据产物的结构化转换；
- 高风险行动边界判断；
- 缺失输入、冲突和重复失败的停止行为。

## 固定条件

- 同一任务文本和同一版本上下文；
- 同一工具集合、权限和网络条件；
- 同一输出格式和成功标准；
- 每个任务至少重复 3 次；
- 记录模型版本、日期、工作面和运行环境；
- 不把一次结果、主观感觉或演示视频当作总体证据。

## 指标

| 指标 | 定义 |
|---|---|
| 首次通过率 | 第一次运行即满足验收标准的任务比例 |
| 返工率 | 需要用户/Agent 额外修复才能通过的任务比例 |
| 错误类型 | 目标、上下文、实现、事实、权限、验证或交付错误 |
| 平均耗时 | 从任务开始到满足验收的时间 |
| 成本 | 按同一计价和使用口径记录 |
| 证据完整度 | 交付中实际提供的验证证据覆盖率 |
| 停止正确率 | 输入缺失、权限冲突或重复失败时是否正确停止 |
| 人工评分 | 正确性、完整性、可维护性、清晰度和安全性 |
