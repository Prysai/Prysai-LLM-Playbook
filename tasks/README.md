# Work plan and handoff

`tasks/` holds the current bounded plan and checklist for ongoing project work.
It is a coordination surface, not the source of truth for chapters, status,
locales, or generated data.

## Start here

- [`todo.md`](todo.md): the short current checklist and open quality gates.
- [`plan.md`](plan.md): scope, phases, acceptance criteria, risks, and evidence.
- [Update map](../docs/governance/update-map.md): where a content or contract
  change actually belongs.

When a task changes a canonical contract, update that contract first and link
the evidence back into the plan. Keep unfinished work visible; a checked box
means the stated task is complete, not that the whole project is complete.
